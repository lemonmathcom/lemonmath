:::goals
- Set out and multiply a number with several digits by a one-digit number (with carrying).
- Set out and divide a number with several digits by a one-digit number (exact division and division with a remainder).
- Know that the remainder is always less than the divisor, and check a division by multiplying.
- Solve word problems using multiplication and division.
:::

The library of a primary school receives $3$ boxes of books, each box holding $1\,245$ books. The library wants to share all the books equally among $5$ classes.

How many books does the library receive altogether? How many books does each class get? Both calculations use a large number and a one-digit number, and this lesson shows you how to do them neatly and without mistakes.

## Multiplying by a one-digit number

### Let's explore

Split $1\,245$ into its places and multiply each place by $3$:

- $5\times3=15$ (ones), $40\times3=120$, $200\times3=600$, $1\,000\times3=3\,000$.
- Add them: $15+120+600+3\,000=3\,735$.

So $1\,245\times3=3\,735$. Splitting works but it is long. Instead, set out the multiplication and multiply each digit from right to left, carrying to the next column when a product is $10$ or more:

$$\begin{array}{r} 1245 \\ \times\ \ \ \ 3 \\ \hline 3735 \end{array}$$

Ones: $3\times5=15$, write $5$ and carry $1$. Tens: $3\times4=12$, add $1$ to make $13$, write $3$ and carry $1$. Hundreds: $3\times2=6$, add $1$ to make $7$, write $7$. Thousands: $3\times1=3$, write $3$.

So the library receives $3\,735$ books altogether.

:::theorem Multiplying by a one-digit number
To multiply a number with several digits by a one-digit number:
1. Set it out: write the one-digit number under the ones digit of the other number.
2. Multiply each digit of the larger number in turn, from right to left.
3. Each time, add the carried number (if any), write the ones digit of the result and carry the other digit to the next column on the left.
:::

Why does this work? We multiply each place by $3$ and then add, just like the splitting above. The carried number is the part of one place's product that belongs to the next place: $15$ ones is $1$ ten and $5$ ones.

We start with a multiplication with no carrying.

:::example No carrying
Set out and work out $3\,021\times3$.

**Solution.** We set out the sum and multiply each place; every product is less than $10$, so nothing is carried:
$$\begin{array}{r} 3021 \\ \times\ \ \ \ 3 \\ \hline 9063 \end{array}$$
Ones: $3\times1=3$. Tens: $3\times2=6$. Hundreds: $3\times0=0$. Thousands: $3\times3=9$.

So $3\,021\times3=9\,063$.
:::

Now a multiplication with carrying in several places.

:::example Carrying
Set out and work out $4\,786\times6$.

**Solution.** We set out the sum and multiply from right to left:
$$\begin{array}{r} 4786 \\ \times\ \ \ \ 6 \\ \hline 28716 \end{array}$$
Ones: $6\times6=36$, write $6$ and carry $3$. Tens: $6\times8=48$, add $3$ to make $51$, write $1$ and carry $5$. Hundreds: $6\times7=42$, add $5$ to make $47$, write $7$ and carry $4$. Thousands: $6\times4=24$, add $4$ to make $28$, write $28$.

So $4\,786\times6=28\,716$.
:::

## Dividing by a one-digit number

### Let's explore

Now we share $3\,735$ books among $5$ classes. Split $3\,735=3\,500+235$:

- $3\,500\div5=700$.
- $235\div5=47$.
- Add them: $700+47=747$.

So $3\,735\div5=747$, and each class gets $747$ books. When we set out a division, we work from the highest place to the lowest, in three steps: **divide, multiply, subtract**, then **bring down** the next digit.

For $3\,735\div5$: the digit $3$ is less than $5$, so we take $37$ (hundreds).

- $37\div5=7$ (remainder $2$), because $7\times5=35$ and $37-35=2$.
- Bring down $3$ to make $23$. $23\div5=4$ (remainder $3$), because $4\times5=20$ and $23-20=3$.
- Bring down $5$ to make $35$. $35\div5=7$ (remainder $0$).

The quotient is $747$ and the remainder is $0$. This is an **exact division**.

When the remainder is not $0$, we have a **division with a remainder**.

:::theorem Dividing by a one-digit number
To divide a number with several digits by a one-digit number:
1. Start at the highest place. If the first digit is less than the divisor, take the next digit as well.
2. Each time: divide, multiply, subtract; then bring down the next digit.
3. Stop when all the digits have been brought down.

The remainder is always **less than the divisor**. To check: $\text{quotient}\times\text{divisor}+\text{remainder}=\text{dividend}$.
:::

Why do we bring a digit down? The remainder in one place is changed into the next smaller place: $2$ hundreds is $20$ tens, and adding $3$ tens makes $23$ tens. That is why we can go on dividing $23$ by $5$.

**Connection.** You have already multiplied and divided three-digit numbers. This lesson extends that to four- and five-digit numbers and uses the link between multiplication and division to check answers. In the next lesson you will multiply by a two-digit number.

:::example Exact division
Set out and work out $4\,872\div4$.

**Solution.** We start with the thousands:
- $4\div4=1$, write $1$; $1\times4=4$; $4-4=0$.
- Bring down $8$: $8\div4=2$, write $2$; $2\times4=8$; $8-8=0$.
- Bring down $7$: $7\div4=1$ (remainder $3$), write $1$; $1\times4=4$; $7-4=3$.
- Bring down $2$ to make $32$: $32\div4=8$, write $8$; $8\times4=32$; $32-32=0$.

So $4\,872\div4=1\,218$.
:::

When you meet the digit $0$, look for the digit $0$ in the quotient.

:::example Division with a remainder
Set out and work out $5\,603\div7$.

**Solution.** The digit $5$ is less than $7$, so we take $56$ (hundreds).
- $56\div7=8$, write $8$; $8\times7=56$; $56-56=0$.
- Bring down $0$: $0\div7=0$, write $0$.
- Bring down $3$: $3\div7=0$ (remainder $3$), write $0$.

The quotient is $800$ and the remainder is $3$ (less than the divisor $7$).

**Check.** $800\times7+3=5\,603$. Correct.

So $5\,603\div7=800$ (remainder $3$).
:::

Now a word problem that uses both multiplication and division.

:::example Carrying rice
A transport company carries rice in $4$ lorry trips, each trip carrying $1\,275$ kg. The rice is shared equally among $6$ warehouses. How many kilograms of rice does each warehouse receive?

**Understand.** We know there are $4$ trips of $1\,275$ kg each, shared equally among $6$ warehouses. We need the kilograms of rice in each warehouse.

**Plan.** First find the total rice by multiplying, then divide the total by $6$.

**Solve.** The rice carried is $1\,275\times4=5\,100$ (kg).

The rice each warehouse receives is $5\,100\div6=850$ (kg).

**Answer:** $850$ kg.

**Look back.** Check: $850\times6=5\,100$. Correct. If there were $5$ warehouses instead of $6$, would each get more or less than $850$ kg?
:::

Finally, a problem where the remainder matters.

:::example Packing books into boxes
A library packs $1\,000$ books into boxes, each box holding $7$ books. What is the smallest number of boxes needed to pack all the books?

**Solution.** We have $1\,000\div7=142$ (remainder $6$), because $7\times142=994$ and $1\,000-994=6$.

There are $142$ full boxes and $6$ books left over. The leftover books need $1$ more box.

The number of boxes needed is $142+1=143$ (boxes).

So at least $143$ boxes are needed.
:::

:::warning Mistakes to watch out for
- **Forgetting to add the carried number.** Wrong: $2\,306\times4=9\,204$. Why it is wrong: $6\times4=24$, write $4$ and carry $2$, but the $2$ was not added in the tens place. Right: $2\,306\times4=9\,224$.
- **Leaving out the digit $0$ in the quotient.** Wrong: $5\,603\div7=8$ (remainder $3$). Why it is wrong: after bringing down $0$ and $3$ there are two more places, so the quotient has three digits; $7\times8+3=59$, not $5\,603$. Right: $5\,603\div7=800$ (remainder $3$).
- **A remainder that is not less than the divisor.** Wrong: $29\div4=6$ (remainder $5$). Why it is wrong: the remainder $5$ is greater than the divisor $4$, so we can divide further. Right: $29\div4=7$ (remainder $1$), because $7\times4=28$.
:::

## Summary

- To multiply a number with several digits by a one-digit number, multiply each place from right to left, carrying to the next column when a product is $10$ or more.
- To divide: divide, multiply, subtract, then bring down a digit, from the highest place to the lowest.
- The remainder is always less than the divisor; if it is $0$, the division is exact.
- Check a division: $\text{quotient}\times\text{divisor}+\text{remainder}=\text{dividend}$.
- When a division in a real problem has a remainder, think whether the leftover needs one more unit.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Set out in columns and work out: $2\,413\times3$.

::hint
**What you need:** multiply each place from right to left.

**Steps:**
1. Write $3$ under the ones digit of $2\,413$.
2. Multiply each digit by $3$ and see whether any product is $10$ or more.

::solution
$$\begin{array}{r} 2413 \\ \times\ \ \ \ 3 \\ \hline 7239 \end{array}$$
Ones: $3\times3=9$. Tens: $3\times1=3$. Hundreds: $3\times4=12$, write $2$ and carry $1$. Thousands: $3\times2=6$, add $1$ to make $7$.

**Answer.** $7\,239$.
:::

:::exercise
Set out in columns and work out: $3\,658\times5$.

::hint
**What you need:** multiply and carry when a product is $10$ or more.

**Steps:**
1. Ones: $5\times8=40$, write $0$ and carry $4$.
2. Continue with the tens, hundreds and thousands, adding the carried number to each new product.

::solution
$$\begin{array}{r} 3658 \\ \times\ \ \ \ 5 \\ \hline 18290 \end{array}$$
Ones: $40$, write $0$ and carry $4$. Tens: $25+4=29$, write $9$ and carry $2$. Hundreds: $30+2=32$, write $2$ and carry $3$. Thousands: $15+3=18$.

**Answer.** $18\,290$.
:::

:::exercise
Set out and work out: $6\,480\div8$.

::hint
**What you need:** if the first digit is less than the divisor, take one more digit.

**Steps:**
1. $6$ is less than $8$, so take $64$: what is $64\div8$?
2. Bring down $8$ and then $0$.

::solution
- $64\div8=8$, write $8$; $64-64=0$.
- Bring down $8$: $8\div8=1$, write $1$; $8-8=0$.
- Bring down $0$: $0\div8=0$, write $0$.

**Answer.** $6\,480\div8=810$.
:::

:::exercise
Set out and work out: $9\,247\div6$.

::hint
**What you need:** the remainder is less than the divisor; check with $\text{quotient}\times\text{divisor}+\text{remainder}$.

**Steps:**
1. $9\div6=1$ (remainder $3$); bring down $2$ to make $32$.
2. Continue, then check.

::solution
- $9\div6=1$ (remainder $3$).
- Bring down $2$: $32\div6=5$ (remainder $2$).
- Bring down $4$: $24\div6=4$ (remainder $0$).
- Bring down $7$: $7\div6=1$ (remainder $1$).

**Check.** $1\,541\times6+1=9\,247$. Correct.

**Answer.** $9\,247\div6=1\,541$ (remainder $1$).
:::

:::exercise
Every day Lan puts $2\,500$ dong into her piggy bank. How many dong has Lan put in the piggy bank after $7$ days?

::hint
**What you need:** the money per day times the number of days.

**Steps:**
1. What do we know? $2\,500$ dong per day, $7$ days. What is asked? The total amount.
2. Which operation do we use? Remember the unit.

::solution
The amount Lan puts in after $7$ days is:
$$2\,500\times7=17\,500\ \text{(dong)}.$$

**Answer.** $17\,500$ dong.
:::

:::exercise
An orchard harvests $4\,860$ kg of oranges. The oranges are packed equally into $9$ crates. How many kilograms of oranges are in each crate?

::hint
**What you need:** sharing equally means division.

**Steps:**
1. What do we know? What is asked?
2. Set out $4\,860\div9$ and check with multiplication.

::solution
The number of kilograms of oranges in each crate is:
$$4\,860\div9=540\ \text{(kg)}.$$

**Check.** $540\times9=4\,860$. Correct.

**Answer.** $540$ kg.
:::

:::exercise
Remember the lesson on rhombuses. A plot of land is a rhombus with side $125$ m. A fence is built all round the plot, with $1$ post for every $5$ m of fence. How many posts are needed?

::hint
**What you need:** perimeter of a rhombus $P=a\times4$.

**Steps:**
1. Work out the perimeter of the plot.
2. Divide the perimeter by the distance between posts.

::solution
The perimeter of the plot is $125\times4=500$ (m).

The number of posts needed is $500\div5=100$ (posts).

**Answer.** $100$ posts.
:::

:::exercise
Find the quotient and the remainder of $2\,009\div5$, then check.

::hint
**What you need:** when you meet a $0$, write $0$ in the quotient; the remainder is less than $5$.

**Steps:**
1. What is $20\div5$? Bring down $0$, then $9$.
2. Check: $\text{quotient}\times5+\text{remainder}$.

::solution
- $20\div5=4$ (remainder $0$).
- Bring down $0$: $0\div5=0$.
- Bring down $9$: $9\div5=1$ (remainder $4$).

The quotient is $401$ and the remainder is $4$.

**Check.** $401\times5+4=2\,009$. Correct.

**Answer.** Quotient $401$, remainder $4$.
:::

:::exercise
A division has divisor $6$, quotient $125$ and remainder $5$. Find the dividend.

::hint
**What you need:** $\text{dividend}=\text{quotient}\times\text{divisor}+\text{remainder}$.

**Steps:**
1. Work out $125\times6$.
2. Add the remainder.

::solution
The dividend is $125\times6+5=750+5=755$.

**Check.** $755\div6=125$ (remainder $5$). Correct.

**Answer.** $755$.
:::

:::exercise Challenge
Find the smallest four-digit number that is divisible by $7$.

::hint
**What you need:** the smallest four-digit number is $1\,000$; an exact division has remainder $0$.

**Steps:**
1. Divide $1\,000$ by $7$ and find the remainder.
2. How much must be added to $1\,000$ to make the remainder $0$?

::solution
We have $1\,000\div7=142$ (remainder $6$), so $1\,000=7\times142+6$.

We must add $7-6=1$ to $1\,000$ to get a number divisible by $7$: $1\,001=7\times143$.

**Answer.** $1\,001$.
:::
