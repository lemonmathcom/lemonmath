title: How many times an event happens
description: Learn to record the results of many trials, use tally marks and count how many times each event happens, then check the total matches the trials.
minutes: 15
---

:::goals
- Count how many times an event happens in many trials.
- Use a tally chart (tally marks) to record and read results.
- Check that the total number of times all events happen equals the number of trials.
:::

Nam tosses a coin $10$ times and records each result: heads (H) or tails (T). The results are: H, T, T, H, H, T, H, H, T, H. How many times did heads come up? How many times did tails come up?

You already know how to read a list of data and a bar chart. This lesson shows you how to count the results of trials like these.

## Let's explore

Each toss of the coin is one **trial**. Heads coming up, or tails coming up, is an **event**. We count each event with **tally marks**: for every time it happens we draw one mark. Every $5$ marks make a group, which is easier to count.

For the list H, T, T, H, H, T, H, H, T, H, read through each toss:

- Tosses $1$, $4$, $5$, $7$, $8$ and $10$ are H. Heads came up $6$ times.
- Tosses $2$, $3$, $6$ and $9$ are T. Tails came up $4$ times.

| Event | Tally marks | Number of times |
|---|---|---|
| Heads | $\mid\mid\mid\mid\mid\ \mid$ | $6$ |
| Tails | $\mid\mid\mid\mid$ | $4$ |

Check: $6+4=10$, exactly the number of tosses.

:::definition How many times an event happens
The **frequency** of an event is how many times it happens in all the trials. The frequencies of all the events add up to the number of trials.
:::

This is true because each trial gives exactly one result. So when we count all the results we get exactly the number of trials.

## Examples

We start with counting directly.

:::example Counting from a list of results
A coin is tossed $10$ times: H, T, T, H, H, T, H, H, T, H. How many times does each side come up?

**Solution.** We count each side, ticking the results so that we miss none and count none twice:
$$\text{heads: } 6\ \text{times},\qquad \text{tails: } 4\ \text{times}.$$
Check: $6+4=10$ tosses. So heads came up $6$ times and tails $4$ times.
:::

Now there are three different results instead of two.

:::example Picking counters
A bag has red, blue and yellow counters. Ha takes one out, looks, and puts it back, $12$ times. The results in order are: R, B, R, R, Y, B, R, Y, R, B, R, R. How many times does each colour come up?

**Solution.** Count each colour in the list:
$$\text{Red: } 7\ \text{times},\qquad \text{Blue: } 3\ \text{times},\qquad \text{Yellow: } 2\ \text{times}.$$
Check: $7+3+2=12$ picks. So red came up $7$ times, blue $3$ times and yellow $2$ times.
:::

Sometimes the results are already in a tally chart. We read the chart and answer.

:::example Rolling a dice
A dice is rolled $20$ times. This table shows how many times each face came up:

| Face | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
|---|---|---|---|---|---|---|
| Number of times | $3$ | $4$ | $2$ | $5$ | $3$ | $3$ |

a) Which face came up most often, and how many times? b) Which face came up least often? c) How many times did the even faces ($2$, $4$, $6$) come up altogether?

**Solution.** First check the table: $3+4+2+5+3+3=20$, which equals the number of rolls.

a) The greatest number is $5$, for face $4$. Face $4$ came up most often, $5$ times.

b) The least number is $2$, for face $3$.

c) Add the times for the three even faces:
$$4+5+3=12\ \text{(times)}.$$
So the even faces came up $12$ times.
:::

If we know the number of trials, we can find a missing frequency.

:::example Finding a missing number of times
A coin is tossed $15$ times and heads comes up $9$ times. How many times does tails come up?

**Solution.** Every toss gives heads or tails, so the times for heads plus the times for tails make $15$. So tails came up:
$$15-9=6\ \text{(times)}.$$
**Check.** $9+6=15$. Correct.
:::

:::warning Mistakes to watch out for
- **Missing or double-counting a result.** Wrong: the list H, T, T, H, H has $2$ heads. Why it is wrong: one H was missed. Right: $3$ heads. Tick each result as you count it.
- **A total that does not match the trials.** Wrong: $6+5=11$ but only $10$ tosses were made. Why it is wrong: something was counted twice. Right: count again until the total is $10$.
- **Mixing up the number of times with the name of the event.** Wrong: "The side that came up most is $6$" when asked which side. Why it is wrong: $6$ is a count, but the question asks for a side. Right: heads, $6$ times.
:::

## Summary

- Each toss, pick or roll is one trial; its result is an event.
- To find how many times an event happens, count its results.
- Tally marks: one mark each time; every $5$ marks make a group.
- The times for all events add up to the number of trials.
- If you know the total and the times for one event, subtract to find the other.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
A coin is tossed $8$ times: H, H, T, H, T, T, H, H. How many times does each side come up?

::hint
**What you need:** count each side, then check that the total is $8$.

**Steps:**
1. Count the Hs.
2. Count the Ts.
3. Add them to see if you get $8$.

::solution
H came up $5$ times and T came up $3$ times. Check $5+3=8$.

**Answer.** Heads $5$ times, tails $3$ times.
:::

:::exercise
A card is picked from three kinds of card A, B and C and put back, $10$ times: A, B, A, C, A, B, A, A, C, B. How many times was each kind picked?

::hint
**What you need:** count each kind of card in turn.

**Steps:**
1. Count the As, then the Bs, then the Cs.
2. Check the total is $10$.

::solution
A: $5$ times, B: $3$ times, C: $2$ times. Check: $5+3+2=10$.

**Answer.** A $5$ times, B $3$ times, C $2$ times.
:::

:::exercise
Remember the lesson on bar charts: a chart shows how many times three faces of a dice came up. The bar for face $1$ is $3$ tall, face $2$ is $5$ tall and face $3$ is $4$ tall. How many rolls were there in all? Which face came up most often?

::hint
**What you need:** the tallest bar is the greatest value; the times add up to the number of rolls.

**Steps:**
1. Read the numbers on top of the three bars.
2. Add the three numbers; find the greatest.

::solution
$3+5+4=12$ (rolls). The tallest bar is face $2$ ($5$ times).

**Answer.** $12$ rolls; face $2$.
:::

:::exercise
A coin is tossed $20$ times and heads comes up $11$ times. How many times does tails come up?

::hint
**What you need:** the times for heads plus the times for tails equal the number of tosses.

**Steps:**
1. Write a subtraction.
2. Check with an addition.

::solution
$20-11=9$ (times). Check: $11+9=20$.

**Answer.** $9$ times.
:::

:::exercise
Why do the times for the two sides of a coin always add up to the number of tosses? Check with heads $6$ times and tails $4$ times.

::hint
**What you need:** every toss gives exactly one result: heads or tails.

**Steps:**
1. How many sides is each toss counted under?
2. Add $6$ and $4$.

::solution
Each toss gives only one side, so each toss is counted exactly once, and when all are counted we get exactly the number of tosses. With $6+4=10$, this equals the $10$ tosses.

**Answer.** Because each toss has exactly one result; $6+4=10$.
:::

:::exercise
Lan counted the list R, B, R, R, B and said: "R came up $4$ times and B came up $2$ times." Where did Lan go wrong? Count again.

::hint
**What you need:** the total of the counts must equal the number of trials.

**Steps:**
1. Count how many trials there were.
2. Count each letter again.

::solution
There are $5$ trials but Lan's counts add up to $4+2=6$, so one was counted twice. The correct counts: R came up $3$ times and B came up $2$ times ($3+2=5$).

**Answer.** R $3$ times, B $2$ times.
:::

:::exercise
During $30$ minutes outside the school gate, the tally chart of passers-by shows: bicycles $12$, motorbikes $9$, cars $5$, and the rest were people on foot.
a) How many people were on foot?
b) How many motorbikes and cars went past altogether?
c) How many more bicycles than cars were there?

::hint
**What you need:** the question gives $30$ in all; subtract the numbers we know.

**Steps:**
1. Add the bicycles, motorbikes and cars.
2. Subtract from $30$ to find the people on foot.

::solution
a) Bicycles, motorbikes and cars: $12+9+5=26$. On foot: $30-26=4$. b) $9+5=14$. c) $12-5=7$.

**Answer.** a) $4$ people; b) $14$; c) $7$ more.
:::

:::exercise Challenge
A dice is rolled $20$ times and the even faces come up $12$ times altogether. Face $2$ came up $5$ times and face $6$ came up $3$ times. How many times did face $4$ come up? How many times did the odd faces come up altogether?

::hint
**What you need:** the even faces are $2$, $4$, $6$; their times add up to $12$.

**Steps:**
1. Find face $4$ by subtracting.
2. The odd faces are $20$ minus the even faces.

::solution
Face $4$: $12-5-3=4$ (times). Odd faces: $20-12=8$ (times).

**Check.** $5+4+3=12$ and $12+8=20$. Correct.

**Answer.** Face $4$ came up $4$ times; the odd faces $8$ times.
:::

## Mini test

:::quiz
::mc
A coin is tossed $10$ times and heads comes up $6$ times. Tails comes up
A. $6$ times.
B. $4$ times.
C. $16$ times.
D. $10$ times.
::key B
$10-6=4$. Option C adds instead of subtracting.

::mc
In the list R, B, R, R, B, how many times does R appear?
A. $2$ times.
B. $3$ times.
C. $5$ times.
D. $4$ times.
::key B
R is in tosses $1$, $3$ and $4$, so $3$ times. Option C is the number of trials.

::mc
The times for all events always add up to
A. the number of trials.
B. the greatest count.
C. $1$.
D. $0$.
::key A
Each trial gives exactly one result. Option B mixes this up with the greatest value.

::mc
Outside a school gate, $12$ bicycles, $9$ motorbikes and $5$ cars went past. How many vehicles went past in all?
A. $26$.
B. $14$.
C. $17$.
D. $12$.
::key A
$12+9+5=26$. Option B leaves out the bicycles, and C leaves out the motorbikes.

::tf
A dice is rolled $20$ times. Faces $1$ to $6$ come up $3, 4, 2, 5, 3, 3$ times.
a) Face $4$ came up $5$ times.
b) Face $3$ came up the fewest times.
c) The times for all the faces add up to $20$.
d) The even faces came up $10$ times altogether.
::key T T T F
a) True. b) True: $2$ is the fewest. c) True: $3+4+2+5+3+3=20$. d) False: $4+5+3=12$ times.

::sa
A coin is tossed $15$ times and heads comes up $9$ times. How many times does tails come up?
::key 6
$15-9=6$.

::sa
A dice is rolled $20$ times. Faces $1$ to $6$ come up $3, 4, 2, 5, 3, 3$ times. How many times did the even faces come up altogether?
::key 12
Faces $2$, $4$, $6$: $4+5+3=12$.
:::
