description: Learn to record the results of many trials, use tally marks and count how many times each event happens, then check the total matches the trials.
minutes: 15

:::goals
- Count how many times an event happens in many trials.
- Use a tally chart (tally marks) to record and read results.
- Check that the total number of times all events happen equals the number of trials.
:::

Nam tosses a coin $10$ times and records each result: heads (H) or tails (T). The results are: H, T, T, H, H, T, H, H, T, H. Looking at a long list like that, can you say at once how many times heads came up and how many times tails came up?

Counting a long list in your head is easy to get wrong: you miss one, or count one twice. You already know how to read a list of data and a bar chart. Now we learn a tidy, reliable way to count the results of trials like these.

## Let's explore

First, a few names. Each toss of the coin is one **trial**. Heads coming up, or tails coming up, is an **event**. To count without missing any, we use **tally marks**: each time an event happens, we draw one more mark for it. Every $5$ marks make a group, so the total is quick to read.

Let's go back to Nam's list H, T, T, H, H, T, H, H, T, H and read through each toss:

- Tosses $1$, $4$, $5$, $7$, $8$ and $10$ are H. Heads came up $6$ times.
- Tosses $2$, $3$, $6$ and $9$ are T. Tails came up $4$ times.
We collect the results in a tally chart:

| Event | Tally marks | Number of times |
|---|---|---|
| Heads | $\mid\mid\mid\mid\mid\ \mid$ | $6$ |
| Tails | $\mid\mid\mid\mid$ | $4$ |

One more thing to do: check. Add the two numbers, $6+4=10$, which is exactly the number of tosses. So nothing was missed and nothing was counted twice.

:::definition How many times an event happens
The **frequency** of an event is how many times it happens in all the trials. The frequencies of all the events add up to the number of trials.
:::

Why does the total always match? Each trial gives exactly one result, no more and no fewer. So when we count all the results we get exactly the number of trials. If the total is off, something has been counted wrongly.

## Examples

We start by counting directly from Nam's list.

:::example Counting from a list of results
A coin is tossed $10$ times: H, T, T, H, H, T, H, H, T, H. How many times does each side come up?

**Solution.** We count each side, ticking the results so that we miss none and count none twice:
$$\text{heads: } 6\ \text{times},\qquad \text{tails: } 4\ \text{times}.$$
Check: $6+4=10$ tosses. So heads came up $6$ times and tails $4$ times.
:::

This time there are three different results instead of two, so take care not to mix up the colours.

:::example Picking counters
A bag has red, blue and yellow counters. Ha takes one out, looks, and puts it back, $12$ times. The results in order are: R, B, R, R, Y, B, R, Y, R, B, R, R. How many times does each colour come up?

**Solution.** Count each colour in the list:
$$\text{Red: } 7\ \text{times},\qquad \text{Blue: } 3\ \text{times},\qquad \text{Yellow: } 2\ \text{times}.$$
Check: $7+3+2=12$ picks. So red came up $7$ times, blue $3$ times and yellow $2$ times.
:::

Sometimes the results come in a tally chart rather than as a list. Then we read the chart carefully before answering, and the first thing to do is check the total.

:::example Rolling a dice
A dice is rolled $20$ times. This table shows how many times each face came up:

| Face | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
|---|---|---|---|---|---|---|
| Number of times | $3$ | $4$ | $2$ | $5$ | $3$ | $3$ |

a) Which face came up most often, and how many times? b) Which face came up least often? c) How many times did the even faces ($2$, $4$, $6$) come up altogether?

**Solution.** First check the table: $3+4+2+5+3+3=20$, which equals the number of rolls.

a) The greatest number is $5$, for face $4$. Face $4$ came up most often, $5$ times.

b) The least number is $2$, for face $3$.

c) Add the times for the three even faces:
$$4+5+3=12\ \text{(times)}.$$
So the even faces came up $12$ times.
:::

Sometimes we know only the number of trials and how many times one event happened. How do we find the other?

:::example Finding a missing number of times
A coin is tossed $15$ times and heads comes up $9$ times. How many times does tails come up?

**Solution.** Every toss gives heads or tails, so the times for heads plus the times for tails make $15$. So tails came up:
$$15-9=6\ \text{(times)}.$$
**Check.** $9+6=15$. Correct.
:::

:::warning Mistakes to watch out for
- **Missing or double-counting a result.** A lot of students slip here. Counting $2$ heads in the list H, T, T, H, H is wrong, because one H was missed. There are $3$ heads. Tick each result as you count it.
- **A total that does not match the trials.** If you get $6+5=11$ but only $10$ tosses were made, something was counted twice. Count again until the total is $10$.
- **Mixing up the number of times with the name of the event.** When asked which side came up most, answering "$6$" is not right, because $6$ is a count and the question asks for a side. The answer is heads, $6$ times.
:::

## Summary

- Each toss, pick or roll is one trial; its result is an event.
- To find how many times an event happens, count its results.
- Tally marks: one mark each time; every $5$ marks make a group.
- The times for all events add up to the number of trials.
- If you know the total and the times for one event, subtract to find the other.
Back to Nam's coin: by counting carefully, we find that heads came up six times and tails four times, and the total matches the tosses. Always check the total, then try the practice questions.

## Practice

Every exercise has the key idea and a hint to get you started. Have a go on your own first, use the hint if you get stuck, and open the solution last to check.

:::exercise
A coin is tossed $8$ times: H, H, T, H, T, T, H, H. How many times does each side come up?

::hint
**What you need:** count each side, then check that the total is $8$.

**Steps:**
1. Count the Hs.
2. Count the Ts.
3. Add them to see if you get $8$.

::solution
We count each side in the list of results H, H, T, H, T, T, H, H.

- Heads (H) came up on tosses $1$, $2$, $4$, $7$, $8$, which is $5$ times.
- Tails (T) came up on tosses $3$, $5$, $6$, which is $3$ times.

Check: $5+3=8$, which is exactly the number of tosses.

So heads came up $5$ times and tails came up $3$ times.

**Answer.** Heads $5$ times, tails $3$ times.
:::

:::exercise
A card is picked from three kinds of card A, B and C and put back, $10$ times: A, B, A, C, A, B, A, A, C, B. How many times was each kind picked?

::hint
**What you need:** count each kind of card in turn.

**Steps:**
1. Count the As, then the Bs, then the Cs.
2. Check the total is $10$.

::solution
We count each kind of card in the list A, B, A, C, A, B, A, A, C, B.

- Card A was picked on draws $1$, $3$, $5$, $7$, $8$, which is $5$ times.
- Card B was picked on draws $2$, $6$, $10$, which is $3$ times.
- Card C was picked on draws $4$, $9$, which is $2$ times.

Check: $5+3+2=10$, which is exactly the number of draws.

So card A was picked $5$ times, card B $3$ times and card C $2$ times.

**Answer.** A $5$ times, B $3$ times, C $2$ times.
:::

:::exercise
Remember the lesson on bar charts: a chart shows how many times three faces of a dice came up. The bar for face $1$ is $3$ tall, face $2$ is $5$ tall and face $3$ is $4$ tall. How many rolls were there in all? Which face came up most often?

::hint
**What you need:** the tallest bar is the greatest value; the times add up to the number of rolls.

**Steps:**
1. Read the numbers on top of the three bars.
2. Add the three numbers; find the greatest.

::solution
The height of each bar shows how many times that face came up: face $1$ came up $3$ times, face $2$ came up $5$ times and face $3$ came up $4$ times.

The total number of rolls is the sum of the times the three faces came up:
$$3+5+4=12\ \text{(rolls)}.$$

We compare the numbers $3$, $5$, $4$: the greatest is $5$, which belongs to the tallest bar, the bar for face $2$.

So there were $12$ rolls in all, and face $2$ came up most often ($5$ times).

**Answer.** $12$ rolls; face $2$.
:::

:::exercise
A coin is tossed $20$ times and heads comes up $11$ times. How many times does tails come up?

::hint
**What you need:** the times for heads plus the times for tails equal the number of tosses.

**Steps:**
1. Write a subtraction.
2. Check with an addition.

::solution
Each toss of a coin gives exactly one side: heads or tails. So the number of tails equals the number of tosses minus the number of heads.

The number of times tails comes up is:
$$20-11=9\ \text{(times)}.$$

*Check.* $11+9=20$, which is exactly the number of tosses.

So tails comes up $9$ times.

**Answer.** $9$ times.
:::

:::exercise
Why do the times for the two sides of a coin always add up to the number of tosses? Check with heads $6$ times and tails $4$ times.

::hint
**What you need:** every toss gives exactly one result: heads or tails.

**Steps:**
1. How many sides is each toss counted under?
2. Add $6$ and $4$.

::solution
Each toss of a coin gives only one side: heads or tails, never both. So each toss is counted exactly once, either under heads or under tails.

Therefore, when we add the times for the two sides, every toss has been counted, and the sum equals the number of tosses.

Check with heads $6$ times and tails $4$ times: $6+4=10$, which is exactly the $10$ tosses.

So the times for the two sides always add up to the number of tosses, because each toss has exactly one result.

**Answer.** Because each toss has exactly one result; $6+4=10$.
:::

:::exercise
Lan counted the list R, B, R, R, B and said: "R came up $4$ times and B came up $2$ times." Where did Lan go wrong? Count again.

::hint
**What you need:** the total of the counts must equal the number of trials.

**Steps:**
1. Count how many trials there were.
2. Count each letter again.

::solution
The list R, B, R, R, B has $5$ trials.

Lan said R came up $4$ times and B came up $2$ times, so the total is $4+2=6$. This is more than $5$, so Lan counted one trial twice.

We count again:
- R is in positions $1$, $3$, $4$, which is $3$ times.
- B is in positions $2$, $5$, which is $2$ times.

Check: $3+2=5$, which is exactly the number of trials.

So Lan counted R one time too many; the correct counts are R $3$ times and B $2$ times.

**Answer.** R $3$ times, B $2$ times.
:::

:::exercise
During $30$ minutes outside the school gate, the tally chart of passers-by shows: bicycles $12$, motorbikes $9$, cars $5$, and the rest were people on foot.
a) How many people were on foot?
b) How many motorbikes and cars went past altogether?
c) How many more bicycles than cars were there?

::hint
**What you need:** the question gives $30$ in all; subtract the numbers we know.

**Steps:**
1. Add the bicycles, motorbikes and cars.
2. Subtract from $30$ to find the people on foot.

::solution
The number of people on foot equals the total number passing minus the number of vehicles of all kinds.

a) The number of bicycles, motorbikes and cars is:
$$12+9+5=26.$$
The number of people on foot is:
$$30-26=4\ \text{(people)}.$$
So $4$ people were on foot.

b) The number of motorbikes and cars altogether is:
$$9+5=14.$$
So $14$ motorbikes and cars went past altogether.

c) The number of bicycles more than cars is:
$$12-5=7.$$
So there were $7$ more bicycles than cars.

So $4$ people were on foot; $14$ motorbikes and cars went past altogether; there were $7$ more bicycles than cars.

**Answer.** a) $4$ people; b) $14$; c) $7$ more.
:::

:::exercise Challenge
A dice is rolled $20$ times and the even faces come up $12$ times altogether. Face $2$ came up $5$ times and face $6$ came up $3$ times. How many times did face $4$ come up? How many times did the odd faces come up altogether?

::hint
**What you need:** the even faces are $2$, $4$, $6$; their times add up to $12$.

**Steps:**
1. Find face $4$ by subtracting.
2. The odd faces are $20$ minus the even faces.

::solution
The even faces of a dice are face $2$, face $4$ and face $6$. These three faces came up $12$ times altogether.

The number of times face $4$ came up is:
$$12-5-3=4\ \text{(times)}.$$

Each roll gives one face, either even or odd, so the number of times the odd faces came up equals the number of rolls minus the number of times the even faces came up:
$$20-12=8\ \text{(times)}.$$

*Check.* $5+4+3=12$ and $12+8=20$. Correct.

So face $4$ came up $4$ times, and the odd faces came up $8$ times altogether.

**Answer.** Face $4$ came up $4$ times; the odd faces $8$ times.
:::

## Mini test

::mc TH

B. $4$ times.
C. $16$ times.

::key B
$10-6=4$. Option C adds instead of subtracting.

A. $2$ times.
B. $3$ times.
C. $5$ times.
D. $4$ times.
::key B
R is in tosses $1$, $3$ and $4$, so $3$ times. Option C is the number of trials.

::mc TH
The times for all events always add up to
A. the number of trials.
B. the greatest count.
C. $1$.
D. $0$.
::key A
Each trial gives exactly one result. Option B mixes this up with the greatest value.

A. $26$.
B. $14$.
C. $17$.
D. $12$.
::key A
$12+9+5=26$. Option B leaves out the bicycles, and C leaves out the motorbikes.
