:::goals
- Set out and add numbers with many digits, with regrouping, for example $348\,650\,000+275\,480\,000$.
- Set out and subtract numbers with many digits, with regrouping, including when the number on top has many $0$ digits.
- Check a result with the inverse operation and estimate a result by rounding.
- Solve word problems with addition and subtraction, in one or two steps.
:::

A company (made-up numbers) earned $348\,650\,000$ dong in the first quarter and $275\,480\,000$ dong in the second quarter. How many dong did the company earn in the two quarters altogether?

These numbers have nine digits, but the method is the same as for numbers with fewer digits: set them out with the places lined up and work from right to left. This lesson helps you add and subtract large numbers.

## Adding numbers with many digits

### Let's explore

Set out the sum with digits of the same place in the same column, then add from right to left:

$$\begin{array}{r} 348\,650\,000 \\ +\ 275\,480\,000 \\ \hline 624\,130\,000 \end{array}$$

The first three places on the right (ones, tens, hundreds) and the thousands place all add as $0+0=0$. Ten-thousands: $5+8=13$, write $3$ and regroup $1$. Hundred-thousands: $6+4+1=11$, write $1$ and regroup $1$. Millions: $8+5+1=14$, write $4$ and regroup $1$. Ten-millions: $4+7+1=12$, write $2$ and regroup $1$. Hundred-millions: $3+2+1=6$.

So the company earned $624\,130\,000$ dong in the two quarters.

### How to add

:::theorem Adding numbers with many digits
To add numbers with many digits:
1. Set out the sum: digits of the same place go in the same column.
2. Add from right to left, starting with the ones. If a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
3. Write the answer.
:::

Why regroup? Because $10$ units in one place make $1$ unit in the place on the left, just as with numbers with fewer digits.

We start with an addition that needs no regrouping.

:::example Set out and work out $245\,318+432\,561$
**Solution.** Every column adds to less than $10$, so nothing is regrouped:
$$\begin{array}{r} 245\,318 \\ +\ 432\,561 \\ \hline 677\,879 \end{array}$$
So $245\,318+432\,561=677\,879$.
:::

Now every column needs regrouping.

:::example Set out and work out $468\,957+376\,849$
**Solution.** We add column by column and regroup when a column makes $10$ or more:
$$\begin{array}{r} 468\,957 \\ +\ 376\,849 \\ \hline 845\,806 \end{array}$$
Ones: $7+9=16$, write $6$ and regroup $1$. Tens: $5+4+1=10$, write $0$ and regroup $1$. Hundreds: $9+8+1=18$, write $8$ and regroup $1$. Thousands: $8+6+1=15$, write $5$ and regroup $1$. Ten-thousands: $6+7+1=14$, write $4$ and regroup $1$. Hundred-thousands: $4+3+1=8$.

So $468\,957+376\,849=845\,806$.
:::

The method is the same with eight-digit numbers.

:::example Set out and work out $56\,789\,034+28\,765\,987$
**Solution.** We set out the sum and add:
$$\begin{array}{r} 56\,789\,034 \\ +\ 28\,765\,987 \\ \hline 85\,555\,021 \end{array}$$
Ones: $4+7=11$, write $1$ and regroup $1$. Tens: $3+8+1=12$, write $2$ and regroup $1$. Hundreds: $0+9+1=10$, write $0$ and regroup $1$. Thousands: $9+5+1=15$, write $5$ and regroup $1$. Ten-thousands: $8+6+1=15$, write $5$ and regroup $1$. Hundred-thousands: $7+7+1=15$, write $5$ and regroup $1$. Millions: $6+8+1=15$, write $5$ and regroup $1$. Ten-millions: $5+2+1=8$.

So $56\,789\,034+28\,765\,987=85\,555\,021$.
:::

## Subtracting numbers with many digits

:::theorem Subtracting numbers with many digits
To subtract numbers with many digits:
1. Set out the subtraction: the larger number on top, the smaller number below, digits of the same place in the same column.
2. Subtract from right to left, starting with the ones. If a digit on top is smaller than the digit below it, add $10$ to the digit on top, subtract, write the result and regroup $1$. This $1$ is added to the digit below in the column on the left.
3. Write the answer.
:::

Why regroup $1$? When we add $10$ units to the top number in one place, we have "borrowed" $1$ unit from the place on the left. To keep the difference the same, we pay it back by adding $1$ to the digit below in that column.

We start with a subtraction with regrouping.

:::example Set out and work out $612\,405-287\,936$
**Solution.** We subtract column by column and regroup when the digit on top is smaller:
$$\begin{array}{r} 612\,405 \\ -\ 287\,936 \\ \hline 324\,469 \end{array}$$
Ones: $5$ is less than $6$, so take $15-6=9$, write $9$ and regroup $1$. Tens: $3+1=4$; $0$ is less than $4$, so take $10-4=6$, write $6$ and regroup $1$. Hundreds: $9+1=10$; $4$ is less than $10$, so take $14-10=4$, write $4$ and regroup $1$. Thousands: $7+1=8$; $2$ is less than $8$, so take $12-8=4$, write $4$ and regroup $1$. Ten-thousands: $8+1=9$; $1$ is less than $9$, so take $11-9=2$, write $2$ and regroup $1$. Hundred-thousands: $2+1=3$; $6-3=3$.

So $612\,405-287\,936=324\,469$.
:::

When the number on top has many $0$ digits, we still follow the same rule.

:::example Set out and work out $500\,000-237\,469$
**Solution.** We set out the subtraction and subtract:
$$\begin{array}{r} 500\,000 \\ -\ 237\,469 \\ \hline 262\,531 \end{array}$$
Ones: $0$ is less than $9$, so take $10-9=1$, write $1$ and regroup $1$. Tens: $6+1=7$; take $10-7=3$, write $3$ and regroup $1$. Hundreds: $4+1=5$; take $10-5=5$, write $5$ and regroup $1$. Thousands: $7+1=8$; take $10-8=2$, write $2$ and regroup $1$. Ten-thousands: $3+1=4$; take $10-4=6$, write $6$ and regroup $1$. Hundred-thousands: $2+1=3$; $5-3=2$.

So $500\,000-237\,469=262\,531$.
:::

The method is the same with eight-digit numbers.

:::example Set out and work out $82\,436\,500-36\,789\,750$
**Solution.** We set out the subtraction and subtract:
$$\begin{array}{r} 82\,436\,500 \\ -\ 36\,789\,750 \\ \hline 45\,646\,750 \end{array}$$
Ones: $0-0=0$. Tens: $0$ is less than $5$, so take $10-5=5$, write $5$ and regroup $1$. Hundreds: $7+1=8$; $5$ is less than $8$, so take $15-8=7$, write $7$ and regroup $1$. Thousands: $9+1=10$; $6$ is less than $10$, so take $16-10=6$, write $6$ and regroup $1$. Ten-thousands: $8+1=9$; $3$ is less than $9$, so take $13-9=4$, write $4$ and regroup $1$. Hundred-thousands: $7+1=8$; $4$ is less than $8$, so take $14-8=6$, write $6$ and regroup $1$. Millions: $6+1=7$; $2$ is less than $7$, so take $12-7=5$, write $5$ and regroup $1$. Ten-millions: $3+1=4$; $8-4=4$.

So $82\,436\,500-36\,789\,750=45\,646\,750$.
:::

Finally, a problem that needs addition, subtraction and estimation. We work in four steps: understand, plan, solve, look back.

:::example A sales target
A company (made-up numbers) sets a target of earning $800\,000\,000$ dong in the first six months of the year. In the first quarter the company earns $348\,650\,000$ dong and in the second quarter it earns $275\,480\,000$ dong. How many dong is the company short of the target?

**Understand.** We are given the target of $800\,000\,000$ dong and the money earned in two quarters. We are asked for the amount still missing.

**Plan.** To know how much is missing, we need to know how much has been earned. Step $1$: add the money from the two quarters. Step $2$: subtract the money earned from the target.

**Solve.**

Solution

The money the company earned in the two quarters is:
$$348\,650\,000+275\,480\,000=624\,130\,000\ \text{(dong)}.$$
The money the company is short is:
$$800\,000\,000-624\,130\,000=175\,870\,000\ \text{(dong)}.$$
Answer: $175\,870\,000$ dong.

**Look back.** Estimate by rounding to the nearest ten million: $350\,000\,000+280\,000\,000=630\,000\,000$ and $800\,000\,000-630\,000\,000=170\,000\,000$. The estimate $170\,000\,000$ is close to $175\,870\,000$, so the calculation is right. Also check with addition: $175\,870\,000+624\,130\,000=800\,000\,000$.
:::

**Connection.** Addition and subtraction are still inverse operations: if $a+b=c$ then $c-b=a$. You can use this to check an answer. Estimating by rounding helps you spot answers that are far wrong, for example wrong by a whole place.

:::warning Mistakes to watch out for
- **Forgetting to regroup in an addition.** Wrong: $468\,957+376\,849=734\,796$. Why it is wrong: in each column only the ones digit of the total was written and the $1$ was forgotten. Right: $468\,957+376\,849=845\,806$.
- **Subtracting the smaller digit from the larger in every column.** Wrong: $500\,000-237\,469=337\,469$. Why it is wrong: in each column the larger digit was taken away from the smaller one, even when the smaller digit is on top. Right: $500\,000-237\,469=262\,531$.
- **Numbers not lined up in columns.** Wrong: $234\,567+45\,678=691\,347$. Why it is wrong: $45\,678$ was written one place too far to the left, so $234\,567$ was added to $456\,780$. Right: $234\,567+45\,678=280\,245$.
:::

## Summary

- To add or subtract numbers with many digits, set them out with digits of the same place **in the same column**, then work from right to left.
- Addition with regrouping: if a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
- Subtraction with regrouping: if the digit on top is smaller, add $10$ to it, subtract, write the result and add $1$ to the digit below in the column on the left.
- Check with the inverse operation: if $a+b=c$ then $c-b=a$. Estimate by rounding to check the result.

Set out in columns and work out: $387\,659+549\,874$.

::hint
**What you need:** if a column makes $10$ or more, regroup $1$ into the column on the left.

**Steps:**
1. Set out the sum with the places lined up.
2. Add column by column, regrouping when needed.

::solution
$$\begin{array}{r} 387\,659 \\ +\ 549\,874 \\ \hline 937\,533 \end{array}$$
Ones: $9+4=13$, write $3$ and regroup $1$. Tens: $5+7+1=13$, write $3$ and regroup $1$. Hundreds: $6+8+1=15$, write $5$ and regroup $1$. Thousands: $7+9+1=17$, write $7$ and regroup $1$. Ten-thousands: $8+4+1=13$, write $3$ and regroup $1$. Hundred-thousands: $3+5+1=9$.

**Answer.** $937\,533$.

:::exercise
Set out in columns and work out: $800\,000-345\,678$.

::hint
**What you need:** $0$ is less than $8$, so take $10$ minus $8$, then regroup $1$ into the tens column.

**Steps:**
1. Set out the subtraction with the places lined up.
2. In each column, add the regrouped $1$ to the digit below before you subtract.

::solution
$$\begin{array}{r} 800\,000 \\ -\ 345\,678 \\ \hline 454\,322 \end{array}$$
Ones: $10-8=2$, write $2$ and regroup $1$. Tens: $7+1=8$; $10-8=2$, write $2$ and regroup $1$. Hundreds: $6+1=7$; $10-7=3$, write $3$ and regroup $1$. Thousands: $5+1=6$; $10-6=4$, write $4$ and regroup $1$. Ten-thousands: $4+1=5$; $10-5=5$, write $5$ and regroup $1$. Hundred-thousands: $3+1=4$; $8-4=4$.

**Answer.** $454\,322$.
:::

:::exercise
Remember the lesson on rounding numbers. Work out $468\,957+376\,849$, then round the sum to the nearest hundred thousand.

::hint
**What you need:** to round to the nearest hundred thousand, look at the ten-thousands digit.

**Steps:**
1. Work out the sum $468\,957+376\,849$.
2. Look at the ten-thousands digit and round.

::solution
We have $468\,957+376\,849=845\,806$. The hundred-thousands digit is $8$ and the ten-thousands digit is $4$. Since $4<5$, keep $8$ and replace the digits to its right with $0$.

**Answer.** $845\,806$, which rounds to $800\,000$.
:::

:::exercise

Find the difference between the largest and the smallest six-digit number whose digits are all different.

**Steps:**

::solution
