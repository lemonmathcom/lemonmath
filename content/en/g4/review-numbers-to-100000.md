:::goals
- Read and write numbers up to $100\,000$ and give the value of each digit.
- Write a number as a sum of its places.
- Compare and order numbers up to $100\,000$.
:::

Our school library has $36\,407$ books. How do you read this number? What is the value of the digit $6$? The library of the next school has $36\,470$ books. Which school has more books?

You learned these numbers in Grade 3. This lesson helps you remember them well before we meet bigger numbers.

## Let's explore

Each digit in a number has a **place**. For the number $36\,407$, read from left to right:

| Place | Ten thousands | Thousands | Hundreds | Tens | Ones |
|---|---|---|---|---|---|
| Digit | $3$ | $6$ | $4$ | $0$ | $7$ |
| Value | $30\,000$ | $6\,000$ | $400$ | $0$ | $7$ |

Add the values and you get the number back:
$$36\,407=30\,000+6\,000+400+0+7.$$

So the digit $6$ is in the thousands place and has value $6\,000$. We read the number as: **thirty-six thousand, four hundred and seven**. The tens digit is $0$, so we say "and seven" with no tens.

Now compare $36\,407$ and $36\,470$. Both have $5$ digits. The ten thousands, thousands and hundreds digits are the same ($3$, $6$, $4$). In the tens place we have $0$ and $7$. Since $0<7$, we get $36\,407<36\,470$. The next school has more books.

:::theorem Reading, writing and comparing numbers
- **Reading and writing:** read from the highest place to the lowest. Say "thousand" after the ten thousands and thousands part. If a place in the middle is $0$, skip it when reading, but write $0$ when writing.
- **Comparing:** the number with more digits is greater. If two numbers have the same number of digits, compare place by place from the highest place; the first place where they differ decides, and the bigger digit gives the bigger number.
:::

This works because higher places are worth much more: $1$ ten thousand is $10\,000$, which is more than all the other four places can make together.

## Examples

We start by reading and partitioning a number.

:::example Reading a number
Read the number $52\,019$ and give the digit in each place.

**Solution.** We look at each place, from left to right:

| Place | Ten thousands | Thousands | Hundreds | Tens | Ones |
|---|---|---|---|---|---|
| Digit | $5$ | $2$ | $0$ | $1$ | $9$ |

The hundreds digit is $0$, so we skip hundreds. So $52\,019$ is read: **fifty-two thousand and nineteen**.
:::

From the places, we can write a number as a sum.

:::example Writing as a sum
Write $84\,350$ as a sum of its places.

**Solution.** Each digit has a value given by its place. The ones digit is $0$, so we do not write it:
$$84\,350=80\,000+4\,000+300+50.$$

So $84\,350=80\,000+4\,000+300+50$.
:::

Next we compare two numbers.

:::example Comparing numbers
Compare: a) $45\,678$ and $45\,687$; b) $9\,999$ and $10\,000$.

**Solution.** a) Both numbers have $5$ digits. Compare place by place from the left: $4=4$, $5=5$, $6=6$. In the tens place: $7<8$. So $45\,678<45\,687$.

b) $9\,999$ has $4$ digits and $10\,000$ has $5$ digits. The number with more digits is greater. So $9\,999<10\,000$.
:::

With several numbers, we compare them one by one and then put them in order.

:::example Ordering numbers
Put the numbers $23\,540$; $32\,450$; $23\,450$; $9\,999$ in order from least to greatest.

**Solution.** $9\,999$ has $4$ digits, so it is the least. The other three have $5$ digits. Their ten thousands digits are $2$, $3$, $2$, so $32\,450$ is the greatest. The numbers $23\,540$ and $23\,450$ have the same ten thousands and thousands digits; in the hundreds place $5>4$, so $23\,540>23\,450$.

So the order from least to greatest is: $9\,999$; $23\,450$; $23\,540$; $32\,450$.
:::

Finally, the number before and the number after.

:::example The number before and after
Find the number after $69\,999$ and the number before $40\,000$.

**Solution.** The number after is $1$ more, and the number before is $1$ less:
$$69\,999+1=70\,000,\qquad 40\,000-1=39\,999.$$

So the number after $69\,999$ is $70\,000$, and the number before $40\,000$ is $39\,999$.
:::

:::warning Mistakes to watch out for
- **Dropping a zero when reading.** Wrong: reading $30\,502$ as "thirty thousand, five hundred and twenty". Why it is wrong: that is $30\,520$. Right: "thirty thousand, five hundred and two".
- **Comparing when the numbers of digits differ.** Wrong: $9\,999>10\,000$ because $9>1$. Why it is wrong: $10\,000$ has more digits. Right: $9\,999<10\,000$.
- **Mixing up a digit and its value.** Wrong: the digit $6$ in $46\,280$ has value $6$. Why it is wrong: the $6$ is in the thousands place. Right: its value is $6\,000$.
:::

## Summary

- A $5$-digit number has these places: ten thousands, thousands, hundreds, tens, ones.
- Each digit has a value given by its place: $36\,407=30\,000+6\,000+400+7$.
- Read from the highest place to the lowest; a middle $0$ is written but not read.
- Comparing: more digits means greater; with the same number of digits, compare place by place from the highest place.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Read the number $41\,305$.

::hint
**What you need:** read from the highest place to the lowest; a tens digit of $0$ is not read.

**Steps:**
1. Write the digit in each place.
2. Say "forty-one thousand", then read the rest.

::solution
The digits: ten thousands $4$, thousands $1$, hundreds $3$, tens $0$, ones $5$.

**Answer.** Forty-one thousand, three hundred and five.
:::

:::exercise
Write these numbers:
a) Sixty thousand, two hundred and ten.
b) Twenty-three thousand and eight.

::hint
**What you need:** write each place from the highest to the lowest; write $0$ in any place that is missing.

**Steps:**
1. Part a): $60\,000$, $200$, $10$.
2. Part b): $23\,000$ and $8$; the hundreds and tens are $0$.

::solution
a) $60\,000+200+10=60\,210$.

b) $23\,000+8=23\,008$.

**Answer.** a) $60\,210$. b) $23\,008$.
:::

:::exercise
Write $70\,605$ as a sum of its places.

::hint
**What you need:** each digit has a value given by its place.

**Steps:**
1. Write the digit in each place.
2. Leave out the places with digit $0$.

::solution
The digits: $7$ ten thousands, $0$ thousands, $6$ hundreds, $0$ tens, $5$ ones. So $70\,605=70\,000+600+5$.

**Answer.** $70\,000+600+5$.
:::

:::exercise
Look at the number $58\,142$. Give the value of the digit $5$, the digit $8$ and the digit $4$.

::hint
**What you need:** the value of a digit depends on its place.

**Steps:**
1. In which place is the digit $5$?
2. Do the same for the digits $8$ and $4$.

::solution
The digit $5$ is in the ten thousands place: value $50\,000$. The digit $8$ is in the thousands place: value $8\,000$. The digit $4$ is in the tens place: value $40$.

**Answer.** $50\,000$; $8\,000$; $40$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box and give a reason:
a) $48\,215\;\square\;48\,251$.
b) $70\,000\;\square\;69\,999$.
c) $12\,345\;\square\;12\,345$.

::hint
**What you need:** more digits means greater; with the same number of digits, compare place by place from the highest place.

**Steps:**
1. Count the digits in each number.
2. Find the first place where the digits differ.

::solution
a) Both have $5$ digits; in the tens place $1<5$. So $48\,215<48\,251$.

b) Both have $5$ digits; in the ten thousands place $7>6$. So $70\,000>69\,999$.

c) The numbers are exactly the same, so they are equal.

**Answer.** a) $<$. b) $>$. c) $=$.
:::

:::exercise
Ha did the two tasks below. Where did Ha go wrong? Correct them.
a) Ha read $30\,502$ as "thirty thousand, five hundred and twenty".
b) Ha said $9\,999>10\,000$ because $9>1$.

::hint
**What you need:** a tens digit of $0$ is not read; the number with more digits is greater.

**Steps:**
1. Part a): how do you write "thirty thousand, five hundred and twenty"?
2. Part b): count the digits in the two numbers.

::solution
a) "Thirty thousand, five hundred and twenty" is $30\,520$. The number $30\,502$ has tens digit $0$, so it is read "thirty thousand, five hundred and two".

b) $9\,999$ has $4$ digits and $10\,000$ has $5$ digits, so $9\,999<10\,000$. Ha must not compare just the first digits when the numbers of digits differ.

**Answer.** a) Thirty thousand, five hundred and two. b) $9\,999<10\,000$.
:::

:::exercise
Three libraries have $24\,300$; $8\,900$; and $24\,030$ books. Put them in order from least to greatest and say which library has the most books.

::hint
**What you need:** more digits means greater; with the same number of digits, compare place by place from the highest place.

**Steps:**
1. Which number has the fewest digits?
2. Compare the other two from the ten thousands place.

::solution
$8\,900$ has $4$ digits, so it is the least. The other two both have $5$ digits and share the ten thousands and thousands digits. In the hundreds place $0<3$, so $24\,030<24\,300$.

**Answer.** $8\,900<24\,030<24\,300$; the library with $24\,300$ books has the most.
:::

:::exercise Challenge
Using the digits $0$, $3$, $5$, $7$, $9$ (each digit used exactly once), make the greatest $5$-digit number and the least $5$-digit number.

::hint
**What you need:** for the greatest number, put big digits in high places; $0$ cannot be the first digit of a $5$-digit number.

**Steps:**
1. Arrange the digits from biggest to smallest for the greatest number.
2. Arrange from smallest to biggest, but the first digit must not be $0$.

::solution
Greatest: $97\,530$. Least: the first digit is the smallest digit that is not $0$, which is $3$; the other digits go from least to greatest: $0$, $5$, $7$, $9$. This gives $30\,579$.

**Answer.** Greatest $97\,530$; least $30\,579$.
:::

## Mini test

:::quiz
::mc
The number "thirty thousand, two hundred and five" is written
A. $30\,250$.
B. $30\,205$.
C. $3\,205$.
D. $30\,025$.
::key B
$30\,000+200+5=30\,205$. Option A is $30\,250$ (the tens digit is $5$), and option D is $30\,025$.

::mc
The digit $6$ in the number $46\,280$ has the value
A. $6$.
B. $60$.
C. $6\,000$.
D. $60\,000$.
::key C
The digit $6$ is in the thousands place, so its value is $6\,000$.

::mc
Which is the greatest of these numbers?
A. $39\,999$.
B. $40\,001$.
C. $9\,999$.
D. $40\,000$.
::key B
$9\,999$ has $4$ digits, so it is the least. The other three have $5$ digits; the ten thousands digit of $39\,999$ is $3$, so it is smaller. For $40\,001$ and $40\,000$, the ones digit $1>0$.

::mc
The number after $79\,999$ is
A. $80\,000$.
B. $79\,998$.
C. $70\,000$.
D. $89\,999$.
::key A
$79\,999+1=80\,000$. Option B is the number before.

::tf
Look at the number $52\,019$.
a) It is read "fifty-two thousand and nineteen".
b) The digit $0$ is in the hundreds place.
c) $52\,019=50\,000+2\,000+100+9$.
d) $52\,019<52\,109$.
::key T T F T
a) True. b) True: the hundreds digit is $0$. c) False: the correct sum is $50\,000+2\,000+10+9$. d) True: in the hundreds place $0<1$.

::sa
Which digit is in the thousands place of $73\,456$?
::key 3
The places: ten thousands $7$, thousands $3$, hundreds $4$, tens $5$, ones $6$.

::sa
What is the greatest $4$-digit number with all digits different?
::key 9876
Arrange different digits from biggest to smallest: $9$, $8$, $7$, $6$.
:::
