:::goals
- Know what a list of statistical data is and read one from a table.
- Count the values, find the greatest and the least, and put a list in order from smallest to largest.
- Count how many times a value appears and compare values by subtracting.
:::

The teacher asks six children in your group how many story books they read this month. Mai read $5$, Nam read $3$, Ha read $7$, Binh read $4$, Lan read $6$ and Tu read $3$. Who read the most? Who read the fewest?

The numbers $5, 3, 7, 4, 6, 3$ are information we collected. This lesson shows you how to read and compare them.

## Let's explore

First we write the information in a table.

| Child | Mai | Nam | Ha | Binh | Lan | Tu |
|---|---|---|---|---|---|---|
| Books read | $5$ | $3$ | $7$ | $4$ | $6$ | $3$ |

Taking only the row of numbers gives a list: $5, 3, 7, 4, 6, 3$. Answer some small questions:

- How many numbers are there? Count each one: there are $6$, one for each child.
- Which is the greatest? Compare them: $7$ is the greatest, and that is Ha.
- Which is the least? $3$ is the least, and that is Nam and Tu.
- In order from smallest to largest: $3, 3, 4, 5, 6, 7$. Notice that $3$ appears twice, so we write it twice.

:::definition A list of statistical data
The numbers we collect about the same thing (for example the number of books, or heights) are called **data values**. Data values written in a row make a **list of statistical data**. Each child or each measurement gives one value, so the number of values equals the number of children or measurements.
:::

When you read a list of data, always do three things: count how many values there are, find the greatest and the least, then answer the question.

## Examples

We start with a short list.

:::example Goals scored
Our class football team scored these numbers of goals in $7$ matches: $2, 0, 3, 1, 3, 2, 4$. a) How many matches did the team play? b) What is the most goals in one match? c) In how many matches did the team score exactly $2$ goals?

**Solution.** Each number is one match. We count the numbers, find the greatest and count the $2$s:

a) There are $7$ numbers, so the team played $7$ matches.

b) The greatest number is $4$, so the most goals in a match is $4$.

c) The number $2$ appears in the first and the sixth match, so there are $2$ matches.
:::

Now we put the values in order and compare them.

:::example Heights
The heights (cm) of $5$ children are: $132, 128, 135, 130, 128$. Put them in order from smallest to largest, then find how many centimetres taller the tallest child is than the shortest.

**Solution.** Find the least, then write the numbers getting larger, each one as many times as it appears:
$$128,\ 128,\ 130,\ 132,\ 135.$$
The greatest is $135$ and the least is $128$. To find how much more, we subtract:
$$135-128=7\ \text{(cm)}.$$
So the tallest child is $7$ cm taller than the shortest.
:::

Data often comes in a table. We read the table and carry on.

:::example Class sizes
The table shows the number of pupils in each Year 4 class:

| Class | 4A | 4B | 4C | 4D |
|---|---|---|---|---|
| Pupils | $32$ | $30$ | $34$ | $32$ |

Which class is the biggest? How many pupils are there in all?

**Solution.** The list of data is $32, 30, 34, 32$. The greatest is $34$, for class $4$C. The total number of pupils is:
$$32+30+34+32=128\ \text{(pupils)}.$$
So class $4$C is the biggest, and there are $128$ pupils in all.
:::

Finally, we count how many times a value appears.

:::example How many times a value appears
Here is a list of data: $6, 9, 4, 9, 7$. How many values are there? Which value appears most often?

**Solution.** Count the numbers, including repeats: $6, 9, 4, 9, 7$ has $5$ numbers. The number $9$ appears $2$ times and the others only $1$ time. So there are $5$ values and $9$ appears most often.

**Check.** Add up the counts: $1+2+1+1=5$. This matches the $5$ values.
:::

:::warning Mistakes to watch out for
- **Leaving out repeats.** Wrong: the list $6, 9, 4, 9, 7$ has $4$ numbers. Why it is wrong: each child or measurement gives one number, and $9$ appears twice so we count it twice. Right: $5$ numbers.
- **Mixing up the greatest with the most common.** Wrong: in $3, 8, 3, 5$ the most common value is $8$. Why it is wrong: $8$ is only the greatest, and $3$ appears twice. Right: the number $3$.
- **Losing repeats when putting in order.** Wrong: writing $7, 3, 9, 3$ as $3, 7, 9$. Why it is wrong: the new list is missing one $3$. Right: $3, 3, 7, 9$.
:::

## Summary

- Data values are numbers we collect; written in a row they make a list of statistical data.
- Each child or measurement gives one value; repeated values are still counted every time.
- Find the greatest and the least by comparing each number.
- To put in order from smallest to largest, write every number, repeats included.
- Compare two values by subtracting: $\text{greater}-\text{smaller}$.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Here is a list of data: $4, 8, 6, 9, 5$. How many numbers are there? Which is the greatest and which is the least?

::hint
**What you need:** count each number; compare to find the greatest and the least.

**Steps:**
1. Count the numbers.
2. Compare the numbers with each other.

::solution
There are $5$ numbers. The greatest is $9$ and the least is $4$.

**Answer.** $5$ numbers; greatest $9$; least $4$.
:::

:::exercise
Put the data $15, 9, 12, 20, 9$ in order from smallest to largest.

::hint
**What you need:** write every number, repeats included.

**Steps:**
1. Find the least number.
2. Write the numbers getting larger.

::solution
The least is $9$, which appears twice. The ordered list is $9, 9, 12, 15, 20$.

**Answer.** $9, 9, 12, 15, 20$.
:::

:::exercise
Remember the last lesson (the unitary method): $5$ boxes of pens hold $30$ pens. How many pens are in each box? Write the list of pens in $1$, $2$, $3$ and $4$ boxes.

::hint
**What you need:** go down to one box; the pens in several boxes equal the pens in one box times the number of boxes.

**Steps:**
1. Divide $30$ by $5$.
2. Multiply the result by $1$, $2$, $3$ and $4$.

::solution
One box holds $30\div5=6$ (pens). The pens in $1$, $2$, $3$, $4$ boxes are $6, 12, 18, 24$.

**Answer.** $6$ pens in each box; the list is $6, 12, 18, 24$.
:::

:::exercise
The test scores of $6$ children are: $8, 9, 7, 10, 9, 8$.
a) How many children scored $9$?
b) How many points higher is the top score than the lowest score?
c) How many children scored $9$ or more?

::hint
**What you need:** count how many times a value appears; compare by subtracting.

**Steps:**
1. Count the $9$s in the list.
2. Find the greatest and least, then subtract.
3. Count the $9$s and the $10$s.

::solution
a) The number $9$ appears $2$ times. b) $10-7=3$ (points). c) There are two $9$s and one $10$, so $3$ children.

**Answer.** a) $2$ children; b) $3$ points; c) $3$ children.
:::

:::exercise
Here is a list of data: $3, 8, 3, 5, 3, 8$. Are the greatest value and the most common value the same number? Why?

::hint
**What you need:** the greatest value is the biggest number; the most common value is the one that appears most times.

**Steps:**
1. Find the greatest value.
2. Count how many times each number appears.

::solution
The greatest value is $8$ (it appears $2$ times). The number $3$ appears $3$ times, more than $8$. So they are different numbers.

**Answer.** No: the greatest is $8$ and the most common is $3$.
:::

:::exercise
Ha wrote: "The list $5, 9, 3, 7, 9$ has $4$ numbers because we count $9$ only once; the least is $5$." Where did Ha go wrong? Do it correctly.

::hint
**What you need:** repeated numbers are still counted every time; the least is the smallest number in the list.

**Steps:**
1. Count the numbers again.
2. Compare all the numbers to find the least.

::solution
The list has $5$ numbers because $9$ appears twice and must be counted twice. The least is $3$, not $5$.

**Answer.** $5$ numbers; the least is $3$.
:::

:::exercise
Six children enter a skipping contest. Number of skips: An $24$, Binh $31$, Chi $28$, Dung $31$, Em $25$, Giang $30$.
a) Write the list of data and say which value is the greatest.
b) Put them in order from smallest to largest.
c) How many more skips did the best child make than the lowest?

::hint
**What you need:** read the data from the question, put it in order, then subtract.

**Steps:**
1. Write the numbers in the order given.
2. Put all six numbers in order.
3. Subtract the least from the greatest.

::solution
a) The list is $24, 31, 28, 31, 25, 30$; the greatest is $31$ (Binh and Dung). b) $24, 25, 28, 30, 31, 31$. c) $31-24=7$ (skips).

**Answer.** a) $31$; b) $24, 25, 28, 30, 31, 31$; c) $7$ skips.
:::

:::exercise Challenge
A list has $5$ numbers: $6, 9, ?, 4, 9$. The least is $4$, the greatest is $9$, and the number $9$ appears exactly $2$ times. What numbers could $?$ be?

::hint
**What you need:** $?$ is not less than $4$, not more than $9$, and not equal to $9$.

**Steps:**
1. Why can $?$ not be less than $4$?
2. Why can $?$ not be equal to $9$?
3. List the numbers that are left.

::solution
If $?<4$, the least would no longer be $4$. If $?>9$, the greatest would no longer be $9$. If $?=9$, the number $9$ would appear $3$ times. So $?$ is a whole number from $4$ to $8$.

**Check.** With $?=6$: the list $6, 9, 6, 4, 9$ has least $4$, greatest $9$, and $9$ appears $2$ times. Correct.

**Answer.** $4, 5, 6, 7, 8$.
:::

## Mini test

:::quiz
::mc
How many numbers are in the list $4, 9, 6, 9, 3$?
A. $4$.
B. $5$.
C. $3$.
D. $9$.
::key B
There are $5$ numbers, each counted once, repeats included. Option A is the mistake of counting $9$ only once.

::mc
The greatest number in the list $12, 8, 15, 9$ is
A. $8$.
B. $12$.
C. $15$.
D. $9$.
::key C
Comparing the numbers, $15$ is the greatest. Option B is the mistake of picking the first number.

::mc
Putting $7, 3, 9, 3$ in order from smallest to largest gives
A. $3, 3, 7, 9$.
B. $9, 7, 3, 3$.
C. $3, 7, 9, 3$.
D. $3, 7, 9$.
::key A
Both $3$s must be written. Option D leaves out one $3$, and B puts them largest first.

::mc
The temperatures on five days are $24, 27, 22, 27, 25$ (degrees). How many degrees warmer is the warmest than the coolest?
A. $5$ degrees.
B. $3$ degrees.
C. $27$ degrees.
D. $2$ degrees.
::key A
$27-22=5$. Option B uses $27-24$ because it misses the least number, and C is only the greatest number.

::tf
Look at the list of data $6, 2, 8, 2, 5, 2$.
a) The list has $6$ numbers.
b) The greatest number is $8$.
c) The number $2$ appears $2$ times.
d) In order from smallest to largest it is $2, 2, 2, 5, 6, 8$.
::key T T F T
a) True: count all six. b) True: $8$ is the greatest. c) False: $2$ appears $3$ times. d) True: all three $2$s are written.

::sa
Here is the list $15, 9, 12, 20, 9$. How much greater is the greatest number than the least?
::key 11
$20-9=11$.

::sa
How many times does $7$ appear in the list $7, 3, 7, 5, 7, 4$?
::key 3
The number $7$ is in the first, third and fifth places, so $3$ times.
:::
