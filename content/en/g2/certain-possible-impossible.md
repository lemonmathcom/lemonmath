description: Learn to tell whether an event is certain, possible or impossible by looking at the marbles in a box and the sections of a spinner.

:::goals
- Use the words "certain", "possible" and "impossible" to talk about an event.
- Look at the marbles in a box to decide whether an event is certain, possible or impossible.
- Compare which event is more likely to happen.
- Give a reason for your answer.
:::

A box holds $4$ red marbles and $6$ blue marbles. You close your eyes, put your hand in the box and take out $1$ marble. What colour is it? Are you sure it is red? Are you sure it is blue? Could you ever pick a yellow one?

You do not know for sure which marble you will pick, but you can still say what is certain to happen and what can never happen. This lesson shows you how.

## Let's explore

There are three boxes. Each time, you close your eyes and take out $1$ marble.

- Box A has $5$ red marbles. What about picking a red marble? The box holds only red marbles, so you pick a red marble every time.
- Box B has $3$ red marbles and $2$ blue marbles. You could pick a red marble, and you could also pick a blue one.
- Box C has $4$ blue marbles. There is no red marble in the box, so you can never pick a red one.

So for the event "picking a red marble": in box A it is **certain**, in box B it is **possible**, in box C it is **impossible**.

:::theorem Certain, possible, impossible
- An event is **certain** if it happens every time.
- An event is **possible** if it sometimes happens and sometimes does not.
- An event is **impossible** if it never happens.
:::

Why do you not need to try many times? Because you only need to look at what is in the box. If every marble is red, you pick red every time; if there is no red marble, you never pick red; if there are both kinds, the result can differ.

Be careful: "possible" does not mean "certain". Box B has red marbles, but you could still pick a blue one.

## Examples

We start with a box that holds only one kind of marble.

:::example A box of yellow marbles
A box holds $8$ yellow marbles. You take out $1$ marble. Is each event below certain, possible or impossible?
a) You pick a yellow marble.
b) You pick a red marble.

**Solution.** The box holds only yellow marbles.

a) You pick a yellow marble every time, so this event is **certain**.

b) There is no red marble in the box, so this event is **impossible**.
:::

Now look at number cards.

:::example Picking a number card
A box holds $4$ cards with the numbers $1$, $2$, $3$, $4$. You pick $1$ card. Is each event below certain, possible or impossible?
a) You pick the card with the number $5$.
b) You pick a card with a number less than $5$.
c) You pick a card with an even number.

**Solution.** a) There is no card with $5$ in the box, so this event is **impossible**.

b) All four cards $1$, $2$, $3$, $4$ are less than $5$, so this event is **certain**.

c) The cards $2$ and $4$ are even, but the cards $1$ and $3$ are not, so this event is **possible**.
:::

These words also work for everyday things.

:::example An everyday day
Today is Monday. Is each event below certain, possible or impossible?
a) Tomorrow is Tuesday.
b) It rains tomorrow afternoon.
c) You grow wings and fly into the sky.

**Solution.** a) Tuesday always comes after Monday, so this event is **certain**.

b) Some days it rains and some days it does not, so this event is **possible**.

c) People do not have wings to fly, so this event is **impossible**.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example An's box of marbles
An's box holds $7$ red marbles and $3$ blue marbles. An takes out $1$ marble. Is picking a blue marble certain, possible or impossible? Which colour is easier to pick? What must An do to make picking a blue marble certain?

**Understand.** The box has $7$ red marbles and $3$ blue marbles. We are asked about the kind of event "picking blue", which colour is easier to pick, and how to make picking blue certain.

**Plan.** Look at which kinds of marble are in the box, then compare how many there are of each kind.

**Solve.** The box holds both blue and red marbles, so picking a blue marble is **possible**. Since $7>3$, picking red is easier than picking blue.

To make picking a blue marble certain, the box must hold only blue marbles. So An must take all $7$ red marbles out of the box.

**Look back.** If An puts $5$ more blue marbles into the box, is picking a blue marble certain? Try to answer it yourself.
:::

:::warning Mistakes to watch out for
- **Mixing up "possible" and "certain".** Wrong: a box has $3$ red marbles and $2$ blue marbles, so "you are certain to pick a red one". Why it is wrong: you could still pick a blue one. Right: picking a red marble is possible.
- **Forgetting to look at all the marbles in the box.** Wrong: a box has $3$ red marbles and $2$ blue marbles, and you say "picking a blue marble is impossible". Why it is wrong: the box holds blue marbles. Right: picking a blue marble is possible.
- **Not using the three words you have learned.** Wrong: "Picking red: yes". Right: "Picking red: possible".
:::

**Connection.** This lesson is the start of probability in later years, where these three words are replaced by numbers.

## Summary

- Certain means it happens every time; impossible means it never happens; possible means it sometimes happens and sometimes does not.
- To decide which kind an event is, look at what is in the box (or on the spinner).
- "Possible" does not mean "certain".
- The kind with more is more likely to happen; always give a reason.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
A box holds $6$ blue marbles. You take out $1$ marble. Say whether each event is certain, possible or impossible: a) you pick a blue marble; b) you pick a red marble.

::hint
**What you need:** look at which kinds of marble are in the box.

**Steps:**
1. What colour are the marbles in the box?

::solution
The box holds only blue marbles.

a) You pick a blue marble every time, so this event is certain.

b) There is no red marble in the box, so this event is impossible.

**Answer.** a) certain; b) impossible.
:::

:::exercise
A box holds $4$ red marbles and $4$ blue marbles. You take out $1$ marble. Say whether each event is certain, possible or impossible: a) you pick a red marble; b) you pick a blue marble; c) you pick a yellow marble.

::hint
**What you need:** if the box holds both kinds, either kind could be picked.

**Steps:**
1. Which kinds of marble are in the box?

::solution
The box holds both red and blue marbles, but no yellow marbles.

a) Picking a red marble is possible. b) Picking a blue marble is possible. c) Picking a yellow marble is impossible.

**Answer.** a) possible; b) possible; c) impossible.
:::

:::exercise
A box holds $5$ cards with the numbers $1$, $2$, $3$, $4$, $5$. You pick $1$ card. Say whether each event is certain, possible or impossible: a) you pick the card with the number $6$; b) you pick a card with a number less than $6$; c) you pick a card with an odd number.

::hint
**What you need:** compare each card with the condition of the event.

**Steps:**
1. Is there a card with $6$?

::solution
a) There is no card with $6$, so this event is impossible.

b) All five cards are less than $6$, so this event is certain.

c) The cards $1$, $3$, $5$ are odd, but $2$ and $4$ are not, so this event is possible.

**Answer.** a) impossible; b) certain; c) possible.
:::

:::exercise
Today is Friday. Say whether each event is certain, possible or impossible: a) tomorrow is Saturday; b) it rains this afternoon; c) you count from $1$ to $10$ and say the number $11$.

::hint
**What you need:** which things are always true, which are sometimes true, which are never true?

**Steps:**
1. Which day comes after Friday?

::solution
a) Saturday always comes after Friday, so this event is certain.

b) Some days it rains and some days it does not, so this event is possible.

c) There is no number $11$ from $1$ to $10$, so this event is impossible.

**Answer.** a) certain; b) possible; c) impossible.
:::

:::exercise
A spinner is divided into $8$ equal sections: $5$ red and $3$ blue. You spin it and the pointer stops on one section. Say whether each event is certain, possible or impossible: a) the pointer stops on red or blue; b) the pointer stops on yellow. c) Which is more likely, red or blue?

::hint
**What you need:** see which colours are on the spinner and how many sections each colour has.

**Steps:**
1. What colour is every section of the spinner?

::solution
a) Every section is red or blue, so this event is certain.

b) The spinner has no yellow section, so this event is impossible.

c) Since $5>3$, the pointer is more likely to stop on red.

**Answer.** a) certain; b) impossible; c) red.
:::

:::exercise
Remember the lesson on tallying. Mai tallies the marbles in a box: red $\cancel{\mid\mid\mid\mid}\ \mid\mid$, blue $\cancel{\mid\mid\mid\mid}$. How many marbles are in the box altogether? You take out $1$ marble: can you pick a yellow one? Which colour is easier to pick?

::hint
**What you need:** each crossed group is $5$ marbles; add the groups to find the total.

**Steps:**
1. Count the red marbles and the blue marbles.

::solution
Red marbles: $5+2=7$. Blue marbles: $5$.

The number of marbles in the box is:
$$7+5=12\ \text{(marbles)}.$$
There is no yellow marble, so picking a yellow marble is impossible. Since $7>5$, red is easier to pick.

**Answer.** $12$ marbles; impossible; red.
:::

:::exercise
A box holds $3$ red marbles and $2$ blue marbles. What must you do so that picking $1$ marble is certain to give a red one?

::hint
**What you need:** an event is certain when every marble in the box fits it.

**Steps:**
1. To be certain of picking red, which marbles can the box hold?

::solution
To make picking a red marble certain, the box must hold only red marbles. So take the $2$ blue marbles out of the box.

**Answer.** Take the $2$ blue marbles out of the box.
:::

:::exercise Challenge
Lan wants to put marbles into a box so that, when $1$ marble is taken out: picking a red one is possible, picking a blue one is possible, and picking a yellow one is impossible. What is the least number of marbles in Lan's box?

::hint
**What you need:** "possible" means the box holds that kind of marble.

**Steps:**
1. Which kinds of marble must the box hold? Which kind must it not hold?

::solution
The box must hold red and blue marbles but no yellow marbles. Each kind needs at least $1$ marble.

The least number of marbles is:
$$1+1=2\ \text{(marbles)}.$$
**Answer.** At least $2$ marbles: $1$ red and $1$ blue.
:::

## Mini test

:::quiz
::mc
A box holds $3$ red marbles and $2$ blue marbles. You take out $1$ marble. Which statement below is correct?
A. Picking a red marble is possible.
B. Picking a blue marble is impossible.
C. You are certain to pick a blue marble.
D. You are certain to pick a red marble.
::key A
The box holds red marbles but also blue ones, so picking a red marble is possible.

::mc
A box holds $6$ yellow marbles. You take out $1$ marble. Which statement below is correct?
A. Picking a red marble is possible.
B. You are certain to pick a yellow marble.
C. Picking a yellow marble is impossible.
D. Picking a blue marble is possible.
::key B
The box holds only yellow marbles, so you pick yellow every time.

::mc
A box holds $4$ red marbles and $2$ blue marbles. You take out $1$ marble. Which event below is impossible?
A. You pick a blue marble.
B. You pick a red marble.
C. You pick a yellow marble.
D. You pick a red or a blue marble.
::key C
There is no yellow marble in the box, so you can never pick one.

::mc
A box holds $4$ red marbles and $2$ blue marbles. You take out $1$ marble. Which event below is certain?
A. You pick a red marble.
B. You pick a blue marble.
C. You pick a yellow marble.
D. You pick a red or a blue marble.
::key D
Every marble is red or blue, so event C happens every time.

::tf
A spinner is divided into $6$ equal sections: $4$ red and $2$ blue. You spin it and the pointer stops on one section.
a) The pointer stopping on red is certain.
b) The pointer stopping on blue is possible.
c) The pointer stopping on yellow is impossible.
d) The pointer is more likely to stop on red than on blue.
::key F T T T
a) False: the spinner also has blue sections, so it is only possible. b) True: there are $2$ blue sections. c) True: there is no yellow section. d) True: $4>2$.

::sa
A box holds $7$ red marbles and $5$ blue marbles. How many marbles are in the box altogether?
::key 12
$7+5=12$ (marbles).

::sa
A box holds $9$ red marbles and $4$ blue marbles. How many more red marbles than blue marbles are there?
::key 5
$9-4=5$ (marbles).
:::
