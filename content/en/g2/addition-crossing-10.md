:::goals
- Add two numbers whose total is more than 10, for example $8+5$.
- Use the "make 10" trick to add quickly, without counting one by one.
- Solve a word problem with one addition.
:::

Lan has $8$ sweets. Her mum gives her $5$ more. How many sweets does Lan have altogether?

You could count on one at a time: $9, 10, 11, 12, 13$. That works, but it is slow and easy to lose your place. A quicker way is to make a full ten first, then add what is left.

## Let's explore

Picture a sweet box with exactly $10$ spaces. Lan puts her $8$ sweets in, so $2$ spaces are still empty.

- Lan takes $2$ of the $5$ sweets from her mum to fill the box. Now the box has $10$.
- $3$ of mum's sweets are left outside the box.
- $10$ in the box and $3$ outside make $13$.
The box is full, so you only need to count the ones outside.

So $8+5=13$. What you just did has a name: **make 10**. Fill the box first, then add what is left outside.

:::theorem The "make 10" trick
To work out $8+5$:
1. Ask: how many does $8$ need to make $10$? It needs $2$.
2. Split $5$ into $2$ and $3$.
3. Add: $8+2=10$, then $10+3=13$.
:::

Why does the trick work? No sweet is lost. You only move $2$ of them into the box to make $10$, and the rest are still counted.

## Examples

We try a $9$ first, because $9$ needs only $1$ more to make $10$. The split is simple to do.

:::example Work out $9+4$
**Solution.** $9$ needs $1$ more to make $10$, so split $4$ into $1$ and $3$:
$$9+4=9+1+3=10+3=13.$$
So $9+4=13$.
:::

With a $7$ it is different: you need more to make $10$. Ask yourself how many more.

:::example Work out $7+6$
**Solution.** $7$ needs $3$ more to make $10$, so split $6$ into $3$ and $3$:
$$7+6=7+3+3=10+3=13.$$
So $7+6=13$.
:::

Sometimes the first number is the smaller one. Then you can swap the two numbers, because the sum stays the same, and work it out more easily.

:::example Work out $6+8$
**Solution.** Swapping the addends does not change the sum, so $6+8=8+6$. $8$ needs only $2$ more to make $10$, so split $6$ into $2$ and $4$:
$$8+6=8+2+4=10+4=14.$$
So $6+8=14$.
:::

Now we use addition for something familiar: groups planting trees together.

:::example Planting trees
Group One planted $9$ trees and Group Two planted $7$ trees. How many trees did the two groups plant altogether?

**Solution.** "Altogether" means putting the two groups' trees together, so we add. $9$ needs $1$ more to make $10$, so split $7$ into $1$ and $6$:
$$9+7=10+6=16.$$
So the two groups planted $16$ trees.
:::

:::warning Mistakes to watch out for
- **Forgetting what is left.** Wrong: $8+5=10$. Why it is wrong: you only added $2$ of the $5$ and forgot the other $3$. Right: $8+5=10+3=13$.
- **Splitting wrongly.** Wrong: splitting $5$ into $2$ and $2$. Why it is wrong: $2+2=4$, not $5$. Right: $5=2+3$.
- **No unit in a word problem.** Wrong: "Answer: $16$". Why it is wrong: a number on its own does not say what it is a number of. Right: "Answer: $16$ trees".
Many pupils slip up here, so after splitting, add the two parts back together to see whether they match the number you started with.
:::

## Summary

- To add across $10$, **make 10**: split the second number into the part that makes $10$ and the part that is left.
- Example: $8+5=8+2+3=10+3=13$.
- Swapping the addends does not change the sum; add on to the bigger number to make it easier.
- Questions with "altogether" or "both" usually need addition; remember the unit in the answer.
Lan's question at the start is solved the same way: fill the box to make a full ten, then add what is left. Practise a few more sums until it feels natural.

## Practice

Each exercise comes with a reminder of what you need and a hint to start you off. Try it yourself first. If you get stuck, or when you have finished, open the solution.

:::exercise
Work out $9+3$.

::hint
**What you need:** make $10$: $9$ needs $1$ more.

**Steps:**
1. Split $3$ into $1$ and $2$.
2. Work out $9+1$, then add $2$.

::solution
To add across $10$, we split $3$ into $1+2$ so that $9+1$ makes $10$.

We have
$$9+3=9+1+2=10+2=12.$$

Check by swapping the two addends: $3+9=12$.

So $9+3=12$.

**Answer.** $12$.
:::

:::exercise
Work out $8+4$.

::hint
**What you need:** $8$ needs $2$ more to make $10$.

**Steps:**
1. Split $4$ into $2$ and $2$.
2. Work out $8+2$, then add what is left.

::solution
To add across $10$, we split $4$ into $2+2$ so that $8+2$ makes $10$.

We have
$$8+4=8+2+2=10+2=12.$$

Check by swapping the two addends: $4+8=12$.

So $8+4=12$.

**Answer.** $12$.
:::

:::exercise
Work out $7+5$.

::hint
**What you need:** $7$ needs $3$ more to make $10$.

**Steps:**
1. Split $5$ into $3$ and $2$.
2. Work out $7+3$, then add $2$.

::solution
To add across $10$, we split $5$ into $3+2$ so that $7+3$ makes $10$.

We have
$$7+5=7+3+2=10+2=12.$$

Check by swapping the two addends: $5+7=12$.

So $7+5=12$.

**Answer.** $12$.
:::

:::exercise
Work out $5+9$.

::hint
**What you need:** swapping the two addends does not change the sum.

**Steps:**
1. Write $5+9$ as $9+5$.
2. $9$ needs $1$ more: split $5$ into $1$ and $4$.

::solution
When we swap the two addends the sum does not change, so $5+9=9+5$. We put $9$ first because $9$ needs only $1$ more to make $10$.

We split $5$ into $1+4$:
$$5+9=9+5=9+1+4=10+4=14.$$

Check: $5+9=5+5+4=10+4=14$.

So $5+9=14$.

**Answer.** $14$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $8+6 \;\square\; 15$.

::hint
**What you need:** work out the sum first, then compare the two numbers.

**Steps:**
1. Work out $8+6$ with the make-10 trick.
2. Compare the result with $15$.

::solution
First we work out $8+6$. We split $6$ into $2+4$ so that $8+2$ makes $10$:
$$8+6=8+2+4=10+4=14.$$

Now compare $14$ with $15$: $14$ comes before $15$ when we count, so $14<15$.

Hence $8+6<15$.

So the sign to write in the box is $<$.

**Answer.** The sign $<$.
:::

:::exercise
In a garden there are $9$ hens and $6$ cockerels. How many chickens are there altogether?

::hint
**What you need:** "altogether" means putting together: use addition.

**Steps:**
1. What do we know? $9$ hens and $6$ cockerels. What is asked? How many chickens altogether.
2. Work out $9+6$ and write the answer with its unit.

::solution
Solution

To find how many chickens there are altogether, we add the number of hens and the number of cockerels.

The number of chickens altogether is:
$$9+6=9+1+5=10+5=15\ \text{(chickens)}.$$

So there are $15$ chickens altogether in the garden.

**Answer.** $15$ chickens.
:::

:::exercise
Remember the last lesson: what number comes just after $12$? Then work out (the number just after $12$) $+\,7$.

::hint
**What you need:** the number just after a number is $1$ more than it.

**Steps:**
1. Find the number just after $12$.
2. Add $7$ to it (count on, or add the ones).

::solution
The number just after a number is $1$ more than it. Since $12+1=13$, the number just after $12$ is $13$.

Next we work out $13+7$. We write $13=10+3$ and add $3$ and $7$ to make $10$:
$$13+7=10+3+7=10+10=20.$$

So the number just after $12$ is $13$, and $13+7=20$.

**Answer.** $20$.
:::

:::exercise Challenge
Find the missing number: $\square+8=15$.

::hint
**What you need:** $8$ needs $2$ more to make $10$; then how many more to reach $15$?

**Steps:**
1. From $8$ to $10$ you need $2$.
2. From $10$ to $15$ you need $5$.
3. Add the two parts: $2+5$.

::solution
The missing number plus $8$ makes $15$. We count on from $8$ up to $15$, passing through $10$.

From $8$ up to $10$ we need $2$. From $10$ up to $15$ we need $5$. The missing number is
$$2+5=7.$$

Check: $7+8=7+3+5=10+5=15$. Correct.

So the number to write in the box is $7$.

**Answer.** $7$.
:::

::key C
$8$ needs $2$ more to make $10$, so split $7=2+5$. Option D is wrong because $2+4=6$, not $7$.

"Altogether" means putting together: $8+6=14$. Option A is $8-6$, a subtraction by mistake.
