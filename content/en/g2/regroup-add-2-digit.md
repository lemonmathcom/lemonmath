:::goals
- Set out a column and add two two-digit numbers, for example $46+38$.
- Remember to add the extra $1$ ten when the ones make $10$ or more.
- Solve a word problem with one addition that needs regrouping.
:::

Lan has $46$ exercise-book labels. Mai has $38$ labels. How many labels do the two girls have altogether?

In the last lesson you added a one-digit number to a two-digit number and carried $1$ ten. This lesson uses the same method, with one more number that has tens.

## Let's explore

We split $46$ into $4$ tens and $6$ ones, and $38$ into $3$ tens and $8$ ones.

- Add the ones: $6+8=14$. That is $1$ ten and $4$ ones.
- Write $4$ in the ones place and carry $1$ ten.
- Add the tens: $4+3=7$, then add the carried $1$ ten to make $8$.

So there are $8$ tens and $4$ ones, which is $84$.

$$\begin{array}{r} 46\\ +\ 38\\ \hline 84 \end{array}$$

You can also jump on a number line: from $46$ add $30$ to reach $76$, then add $8$ to reach $84$.

:::theorem Adding two two-digit numbers with regrouping
To work out $46+38$:
1. Set out the column: ones under ones, tens under tens.
2. Add the ones: $6+8=14$. Write $4$ and carry $1$ ten.
3. Add the tens: $4+3+1=8$. Write $8$.
:::

This works because $14$ ones make $1$ ten and $4$ ones. The new ten is added to the tens, so it is not lost.

## Examples

We start with two small numbers whose ones make just a little more than $10$.

:::example Work out $27+15$
**Solution.** Ones: $7+5=12$, write $2$ and carry $1$. Tens: $2+1+1=4$ (the tens of both numbers and the carried ten):
$$\begin{array}{r} 27\\ +\ 15\\ \hline 42 \end{array}$$
So $27+15=42$.
:::

The next sum is done in exactly the same way, with different numbers.

:::example Work out $48+36$
**Solution.** Ones: $8+6=14$, write $4$ and carry $1$. Tens: $4+3+1=8$:
$$\begin{array}{r} 48\\ +\ 36\\ \hline 84 \end{array}$$
So $48+36=84$.
:::

Now there is a $9$ in the ones, so the ones make more.

:::example Work out $59+27$
**Solution.** Ones: $9+7=16$, write $6$ and carry $1$. Tens: $5+2+1=8$:
$$\begin{array}{r} 59\\ +\ 27\\ \hline 86 \end{array}$$
So $59+27=86$.

**Check.** Round $59$ up to $60$: $60+27=87$, then take away $1$ to get $86$. The answers match.
:::

Now use addition to solve a problem from everyday life.

:::example The class
A class has $35$ boys and $48$ girls. How many children are in the class altogether?

**Solution.** "Altogether" means putting together, so we add. Ones: $5+8=13$, write $3$ and carry $1$. Tens: $3+4+1=8$:
$$35+48=83\ \text{(children)}.$$
So there are $83$ children in the class.
:::

:::warning Mistakes to watch out for
- **Forgetting the carried ten.** Wrong: $46+38=74$. Why it is wrong: you wrote $4$ but forgot to add the carried $1$ ten to the tens. Right: $46+38=84$.
- **Writing all of $14$ in the ones place.** Wrong: $46+38=714$. Why it is wrong: $14$ ones must be exchanged for $1$ ten and $4$ ones. Right: $46+38=84$.
- **No unit in a word problem.** Wrong: "Answer: $83$". Right: "Answer: $83$ children".
:::

## Summary

- Set out the column and add from the ones to the tens.
- If the ones make $10$ or more, write the ones that are left and carry $1$ ten.
- In the tens: add the two tens digits, then add the carried $1$ ten.
- Example: $46+38$: $6+8=14$, write $4$ carry $1$; $4+3+1=8$; the answer is $84$.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out $24+18$.

::hint
**What you need:** add the ones first; if they make $10$ or more, carry $1$ ten.

**Steps:**
1. Work out $4+8$.
2. Add the tens and the carried $1$.

::solution
Ones: $4+8=12$, write $2$ carry $1$. Tens: $2+1+1=4$. So $24+18=42$.

**Answer.** $42$.
:::

:::exercise
Set out the column and work out $37+25$.

::hint
**What you need:** put tens under tens and ones under ones.

**Steps:**
1. Write the two numbers in columns.
2. Add the ones, then the tens.

::solution
$7+5=12$, write $2$ carry $1$. $3+2+1=6$. So $37+25=62$.

**Answer.** $62$.
:::

:::exercise
Remember the last lesson. Work out $58+7$.

::hint
**What you need:** a one-digit number has only ones; you still carry $1$ ten when the ones make $10$ or more.

**Steps:**
1. Work out $8+7$.
2. Tens: $5$ plus the carried ten.

::solution
$8+7=15$, write $5$ carry $1$. $5+1=6$. So $58+7=65$.

**Answer.** $65$.
:::

:::exercise
Work out.

a) $45+39$.

b) $56+27$.

::hint
**What you need:** the same method works for both sums.

**Steps:**
1. Add the ones, write the ones that are left, carry $1$.
2. Add the tens and the carried $1$.

::solution
a) $5+9=14$, write $4$ carry $1$; $4+3+1=8$. So $45+39=84$.

b) $6+7=13$, write $3$ carry $1$; $5+2+1=8$. So $56+27=83$.

**Answer.** a) $84$; b) $83$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Say why.

a) $38+47 \;\square\; 84$.

b) $29+35 \;\square\; 65$.

::hint
**What you need:** work out the sum first, then compare the two numbers.

**Steps:**
1. Work out the sum on the left.
2. Compare the tens, then the ones.

::solution
a) $38+47=85$. Since $85>84$, we have $38+47>84$.

b) $29+35=64$. Since $64<65$, we have $29+35<65$.

**Answer.** a) The sign $>$; b) the sign $<$.
:::

:::exercise
Ha wrote: $36+47=73$. Where did Ha go wrong? Correct the answer.

::hint
**What you need:** when the ones make $10$ or more, you must carry $1$ ten.

**Steps:**
1. Work out $6+7$.
2. Work out the tens: was the carried ten added?

::solution
$6+7=13$, write $3$ carry $1$. The tens should be $3+4+1=8$, but Ha only worked out $3+4=7$ (the carried ten was forgotten). So $36+47=83$.

**Answer.** Ha forgot the carried ten; the right answer is $83$.
:::

:::exercise
Group One planted $49$ trees and Group Two planted $38$ trees. How many trees did the two groups plant altogether?

::hint
**What you need:** "the two groups altogether" means putting together: use addition.

**Steps:**
1. What do we know? $49$ trees and $38$ trees. What is asked?
2. Work out $49+38$ and write the answer with its unit.

::solution
$9+8=17$, write $7$ carry $1$. $4+3+1=8$. The number of trees is:
$$49+38=87\ \text{(trees)}.$$

**Answer.** $87$ trees.
:::

:::exercise Challenge
Find the missing digit: $5\square+27=84$.

::hint
**What you need:** the ones digit of the sum is $4$, so $\square+7$ must make $14$.

**Steps:**
1. What must $\square+7$ equal to write $4$ and carry $1$?
2. Check with the addition.

::solution
The ones digit of the sum is $4$, so $\square+7=14$, which gives $\square=7$. Check: $57+27=84$ (because $7+7=14$ and $5+2+1=8$).

**Answer.** The missing digit is $7$.
:::
