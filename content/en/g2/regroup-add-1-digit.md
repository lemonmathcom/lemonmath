:::goals
- Understand why you add $1$ ten when the ones make $10$ or more.
- Set out the sum in columns and work it out correctly, such as $38+6$.
- Solve a word problem with one addition with regrouping.
:::

Nam has $38$ marbles. His friend Hung gives him $6$ more. How many marbles does Nam have altogether?

Counting marbles one by one is slow, and it is easy to lose your place. There is a quicker way, and you already know it: in earlier lessons you added across $10$ within $20$. We will use the same idea for bigger numbers. The question for this lesson is: when the ones fill up, where does the extra go?

## Let's explore

To add them, first look at what each number is made of. We split $38$ into $3$ tens and $8$ ones. The number $6$ has no tens at all, just $6$ ones.

- First add the ones: $8+6=14$. So there are $14$ ones.
- That is too many ones to leave in the ones place. $14$ ones are $1$ ten and $4$ ones, because we exchange $10$ ones for $1$ ten.
- Then add the tens: the $3$ tens we had plus the $1$ new ten make $4$ tens.

Put together, that is $4$ tens and $4$ ones, which is $44$ marbles. That answers the question about Nam's marbles.

$$\begin{array}{r} 38\\ +\ \ 6\\ \hline 44 \end{array}$$

If you like to see it, you can also use a number line. From $38$ jump $2$ steps to $40$, which makes a round ten, then $4$ more steps to $44$. Both ways give the same answer.

:::theorem Adding a one-digit number to a two-digit number with regrouping
To work out $38+6$:
1. Set out the sum: ones under ones, tens under tens.
2. Add the ones: $8+6=14$. Write $4$ in the ones and carry $1$ ten.
3. Add the tens: $3+1=4$. Write $4$ in the tens.
:::

Why does this work? Because $14$ ones are the same as $1$ ten and $4$ ones: we have only gathered them up more neatly. The new ten is not lost, so remember to add it to the tens. Many children forget this step, so look back at the tens before you finish.

## Examples

Let us try a few more sums until the steps feel familiar. The first is a gentle one: the ones make only a little more than $10$.

:::example Work out $27+5$
**Solution.** Add the ones first: $7+5=12$, write $2$ and carry $1$ ten. Then add the tens: $2+1=3$:
$$\begin{array}{r} 27\\ +\ \ 5\\ \hline 32 \end{array}$$
So $27+5=32$.
:::

The next sum is done in exactly the same way, only with different numbers. Before you read the solution, see if you can tell whether the ones will need an exchange.

:::example Work out $46+8$
**Solution.** Ones: $6+8=14$, write $4$ and carry $1$. Tens: $4+1=5$:
$$\begin{array}{r} 46\\ +\ \ 8\\ \hline 54 \end{array}$$
So $46+8=54$.
:::

This time the ones make a bigger total. No need to worry: the method stays exactly the same. When we have finished, we will check the answer in a different way.

:::example Work out $69+7$
**Solution.** Ones: $9+7=16$, write $6$ and carry $1$. Tens: $6+1=7$:
$$\begin{array}{r} 69\\ +\ \ 7\\ \hline 76 \end{array}$$
So $69+7=76$.

**Check.** Split $7=1+6$: $69+1=70$, then $70+6=76$. The answers match.
:::

Here is a problem from everyday life: Mum puts more apples into a basket. Ask yourself whether things are put together or taken away.

:::example A basket of apples
A basket holds $58$ apples. Mum puts in $6$ more apples. How many apples are in the basket altogether?

**Solution.** "Puts in more" means putting together, so you add. Ones: $8+6=14$, write $4$ and carry $1$. Tens: $5+1=6$:
$$58+6=64\ \text{(apples)}.$$
So there are $64$ apples in the basket altogether.
:::

:::warning Mistakes to watch out for
- **Forgetting the carried ten.** Wrong: $38+6=34$. Why it is wrong: many children write $4$ and stop, forgetting to add $1$ ten to the tens. Right: $38+6=44$.
- **Writing all of $14$ in the ones.** Wrong: $38+6=314$. Why it is wrong: $14$ ones must be exchanged for $1$ ten and $4$ ones, so the ones place keeps only the leftover ones. Right: $38+6=44$.
- **Leaving out the unit in a word problem.** Wrong: "Answer: $64$". Why it is wrong: a number on its own does not say what we are counting. Right: "Answer: $64$ apples".
:::

## Summary

- Add the ones first. If they make $10$ or more, exchange $10$ ones for $1$ ten.
- Write the ones that are left in the ones place, and carry $1$ ten to the tens.
- Example: $38+6$: $8+6=14$, write $4$ and carry $1$; $3+1=4$; the answer is $44$.
- A problem that asks "altogether", or says some more are added, usually needs an addition. Remember to write the unit in the answer.
Remember the question at the start: when the ones fill up, where does the extra go? It is not lost. It becomes a ten and joins the tens. Try a few sums in Practice until the steps feel natural.

## Practice

Each exercise comes with what you need to remember and a hint to help you start. Try it yourself first, and do not worry if the answer does not come at once. When you have finished, open the solution and compare.

:::exercise
Work out $35+7$.

::hint
**What you need:** add the ones first; if they make $10$ or more, carry $1$ ten.

**Steps:**
1. Work out $5+7$.
2. Write the ones, carry $1$ ten, then add the tens.

::solution
We set out the addition and add from the ones.

Ones: $5+7=12$, write $2$ and carry $1$.

Tens: $3$ plus $1$ (carried) is $4$, write $4$.

We have
$$35+7=42.$$

Check: $42-7=35$. Correct.

So $35+7=42$.

**Answer.** $42$.
:::

:::exercise
Set out in columns and work out $48+5$.

::hint
**What you need:** put the ones under the ones.

**Steps:**
1. Write $48$, then write $5$ under the $8$.
2. Add the ones, then the tens.

::solution
Set out the sum so that the digit $8$ is in the same column as the digit $5$, in the ones:
$$\begin{array}{r}48\\+\phantom{0}5\\\hline53\end{array}$$

Ones: $8+5=13$, write $3$ and carry $1$.

Tens: $4$ plus $1$ (carried) is $5$, write $5$.

Check: $53-5=48$. Correct.

So $48+5=53$.

**Answer.** $53$.
:::

:::exercise
Remember the lesson on litres. A can holds $26$ litres of water. Someone pours in $7$ more litres. How many litres of water are in the can altogether?

::hint
**What you need:** "pours in more" means putting together: use an addition; the unit is litres ($l$).

**Steps:**
1. What do we know? What is asked?
2. Work out $26+7$ and write the unit litres.

::solution
Solution

To find how many litres of water are in the can altogether, we add the litres already in the can and the litres poured in.

Ones: $6+7=13$, write $3$ and carry $1$. Tens: $2+1=3$.

The amount of water in the can altogether is:
$$26+7=33\ \text{(litres)}$$

So the can holds $33$ litres of water altogether.

**Answer.** $33$ litres of water.
:::

:::exercise
Find the number that goes in the box.

a) $56+\square=62$.

b) $47+\square=52$.

::hint
**What you need:** how much do you add to $56$ to reach $60$, and how much more to reach $62$?

**Steps:**
1. Go from the first number up to the next multiple of ten.
2. Add the rest.

::solution
a) From $56$ to $60$ is $4$, because $56+4=60$. From $60$ to $62$ is $2$. The missing number is $4+2=6$. Check: $56+6=62$. Correct.

b) From $47$ to $50$ is $3$, because $47+3=50$. From $50$ to $52$ is $2$. The missing number is $3+2=5$. Check: $47+5=52$. Correct.

So the number in box a) is $6$ and in box b) is $5$.

**Answer.** a) $6$; b) $5$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Say why.

a) $59+4 \;\square\; 62$.

b) $28+5 \;\square\; 34$.

::hint
**What you need:** work out the sum first, then compare the two numbers.

**Steps:**
1. Work out the sum on the left.
2. Compare the tens, then the ones.

::solution
a) Work out $59+4$: ones $9+4=13$, write $3$ and carry $1$; tens $5+1=6$. So $59+4=63$. Since $63>62$, we have $59+4>62$.

b) Work out $28+5$: ones $8+5=13$, write $3$ and carry $1$; tens $2+1=3$. So $28+5=33$. Since $33<34$, we have $28+5<34$.

So in a) we write the sign $>$, and in b) we write the sign $<$.

**Answer.** a) The sign $>$; b) the sign $<$.
:::

:::exercise
An writes: $47+8=45$. Where did An go wrong? Correct the answer.

::hint
**What you need:** when the ones make $10$ or more, you must carry $1$ ten.

**Steps:**
1. Work out $7+8$.
2. Check whether An added the carried ten to the tens.

::solution
We work out $47+8$ again.

Ones: $7+8=15$, write $5$ and carry $1$.

The tens should be $4+1=5$ (we add the carried ten). An only wrote $4$ because the carried ten was forgotten, so An got the wrong answer $45$.

The correct working is
$$47+8=55.$$

Check: $55-8=47$. Correct.

So An went wrong by forgetting the carried ten; the right answer is $47+8=55$.

**Answer.** An forgot the carried ten; the right answer is $55$.
:::

:::exercise
There are $67$ pupils lining up in the school yard. Then $9$ more pupils run over and join the line. How many pupils are there now altogether?

::hint
**What you need:** "more join" means putting together: use an addition.

**Steps:**
1. What do we know? $67$ pupils and $9$ more pupils. What is asked?
2. Work out $67+9$ and write the answer with its unit.

::solution
Solution

To find how many pupils there are now altogether, we add the pupils already in the line and the pupils who ran over.

Ones: $7+9=16$, write $6$ and carry $1$. Tens: $6+1=7$.

The number of pupils now is:
$$67+9=76\ \text{(pupils)}$$

So there are $76$ pupils altogether now.

**Answer.** $76$ pupils.
:::

:::exercise Challenge
Find the digit that goes in the box: $4\square+7=51$.

::hint
**What you need:** the sum has $1$ in the ones, so $\square+7$ must make $11$.

**Steps:**
1. What must $\square+7$ equal so that you write $1$ and carry $1$?
2. Check with an addition.

::solution
The sum in $4\square+7=51$ is $51$, so the ones digit of the sum is $1$.

In the ones, $\square+7$ must end in $1$. Since $\square+7$ is at least $7$ and at most $16$, we get $\square+7=11$, which gives $\square=11-7=4$.

Check the tens: $4$ plus $1$ (carried) is $5$, which matches the tens digit of $51$.

Check: $44+7=51$ (because $4+7=11$ and $4+1=5$). Correct.

So the missing digit is $4$.

**Answer.** The missing digit is $4$.
:::
