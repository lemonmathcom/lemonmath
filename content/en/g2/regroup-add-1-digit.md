:::goals
- Understand why you add $1$ ten when the ones make $10$ or more.
- Set out the sum in columns and work it out correctly, such as $38+6$.
- Solve a word problem with one addition with regrouping.
:::

Nam has $38$ marbles. His friend Hung gives him $6$ more. How many marbles does Nam have altogether?

You already know how to add across $10$ within $20$ from earlier lessons. This lesson uses the same idea for bigger numbers.

## Let's explore

We split $38$ into $3$ tens and $8$ ones. The number $6$ has just $6$ ones.

- Add the ones: $8+6=14$. So there are $14$ ones.
- $14$ ones are $1$ ten and $4$ ones. We exchange $10$ ones for $1$ ten.
- Add the tens: the $3$ tens we had plus the $1$ new ten make $4$ tens.

So there are $4$ tens and $4$ ones, which is $44$.

$$\begin{array}{r} 38\\ +\ \ 6\\ \hline 44 \end{array}$$

You can also jump along a number line: from $38$ jump $2$ steps to $40$, then $4$ more steps to $44$.

:::theorem Adding a one-digit number to a two-digit number with regrouping
To work out $38+6$:
1. Set out the sum: ones under ones, tens under tens.
2. Add the ones: $8+6=14$. Write $4$ in the ones and carry $1$ ten.
3. Add the tens: $3+1=4$. Write $4$ in the tens.
:::

This works because $14$ ones are the same as $1$ ten and $4$ ones. The new ten is not lost: you add it to the tens.

## Examples

We start with an addition where the ones make just a little more than $10$.

:::example Work out $27+5$
**Solution.** Add the ones first: $7+5=12$, write $2$ and carry $1$ ten. Then add the tens: $2+1=3$:
$$\begin{array}{r} 27\\ +\ \ 5\\ \hline 32 \end{array}$$
So $27+5=32$.
:::

The next sum works in exactly the same way, with different numbers.

:::example Work out $46+8$
**Solution.** Ones: $6+8=14$, write $4$ and carry $1$. Tens: $4+1=5$:
$$\begin{array}{r} 46\\ +\ \ 8\\ \hline 54 \end{array}$$
So $46+8=54$.
:::

Now the ones make a bigger total, but the method stays the same.

:::example Work out $69+7$
**Solution.** Ones: $9+7=16$, write $6$ and carry $1$. Tens: $6+1=7$:
$$\begin{array}{r} 69\\ +\ \ 7\\ \hline 76 \end{array}$$
So $69+7=76$.

**Check.** Split $7=1+6$: $69+1=70$, then $70+6=76$. The answers match.
:::

Now use addition to solve a problem from everyday life.

:::example A basket of apples
A basket holds $58$ apples. Mum puts in $6$ more apples. How many apples are in the basket altogether?

**Solution.** "Puts in more" means putting together, so you add. Ones: $8+6=14$, write $4$ and carry $1$. Tens: $5+1=6$:
$$58+6=64\ \text{(apples)}.$$
So there are $64$ apples in the basket altogether.
:::

:::warning Mistakes to watch out for
- **Forgetting the carried ten.** Wrong: $38+6=34$. Why it is wrong: you wrote $4$ but forgot to add $1$ ten to the tens. Right: $38+6=44$.
- **Writing all of $14$ in the ones.** Wrong: $38+6=314$. Why it is wrong: $14$ ones must be exchanged for $1$ ten and $4$ ones. Right: $38+6=44$.
- **Leaving out the unit in a word problem.** Wrong: "Answer: $64$". Right: "Answer: $64$ apples".
:::

## Summary

- Add the ones first. If they make $10$ or more, exchange $10$ ones for $1$ ten.
- Write the ones that are left in the ones place and carry $1$ ten to the tens.
- Example: $38+6$: $8+6=14$, write $4$ carry $1$; $3+1=4$; the answer is $44$.
- Word problems that ask "altogether" or "how many more are added" usually need an addition; remember to write the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out $35+7$.

::hint
**What you need:** add the ones first; if they make $10$ or more, carry $1$ ten.

**Steps:**
1. Work out $5+7$.
2. Write the ones, carry $1$ ten, then add the tens.

::solution
Ones: $5+7=12$, write $2$ carry $1$. Tens: $3+1=4$. So $35+7=42$.

**Answer.** $42$.
:::

:::exercise
Set out in columns and work out $48+5$.

::hint
**What you need:** put the ones under the ones.

**Steps:**
1. Write $48$, then write $5$ under the $8$.
2. Add the ones, then the tens.

::solution
$8+5=13$, write $3$ carry $1$. $4+1=5$. So $48+5=53$.

**Answer.** $53$.
:::

:::exercise
Remember the lesson on litres. A can holds $26$ litres of water. Someone pours in $7$ more litres. How many litres of water are in the can altogether?

::hint
**What you need:** "pours in more" means putting together: use an addition; the unit is litres ($l$).

**Steps:**
1. What do we know? What is asked?
2. Work out $26+7$ and write the unit litres.

::solution
$6+7=13$, write $3$ carry $1$. $2+1=3$. The amount of water is:
$$26+7=33\ \text{(litres)}.$$

**Answer.** $33$ litres of water.
:::

:::exercise
Find the number that goes in the box.

a) $56+\square=62$.

b) $47+\square=52$.

::hint
**What you need:** how much do you add to $56$ to reach $60$, and how much more to reach $62$?

**Steps:**
1. Go from the first number up to the next multiple of ten.
2. Add the rest.

::solution
a) From $56$ to $60$ is $4$, and from $60$ to $62$ is $2$, so the missing number is $4+2=6$. Check: $56+6=62$.

b) From $47$ to $50$ is $3$, and from $50$ to $52$ is $2$, so the missing number is $5$. Check: $47+5=52$.

**Answer.** a) $6$; b) $5$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Say why.

a) $59+4 \;\square\; 62$.

b) $28+5 \;\square\; 34$.

::hint
**What you need:** work out the sum first, then compare the two numbers.

**Steps:**
1. Work out the sum on the left.
2. Compare the tens, then the ones.

::solution
a) $59+4=63$. Since $63>62$, $59+4>62$.

b) $28+5=33$. Since $33<34$, $28+5<34$.

**Answer.** a) The sign $>$; b) the sign $<$.
:::

:::exercise
An writes: $47+8=45$. Where did An go wrong? Correct the answer.

::hint
**What you need:** when the ones make $10$ or more, you must carry $1$ ten.

**Steps:**
1. Work out $7+8$.
2. Check whether An added the carried ten to the tens.

::solution
$7+8=15$, write $5$ carry $1$. The tens should be $4+1=5$, but An only wrote $4$ (forgot the carried ten). So $47+8=55$.

**Answer.** An forgot the carried ten; the right answer is $55$.
:::

:::exercise
There are $67$ pupils lining up in the school yard. Then $9$ more pupils run over and join the line. How many pupils are there now altogether?

::hint
**What you need:** "more join" means putting together: use an addition.

**Steps:**
1. What do we know? $67$ pupils and $9$ more pupils. What is asked?
2. Work out $67+9$ and write the answer with its unit.

::solution
$7+9=16$, write $6$ carry $1$. $6+1=7$. The number of pupils is:
$$67+9=76\ \text{(pupils)}.$$

**Answer.** $76$ pupils.
:::

:::exercise Challenge
Find the digit that goes in the box: $4\square+7=51$.

::hint
**What you need:** the sum has $1$ in the ones, so $\square+7$ must make $11$.

**Steps:**
1. What must $\square+7$ equal so that you write $1$ and carry $1$?
2. Check with an addition.

::solution
The sum has $1$ in the ones, so $\square+7=11$, which means $\square=4$. Check: $44+7=51$ (because $4+7=11$ and $4+1=5$).

**Answer.** The missing digit is $4$.
:::

## Mini test

:::quiz
::mc
The answer to $47+6$ is
A. $53$.
B. $43$.
C. $52$.
D. $413$.
::key A
$7+6=13$, write $3$ carry $1$; $4+1=5$, so $47+6=53$. Option B forgets the carried ten, D writes all of $13$ in the ones.

::mc
When you work out $68+5$, you write $3$ in the ones. How many tens do you carry to the tens?
A. $0$.
B. $1$.
C. $2$.
D. $3$.
::key B
$8+5=13$ is $1$ ten and $3$ ones, so you carry $1$ ten. Tens: $6+1=7$, so the answer is $73$.

::mc
Which sum has the answer $52$?
A. $47+4$.
B. $45+8$.
C. $46+6$.
D. $49+4$.
::key C
$46+6=52$. The other sums give $53$, $51$ and $53$.

::mc
Lan has $36$ book labels and a friend gives her $8$ more. How many book labels does Lan have altogether?
A. $34$ labels.
B. $28$ labels.
C. $314$ labels.
D. $44$ labels.
::key D
"Gives more" means putting together: $36+8=44$. Option A forgets the carried ten, B works out $36-8$, a subtraction by mistake.

::tf
Look at the sum $59+7$.
a) Ones: $9+7=16$.
b) $16$ ones can be exchanged for $1$ ten and $6$ ones.
c) $59+7=65$.
d) $59+7$ is greater than $60$.
::key T T F T
a) True: $9+7=16$. b) True: $16=10+6$. c) False: the tens are $5+1=6$, so the answer is $66$. d) True: $66>60$.

::sa
Work out $75+8$.
::key 83
$5+8=13$, write $3$ carry $1$; $7+1=8$. So $75+8=83$.

A tank has $49$ fish and $5$ more fish are put in. How many fish are in the tank altogether?
::key 54
$9+5=14$, write $4$ carry $1$; $4+1=5$. So $49+5=54$ (fish).
