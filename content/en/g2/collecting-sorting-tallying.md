:::goals
- Collect, sort and tally data using tally marks.
- Record the tally in a table of data and check it with addition.
- Read a pictogram, including one where each symbol stands for $2$.
- Draw a pictogram from a table of data and answer questions about more and fewer.
:::

Class $2$A has $20$ pupils. The teacher wants to buy one kind of fruit for the end-of-week party, so she asks each pupil: "Which fruit do you like best: oranges, bananas or apples?". She gets $20$ answers but does not yet know which fruit to buy. Can you help her?

To answer, you need to arrange the answers neatly and count them reliably. This lesson shows you how.

## Collecting, sorting and tallying data

### Let's explore

The teacher writes down the answers of the $20$ pupils in order: orange, banana, apple, orange, banana, orange, apple, banana, orange, orange, banana, apple, orange, banana, orange, apple, banana, orange, banana, orange. This list is hard to read, so you do three things:

- **Collect:** ask each pupil and write down the answer.
- **Sort:** put the same answers into the same group: orange, banana, apple.
- **Tally:** draw one mark for each answer. After $4$ upright marks, mark $5$ is drawn across them, making a group of $5$.

The tally:

- Orange: $\cancel{\mid\mid\mid\mid}\ \mid\mid\mid\mid$, which is $5+4=9$ pupils.
- Banana: $\cancel{\mid\mid\mid\mid}\ \mid\mid$, which is $5+2=7$ pupils.
- Apple: $\mid\mid\mid\mid$, which is $4$ pupils.

Now record it in a table of data:

| Fruit | Number of pupils |
|---|---|
| Orange | $9$ |
| Banana | $7$ |
| Apple | $4$ |
| Total | $20$ |

The total $9+7+4=20$ equals the number of pupils in the class, so nothing was missed and nothing was counted twice.

:::theorem Tallying data
To tally data:
1. Sort the answers into groups.
2. Draw one mark for each answer; after $4$ upright marks, draw mark $5$ across them.
3. Count the marks in each group and write the numbers in a table of data.
4. Add all the groups: the total must equal the number of answers collected.
:::

Why make groups of $5$? Counting $5$, $10$, $15$ group by group is quicker and safer than counting single marks. The final addition then tells you whether you counted too few or too many.

### Examples

We start with a small tally.

:::example Tallying pen colours
Our group asks $10$ pupils for their favourite pen colour and gets: red, blue, yellow, blue, red, blue, blue, yellow, red, blue. Tally the number of pupils who like each colour.

**Solution.** Sort the answers and count each colour:

- Red: $3$ pupils.
- Blue: $5$ pupils, drawn as $\cancel{\mid\mid\mid\mid}$.
- Yellow: $2$ pupils.

Check: $3+5+2=10$, which equals the number of pupils asked.
:::

Once you have a table of data, you can read it and compare the numbers.

:::example Clubs at school
The table of data shows how many pupils belong to each club:

| Club | Number of pupils |
|---|---|
| Art | $9$ |
| Chess | $6$ |
| Football | $12$ |

Which club has the most pupils? Which club has the fewest? How many pupils belong to the three clubs altogether?

**Solution.** We have $12>9>6$, so Football has the most pupils and Chess has the fewest.

The number of pupils in the three clubs altogether is:
$$9+6+12=27\ \text{(pupils)}.$$
**Answer:** Football has the most, Chess has the fewest, $27$ pupils altogether.
:::

## Pictograms

### Let's explore

A table of data uses numbers. A **pictogram** uses pictures, so you can compare at a glance. Here is a pictogram of the votes in Class $2$A, where each ● stands for $1$ pupil:

| Fruit | Pupils who like it (each ● is $1$ pupil) |
|---|---|
| Orange | ●●●●●●●●● |
| Banana | ●●●●●●● |
| Apple | ●●●● |

The orange row is the longest, so oranges are liked by the most pupils. Count the ● in each row: orange $9$, banana $7$, apple $4$. The teacher will buy oranges. Oranges beat apples by $9-4=5$ pupils.

:::theorem Reading a pictogram
To read a pictogram:
1. Read the key to see what each symbol stands for.
2. Count the symbols in the row you want; if each symbol stands for $2$, count in steps of $2$: $2$, $4$, $6$, ...
3. Write the number you find with its unit.
:::

Why read the key first? Because $5$ symbols ● mean $5$ pupils if each ● is $1$ pupil, but $10$ pupils if each ● is $2$ pupils. A picture only has a meaning when you know what it stands for.

### Examples

We start with a pictogram where each symbol stands for $2$.

:::example Borrowing books from the class library
The pictogram shows how many storybooks our class borrowed in three days (each ● is $2$ books):

| Day | Number of storybooks |
|---|---|
| Monday | ●●● |
| Tuesday | ●●●● |
| Wednesday | ●● |

How many books were borrowed on Tuesday? How many books were borrowed in the three days altogether?

**Solution.** The Tuesday row has $4$ symbols ●, each ● is $2$ books, so on Tuesday $4\times 2=8$ books were borrowed. In the same way, $6$ books were borrowed on Monday and $4$ on Wednesday.

The number of books borrowed in the three days is:
$$6+8+4=18\ \text{(books)}.$$
**Answer:** $8$ books on Tuesday; $18$ books in the three days.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example Picking up litter in the playground
Three groups pick up litter in the playground. The pictogram shows how many bags of litter each group collected (each ● is $2$ bags):

| Group | Bags of litter |
|---|---|
| Group $1$ | ●●●●● |
| Group $2$ | ●●●● |
| Group $3$ | ●●●●●● |

How many bags of litter did the three groups collect altogether? How many more bags did Group $3$ collect than Group $2$?

**Understand.** We know the number of ● for each group and that each ● is $2$ bags. We are asked for the total number of bags and for how many more bags Group $3$ collected than Group $2$.

**Plan.** Change the number of ● into bags, then add for "altogether" and subtract for "how many more".

**Solve.** Group $1$ collected $10$ bags, Group $2$ collected $8$ bags, Group $3$ collected $12$ bags.

The number of bags the three groups collected is:
$$10+8+12=30\ \text{(bags)}.$$
The number of bags Group $3$ collected more than Group $2$ is:
$$12-8=4\ \text{(bags)}.$$
**Answer:** $30$ bags; $4$ more bags.

**Look back.** Group $3$ has $6-4=2$ more symbols ● than Group $2$, and each ● is $2$ bags, which is $4$ more bags, the same as above. If each ● were $5$ bags, would the total number of bags change?
:::

:::warning Mistakes to watch out for
- **Tallying too few or too many.** Wrong: asking $10$ pupils and writing red $3$, blue $5$, yellow $3$. Why it is wrong: $3+5+3=11$, which is more than $10$, so one pupil was counted twice. Right: yellow has $2$ pupils, because $3+5+2=10$.
- **Forgetting to read the key.** Wrong: a row has $4$ symbols ●, each ● is $2$ books, and the answer given is "$4$ books". Why it is wrong: each symbol stands for $2$ books. Right: $8$ books.
- **No unit in the answer.** Wrong: "Answer: $18$". Right: "Answer: $18$ books".
:::

**Connection.** Pictograms use the addition and subtraction you already know: add to find a total, subtract to find "how many more" or "how many fewer".

## Summary

- To get data, collect the answers, sort them into groups and tally with marks: after $4$ upright marks, draw mark $5$ across them.
- Add the groups: the total must equal the number of answers collected.
- A pictogram uses pictures instead of numbers; always read the key to see what each symbol stands for.
- "Altogether" means add, "how many more" or "how many fewer" means subtract; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Our class asks $12$ pupils for their favourite colour and gets: blue, red, blue, yellow, red, blue, blue, red, yellow, blue, red, blue. Tally the number of pupils who like each colour, then check with addition.

::hint
**What you need:** sort by colour, draw one mark for each answer, then add the groups.

**Steps:**
1. Count the answers "blue", then "red", then "yellow".
2. Add the three numbers and compare with $12$.

::solution
Blue: $6$ pupils, drawn as $\cancel{\mid\mid\mid\mid}\ \mid$. Red: $4$ pupils. Yellow: $2$ pupils.

Check: $6+4+2=12$, which equals the number of pupils asked.

**Answer.** Blue $6$ pupils, red $4$ pupils, yellow $2$ pupils.
:::

:::exercise
The table of data shows how many trees three groups planted: Group $1$ planted $14$ trees, Group $2$ planted $9$ trees, Group $3$ planted $11$ trees. Which group planted the most trees? How many trees did the three groups plant altogether?

::hint
**What you need:** compare the numbers to find the most; "the three groups altogether" means putting together.

**Steps:**
1. Compare $14$, $9$, $11$.
2. Add the three numbers, setting out in columns if needed.

::solution
We have $14>11>9$, so Group $1$ planted the most trees.

The number of trees the three groups planted is:
$$14+9+11=34\ \text{(trees)}.$$
**Answer.** Group $1$ planted the most; $34$ trees altogether.
:::

:::exercise
The pictogram shows how pupils come to school (each ● is $1$ pupil): bicycle ●●●●●, on foot ●●●●●●●●, bus ●●●. How many pupils walk? How many more pupils walk than come by bus?

::hint
**What you need:** read the key, then count the symbols ● in each row.

**Steps:**
1. Count the ● in the "on foot" row and in the "bus" row.
2. "How many more" is a subtraction.

::solution
The "on foot" row has $8$ symbols ●, so $8$ pupils walk. The "bus" row has $3$ symbols ●, so $3$ pupils come by bus.

The number of pupils who walk more than those who come by bus is:
$$8-3=5\ \text{(pupils)}.$$
**Answer.** $8$ pupils walk; $5$ more than by bus.
:::

:::exercise
The pictogram shows the flowers in the school garden (each ● is $2$ plants): roses ●●●●, chrysanthemums ●●●●●, orchids ●●●. How many chrysanthemum plants are there? How many flower plants are there in the whole garden?

::hint
**What you need:** each ● is $2$ plants, so count in steps of $2$.

**Steps:**
1. How many symbols ● are in the chrysanthemum row? How many plants is each symbol?
2. Find the number of rose and orchid plants, then add the three numbers.

::solution
Chrysanthemums: $5\times 2=10$ (plants). Roses: $4\times 2=8$ (plants). Orchids: $3\times 2=6$ (plants).

The number of flower plants in the whole garden is:
$$8+10+6=24\ \text{(plants)}.$$
**Answer.** $10$ chrysanthemum plants; $24$ flower plants in the garden.
:::

:::exercise
The table of data shows how many balls three classes borrowed: Class $2$A borrowed $6$ balls, Class $2$B borrowed $10$ balls, Class $2$C borrowed $4$ balls. Draw a pictogram where each ● stands for $2$ balls.

::hint
**What you need:** the number of symbols ● is the number of balls divided by $2$.

**Steps:**
1. Class $2$A borrowed $6$ balls: how many times $2$ make $6$?
2. Do the same for the other two classes, then draw.

::solution
Class $2$A: $6$ balls, draw $3$ symbols. Class $2$B: $10$ balls, draw $5$ symbols. Class $2$C: $4$ balls, draw $2$ symbols.

| Class | Balls borrowed (each ● is $2$ balls) |
|---|---|
| Class $2$A | ●●● |
| Class $2$B | ●●●●● |
| Class $2$C | ●● |

**Answer.** $3$ symbols, $5$ symbols and $2$ symbols.
:::

:::exercise
For three days in a row, our group collected plastic bottles for recycling: Monday $25$ bottles, Tuesday $18$ bottles, Wednesday $30$ bottles. How many bottles were collected in the three days altogether? How many more bottles were collected on Wednesday than on Tuesday?

::hint
**What you need:** "the three days altogether" is an addition; "how many more" is a subtraction.

**Steps:**
1. What do we know? What is asked?
2. Write the two calculations, set them out in columns, then check.

::solution
The number of bottles collected in the three days is:
$$25+18+30=73\ \text{(bottles)}.$$
The number of bottles collected on Wednesday more than on Tuesday is:
$$30-18=12\ \text{(bottles)}.$$
**Answer.** $73$ bottles; $12$ more bottles.
:::

:::exercise
Remember adding and subtracting within 1,000. The pictogram shows the books in a library (each ● is $100$ books): storybooks ●●●●, science books ●●●, picture books ●●. How many books are there altogether? How many more storybooks are there than science books?

::hint
**What you need:** each ● is $100$ books; work in hundreds in your head.

**Steps:**
1. How many symbols ● are in the storybook row, so how many hundreds of books?
2. Add, then subtract the round hundreds.

::solution
Storybooks: $400$ books. Science books: $300$ books. Picture books: $200$ books.

The number of books altogether is:
$$400+300+200=900\ \text{(books)}.$$
The number of storybooks more than science books is:
$$400-300=100\ \text{(books)}.$$
**Answer.** $900$ books; $100$ more storybooks.
:::

:::exercise Challenge
All $20$ pupils in a class choose one of three games. The pictogram, where each ● is $2$ pupils, shows only two games so far: Tug of war ●●●●, Skipping ●●●. The third game, Shuttlecock, has not been drawn yet. How many symbols ● do you need to draw for Shuttlecock?

::hint
**What you need:** the numbers of pupils for the three games add up to $20$.

**Steps:**
1. Find the number of pupils who chose Tug of war and Skipping.
2. The number who chose Shuttlecock is what is left of $20$; then divide by $2$.

::solution
Tug of war: $4\times 2=8$ pupils. Skipping: $3\times 2=6$ pupils.

The number of pupils who chose Shuttlecock is:
$$20-8-6=6\ \text{(pupils)}.$$
Each ● is $2$ pupils, so draw $3$ symbols ●.

Check: $8+6+6=20$. Correct.

**Answer.** $3$ symbols ●.
:::

## Mini test

:::quiz
::mc
In a tally table, the colour red is recorded as $\cancel{\mid\mid\mid\mid}\ \mid\mid\mid$. The number of pupils who chose red is
A. $8$.
B. $5$.
C. $7$.
D. $3$.
::key A
The crossed group is $5$ pupils, plus $3$ single marks: $5+3=8$. Option C counts the crossed group as $4$, option B counts only the crossed group, option D counts only the single marks.

::mc
In a pictogram each ● is $2$ pupils. The "Football" row has ●●●●●. The number of pupils who like football is
A. $5$.
B. $10$.
C. $7$.
D. $2$.
::key B
There are $5$ symbols ●, each ● is $2$ pupils, so $5\times 2=10$ pupils. Option A forgets to read the key, option C adds $5+2$.
 
::mc
Table of data: Orange $9$ pupils, Banana $7$ pupils, Apple $4$ pupils. How many more pupils like oranges than apples?
A. $13$.
B. $2$.
C. $5$.
D. $3$.
::key C
"How many more" is a subtraction: $9-4=5$. Option A is an addition, option B is $9-7$ and option D is $7-4$: those subtractions use the wrong two fruits.

::mc
In a pictogram each ● is $2$ books: Monday ●●●, Tuesday ●●●●. How many books were borrowed on the two days altogether?
A. $7$ books.
B. $12$ books.
C. $34$ books.
D. $14$ books.
::key D
Monday: $3\times 2=6$ books; Tuesday: $4\times 2=8$ books; $6+8=14$. Option A only adds the number of symbols ●, option C joins the digits $3$ and $4$.

::tf
The table of data shows how many pupils like each game: Tug of war $8$ pupils, Skipping $11$ pupils, Chess $6$ pupils.
a) Skipping is liked by the most pupils.
b) More pupils like Tug of war than Chess.
c) The three games are liked by $24$ pupils altogether.
d) Skipping has $5$ more pupils than Chess.
::key T T F T
a) True: $11>8>6$. b) True: $8>6$. c) False: $8+11+6=25$, not $24$. d) True: $11-6=5$.

::sa
In a pictogram each ● is $2$ pupils. The "Swimming" row has $7$ symbols ●. How many pupils like swimming?
::key 14
$7\times 2=14$ pupils.

::sa
Group One collected $16$ bags of litter, Group Two collected $9$ bags and Group Three collected $14$ bags. How many bags of litter did the three groups collect altogether?
::key 39
$16+9+14=39$ (bags): $16+9=25$, then $25+14=39$.
:::
