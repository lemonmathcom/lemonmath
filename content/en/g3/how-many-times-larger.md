:::goals
- Find how many times larger the larger number is than the smaller number by dividing the larger by the smaller.
- Tell the difference between "how many times as large" and "how many more".
- Check with multiplication.
- Solve word problems about how many times larger, including two-step problems.
:::

A blue string is $6$ m long and a red string is $24$ m long. You can say that the red string is $18$ m longer than the blue string. But you can also say it another way: how many times as long as the blue string is the red string?

These two ways of saying it give two different answers. This lesson teaches you how to answer the question "how many times".

## Let's explore

Cut the $24$ m red string into pieces as long as the blue string, each piece $6$ m long. Count how many pieces you get:
$$24\div6=4.$$
So the red string is made of $4$ pieces of $6$ m, which means the red string is $4$ times as long as the blue string. Check by multiplying: $6\times 4=24$. Correct.

:::theorem How many times larger is the larger number?
To find how many times larger the larger number is than the smaller number, divide the larger number by the smaller number.
:::

Why divide? Because "$4$ times as large" means the larger number is made of $4$ groups the size of the smaller number. To find how many groups the size of the smaller number make up the larger number, you split the larger number into such groups, and that is division.

"How many times as large" and "how many more" are two different questions. For how many more, you subtract: $24-6=18$ (m). For how many times as large, you divide: $24\div6=4$ (times).

## Examples

We start with small numbers.

:::example $12$ is how many times as large as $3$?
**Solution.** Divide the larger number by the smaller number:
$$12\div3=4.$$
Check: $3\times 4=12$. So $12$ is $4$ times as large as $3$.
:::

Now another pair of numbers.

:::example $35$ is how many times as large as $5$?
**Solution.** Divide $35$ by $5$:
$$35\div5=7.$$
Check: $5\times 7=35$. So $35$ is $7$ times as large as $5$.
:::

Use this to solve a word problem.

:::example Binh's and Ha's storybooks
Binh has $7$ storybooks and Ha has $28$ storybooks. How many times as many storybooks as Binh does Ha have?

**Solution.** "How many times as many" means divide the larger number by the smaller number.

The number of times Ha's books are as many as Binh's is:
$$28\div7=4\ \text{(times)}.$$
**Answer:** $4$ times.
:::

Tell the two questions apart using the same pair of numbers.

:::example How many more and how many times
The blue string is $6$ m long and the red string is $24$ m long. How many metres longer is the red string than the blue string? How many times as long as the blue string is the red string?

**Solution.** The first question asks "how many metres longer", so subtract:
$$24-6=18\ \text{(m)}.$$
The second question asks "how many times as long", so divide:
$$24\div6=4\ \text{(times)}.$$
**Answer:** $18$ m longer; $4$ times as long.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example Ha's and Lan's exercise books
Ha has $4$ exercise books. Lan has $8$ more exercise books than Ha. How many times as many exercise books as Ha does Lan have?

**Understand.** Ha has $4$ books, and Lan has $8$ more than Ha. We are asked how many times as many books as Ha's Lan has.

**Plan.** We do not yet know how many books Lan has, so step one finds Lan's number by adding. Step two divides Lan's number by Ha's number.

**Solve.** The number of books Lan has is:
$$4+8=12\ \text{(books)}.$$
The number of times Lan's books are as many as Ha's is:
$$12\div4=3\ \text{(times)}.$$
**Answer:** $3$ times.

**Look back.** Check: $4\times 3=12$, exactly Lan's number of books. If Lan had $12$ more books than Ha, how many times as many books as Ha would Lan have? Try to think it through.
:::

:::warning Mistakes to watch out for
- **Subtracting instead of dividing.** Wrong: the red string is $24$ m and the blue string is $6$ m, so the red string is $24-6=18$ times as long. Why it is wrong: $18$ tells you how many metres longer the red string is, not how many times as long. Right: $24\div6=4$ times.
- **Dividing the smaller number by the larger.** Wrong: $12$ is how many times $3$: $3\div12$. Why it is wrong: you must divide the larger number by the smaller number. Right: $12\div3=4$.
- **Forgetting to write "times" in the answer.** Wrong: "Answer: $4$". Right: "Answer: $4$ times".
:::

**Connection.** In the last lesson you made a number several times larger by multiplying. This lesson goes the other way: given two numbers, you find the number of times by dividing. Multiplication and division undo each other, as you know.

## Summary

- How many times larger the larger number is: divide the larger number by the smaller number.
- "How many more" means subtract, "how many times as large" means divide.
- Check by multiplying: the smaller number times the number of times must equal the larger number.
- Write "times" in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
$18$ is how many times as large as $6$?

::hint
**What you need:** divide the larger number by the smaller number.

**Steps:**
1. Write the division $18\div6$.

::solution
$$18\div6=3.$$
Check: $6\times 3=18$.

**Answer.** $3$ times.
:::

:::exercise
$56$ is how many times as large as $8$?

::hint
**What you need:** use the $8$ times table to divide.

**Steps:**
1. Which number multiplied by $8$ gives $56$?

::solution
$$56\div8=7.$$
Check: $8\times 7=56$.

**Answer.** $7$ times.
:::

:::exercise
$40$ is how many times as large as $5$?

::hint
**What you need:** the larger number divided by the smaller number.

**Steps:**
1. Write the division $40\div5$, then check.

::solution
$$40\div5=8.$$
Check: $5\times 8=40$.

**Answer.** $8$ times.
:::

:::exercise
Mum is $36$ years old and Lan is $9$. How many times as old as Lan is Mum?

::hint
**What you need:** "how many times as" is a division.

**Steps:**
1. What do we know? What is asked?
2. Divide the larger number by the smaller number.

::solution
The number of times Mum's age is as large as Lan's is:
$$36\div9=4\ \text{(times)}.$$
**Answer.** $4$ times.
:::

:::exercise
A small tank holds $7$ l of water and a large tank holds $28$ l of water. How many litres more water does the large tank hold than the small tank? How many times as much water does the large tank hold as the small tank?

::hint
**What you need:** "how many more" is a subtraction; "how many times as much" is a division.

**Steps:**
1. Work out the subtraction $28-7$.
2. Work out the division $28\div7$.

::solution
The number of litres more the large tank holds is:
$$28-7=21\ \text{(l)}.$$
The number of times as much the large tank holds is:
$$28\div7=4\ \text{(times)}.$$
**Answer.** $21$ l more; $4$ times as much.
:::

:::exercise
Ha has $5$ storybooks. Lan has $15$ more storybooks than Ha. How many times as many storybooks as Ha does Lan have?

::hint
**What you need:** this problem has two steps: find Lan's number of books first.

**Steps:**
1. Find Lan's number of books by adding.
2. Divide Lan's number of books by Ha's.

::solution
The number of storybooks Lan has is:
$$5+15=20\ \text{(books)}.$$
The number of times Lan's books are as many as Ha's is:
$$20\div5=4\ \text{(times)}.$$
**Answer.** $4$ times.
:::

:::exercise
Remember the lesson on making a number several times larger. A number made $6$ times larger gives $54$. What is the number?

::hint
**What you need:** making larger is multiplying, so going back is dividing.

**Steps:**
1. Divide $54$ by $6$.

::solution
The number is:
$$54\div6=9.$$
Check: $9\times 6=54$. Correct.

**Answer.** $9$.
:::

:::exercise Challenge
This year Mum is $28$ years old and her child is $4$. In $4$ years' time, how many times as old as her child will Mum be?

::hint
**What you need:** after $4$ years, both people are $4$ years older.

**Steps:**
1. Find Mum's age and her child's age after $4$ years.
2. Divide Mum's age by her child's age.

::solution
After $4$ years, Mum's age is $28+4=32$ (years) and her child's age is $4+4=8$ (years).

The number of times Mum's age is as large as her child's is:
$$32\div8=4\ \text{(times)}.$$
**Answer.** $4$ times.
:::

## Mini test

:::quiz
::mc
$48$ is how many times as large as $6$?
A. $8$ times.
B. $42$ times.
C. $54$ times.
D. $288$ times.
::key A
$48\div6=8$. B is a subtraction, C an addition, D a multiplication.

::mc
Ha has $7$ storybooks and Lan has $21$ storybooks. How many times as many storybooks as Ha does Lan have?
A. $14$ times.
B. $3$ times.
C. $147$ times.
D. $28$ times.
::key B
$21\div7=3$. A is a subtraction, D an addition, C a multiplication.

::mc
The blue string is $5$ m long and the red string is $20$ m long. Which statement is correct?
A. The red string is $4$ m longer than the blue string.
B. The red string is $15$ times as long as the blue string.
C. The red string is $4$ times as long as the blue string.
D. The blue string is $4$ times as long as the red string.
::key C
$20\div5=4$, so the red string is $4$ times as long as the blue string. A mixes up "times as long" and "longer", B uses $20-5$, D swaps the two strings.

::mc
Ha has $4$ exercise books. Lan has $8$ more than Ha. How many times as many books as Ha does Lan have?
A. $2$ times.
B. $12$ times.
C. $4$ times.
D. $3$ times.
::key D
Lan has $4+8=12$ books, then $12\div4=3$ times. A only works out $8\div4$, B is Lan's number of books, C is Ha's number of books.

::tf
Look at the numbers $24$ and $6$.
a) $24$ is $4$ times as large as $6$.
b) $24$ is $4$ more than $6$.
c) $6$ is $4$ times as large as $24$.
d) $24\div6=4$.
::key T F F T
a) True: $6\times 4=24$. b) False: $24-6=18$. c) False: the larger number is the multiple of the smaller, not the other way round. d) True: $6\times 4=24$.

::sa
$63$ is how many times as large as $9$?
::key 7
$63\div9=7$ (times).

::sa
A ruler is $30$ cm long and a pencil is $6$ cm long. How many times as long as the pencil is the ruler?
::key 5
$30\div6=5$ (times).
