:::goals
- Multiply a two-digit number by a one-digit number (with and without carrying), with a product of at most $100$.
- Set out the working in columns: ones first, then tens.
- Solve a word problem with one multiplication.
:::

Mai has $4$ boxes of pencils, with $12$ pencils in each box. How many pencils does Mai have altogether?

You do not know a $12$ times table, but you can still work it out. This lesson shows you how to multiply a two-digit number.

## Let's explore

The number $12$ is $1$ ten and $2$ ones, so $12=10+2$. Each box has $10+2$ pencils, so $4$ boxes have:

- $10\times4=40$ pencils (the tens part);
- $2\times4=8$ pencils (the ones part);
- $40+8=48$ pencils.

So $12\times4=48$. You see: we multiply each part and then add.

To write this shortly, we **set it out in columns** and multiply the ones first, then the tens.

:::theorem How to multiply a two-digit number by a one-digit number
To work out $24\times3$:
1. Multiply the ones: $4\times3=12$. Write $2$ and carry $1$ (ten).
2. Multiply the tens: $2\times3=6$, then add the carried $1$: $6+1=7$. Write $7$.
3. The result is $24\times3=72$.

If the product of the ones is less than $10$, there is nothing to carry.
:::

This works because $24\times3=(20+4)\times3=60+12=72$. The carried $1$ is the $1$ ten in $12$.

## Examples

We start with a multiplication where nothing is carried.

:::example No carrying
Work out $12\times4$.

**Solution.** Multiply the ones first, then the tens:
$$2\times4=8,\qquad 1\times4=4.$$

Write $4$ in the tens place and $8$ in the ones place. So $12\times4=48$.
:::

Now a multiplication with carrying. Setting it out in columns makes it easier to see.

:::example With carrying
Work out $24\times3$.

**Solution.** Set it out in columns and multiply the ones first: $4\times3=12$, write $2$ and carry $1$. Then $2\times3=6$, and adding the carried $1$ gives $7$:
$$\begin{array}{r}24\\\times\ \ 3\\\hline72\end{array}$$

So $24\times3=72$.
:::

Sometimes the product of the ones ends in $5$ or $0$. We work in just the same way.

:::example Another multiplication with carrying
Work out $15\times5$.

**Solution.** Ones: $5\times5=25$, write $5$ and carry $2$. Tens: $1\times5=5$, and adding the carried $2$ gives $7$:
$$15\times5=75.$$

So $15\times5=75$.
:::

Finally, use multiplication to solve a problem from everyday life.

:::example Boxes of crayons
Each box has $16$ crayons. How many crayons are in $5$ such boxes?

**Solution.** There are $5$ boxes with $16$ crayons each, so we multiply. Ones: $6\times5=30$, write $0$ and carry $3$. Tens: $1\times5=5$, and adding the carried $3$ gives $8$:
$$16\times5=80\ \text{(crayons)}.$$

So $5$ boxes have $80$ crayons.
:::

:::warning Mistakes to watch out for
- **Forgetting the carry.** Wrong: $24\times3=62$. Why it is wrong: you wrote $2$, then worked out $2\times3=6$ and forgot to add the carried $1$. Right: $24\times3=72$.
- **Adding the carry to the ones.** Wrong: adding the carried ten to the $5$ in the ones place. Why it is wrong: the carry is tens, so it must be added to the tens. Right: $1\times5+2=7$ tens.
- **No unit.** Wrong: "Answer: $80$". Right: "Answer: $80$ crayons".
:::

## Summary

- A two-digit number is tens and ones: $24=20+4$.
- Multiply the ones first, then the tens.
- If the product of the ones is $10$ or more, write the ones digit and carry the tens.
- A problem with several equal groups needs multiplication; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out $21\times4$.

::hint
**What you need:** multiply the ones first, then the tens; nothing is carried here.

**Steps:**
1. Work out $1\times4$.
2. Work out $2\times4$ for the tens.

::solution
$1\times4=4$; $2\times4=8$. So $21\times4=84$.

**Answer.** $84$.
:::

:::exercise
Work out $13\times3$.

::hint
**What you need:** $13=10+3$.

**Steps:**
1. Work out $3\times3$ and $1\times3$.
2. Put the results together.

::solution
$3\times3=9$; $1\times3=3$. So $13\times3=39$.

**Answer.** $39$.
:::

:::exercise
Work out $18\times4$.

::hint
**What you need:** if the product of the ones is $10$ or more, carry the tens.

**Steps:**
1. Work out $8\times4$, write the ones digit and carry the tens.
2. Work out $1\times4$ and add the carry.

::solution
$8\times4=32$, write $2$ and carry $3$. $1\times4=4$, and adding $3$ gives $7$. So $18\times4=72$.

**Answer.** $72$.
:::

:::exercise
Work out $25\times3$.

::hint
**What you need:** multiply the ones first, carry, then multiply the tens.

**Steps:**
1. Work out $5\times3$.
2. Work out $2\times3$ and add the carry.

::solution
$5\times3=15$, write $5$ and carry $1$. $2\times3=6$, and adding $1$ gives $7$. So $25\times3=75$.

**Answer.** $75$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $14\times5 \;\square\; 70$.

::hint
**What you need:** work out the product first, then compare.

**Steps:**
1. Work out $14\times5$.
2. Compare the result with $70$.

::solution
$4\times5=20$, write $0$ and carry $2$. $1\times5=5$, and adding $2$ gives $7$. So $14\times5=70$.

**Answer.** The sign $=$.
:::

:::exercise
Each bag has $23$ marbles. How many marbles are in $4$ such bags?

::hint
**What you need:** several equal bags: use multiplication.

**Steps:**
1. What do we know? $23$ marbles in each bag, $4$ bags. What is asked? The total number of marbles.
2. Work out $23\times4$ and write the answer with its unit.

::solution
The number of marbles altogether is:
$$23\times4=92\ \text{(marbles)}.$$

**Answer.** $92$ marbles.
:::

:::exercise
Remember the last lesson: a cuboid is built from small cubes in $4$ layers with $12$ cubes in each layer. How many small cubes are there altogether?

::hint
**What you need:** $4$ layers of $12$ cubes: multiply the number of cubes in a layer by the number of layers.

**Steps:**
1. Write the multiplication.
2. Work out $12\times4$.

::solution
The number of small cubes is:
$$12\times4=48\ \text{(cubes)}.$$

**Answer.** $48$ cubes.
:::

:::exercise Challenge
Find the missing number: $\square\times4=52$.

::hint
**What you need:** to find a missing factor, divide the product by the known factor.

**Steps:**
1. Write the division $52\div4$.
2. Check with multiplication.

::solution
The missing number is $52\div4=13$.

**Check.** $13\times4=52$. Correct.

**Answer.** $13$.
:::

## Mini test

:::quiz
::mc
$32\times3$ equals
A. $96$.
B. $36$.
C. $69$.
D. $35$.
::key A
$2\times3=6$ and $3\times3=9$, so $32\times3=96$. Option B is the mistake of not multiplying the tens.

::mc
$24\times4$ equals
A. $86$.
B. $96$.
C. $28$.
D. $106$.
::key B
$4\times4=16$, write $6$ and carry $1$; $2\times4=8$, and adding $1$ gives $9$. Option A is the mistake of forgetting the carry.

::mc

A. $60$.
B. $80$.
C. $90$.
D. $21$.
::key C
$5\times6=30$, write $0$ and carry $3$; $1\times6=6$, and adding $3$ gives $9$. So there are $90$ sweets. Option A is the mistake of forgetting the carry.

::mc
Which multiplication gives $68$?
A. $17\times3$.
B. $18\times4$.
C. $16\times4$.
D. $17\times4$.
::key D
$17\times4=68$. The others give $51$, $64$ and $72$.

::tf
Look at the multiplication $26\times3$.
a) $6\times3=18$, write $8$ and carry $1$.
b) $2\times3=6$, and adding the carried $1$ gives $7$.
c) $26\times3=68$.
d) $26\times3=78$.
::key T T F T
a) True. b) True. c) False: the result is $78$, not $68$. d) True: write $7$ in the tens place and $8$ in the ones place.

::sa

::key 85
$7\times5=35$, write $5$ and carry $3$; $1\times5=5$, and adding $3$ gives $8$. So $85$.

::sa

::key 96
$12\times8$: $2\times8=16$, write $6$ and carry $1$; $1\times8=8$, and adding $1$ gives $9$. So $96$ (chairs).
