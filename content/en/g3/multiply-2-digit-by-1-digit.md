:::goals
- Multiply a two-digit number by a one-digit number (with and without carrying), with a product of at most $100$.
- Set out the working in columns: ones first, then tens.
- Solve a word problem with one multiplication.
:::

Mai has $4$ boxes of pencils, with $12$ pencils in each box. How many pencils does Mai have altogether?

You do not know a $12$ times table, so how can we tell how many pencils Mai has? Do not worry: you do not need a new table. We only need to split that number into parts that are easy to multiply. The same idea works for many other two-digit numbers.

## Let's explore

Look closely at the number $12$. It is $1$ ten and $2$ ones, so $12=10+2$. Each box has $10+2$ pencils, so $4$ boxes have:

- $10\times4=40$ pencils: the tens part;
- $2\times4=8$ pencils: the ones part;
- $40+8=48$ pencils: we add the parts together.

So $12\times4=48$. Notice what we did: we multiplied each part and then added. That idea sits behind the method you are about to learn.

That works, but it is a little long. To write it more shortly, we **set it out in columns**: we multiply the ones first, then the tens. The steps are in the box below.

:::theorem How to multiply a two-digit number by a one-digit number
To work out $24\times3$:
1. Multiply the ones: $4\times3=12$. Write $2$ and carry $1$ (ten).
2. Multiply the tens: $2\times3=6$, then add the carried $1$: $6+1=7$. Write $7$.
3. The result is $24\times3=72$.

If the product of the ones is less than $10$, there is nothing to carry.
:::

Why does this work? Because $24\times3=(20+4)\times3=60+12=72$. There is $1$ ten in $12$. That ten belongs in the tens place, so we carry it and add it at the next step. The carried $1$ is that ten.

## Examples

We start with a multiplication where nothing needs to be carried. The ones come first, then the tens.

:::example No carrying
Work out $12\times4$.

**Solution.** Multiply the ones first, then the tens:
$$2\times4=8,\qquad 1\times4=4.$$

Write $4$ in the tens place and $8$ in the ones place. So $12\times4=48$.
:::

Now a multiplication with carrying. Do not worry if it looks strange the first time. Setting it out in columns lets us follow each step.

:::example With carrying
Work out $24\times3$.

**Solution.** Set it out in columns and multiply the ones first: $4\times3=12$, write $2$ and carry $1$. Then $2\times3=6$, and adding the carried $1$ gives $7$:
$$\begin{array}{r}24\\\times\ \ 3\\\hline72\end{array}$$

So $24\times3=72$.
:::

Sometimes the product of the ones ends in $5$ or $0$. Nothing changes: we work in just the same way.

:::example Another multiplication with carrying
Work out $15\times5$.

**Solution.** Ones: $5\times5=25$, write $5$ and carry $2$. Tens: $1\times5=5$, and adding the carried $2$ gives $7$:
$$15\times5=75.$$

So $15\times5=75$.
:::

Now let us use multiplication for something that happens all the time: counting crayons in several equal boxes. When there are many equal groups, we think of multiplying.

:::example Boxes of crayons
Each box has $16$ crayons. How many crayons are in $5$ such boxes?

**Solution.** There are $5$ boxes with $16$ crayons each, so we multiply. Ones: $6\times5=30$, write $0$ and carry $3$. Tens: $1\times5=5$, and adding the carried $3$ gives $8$:
$$16\times5=80\ \text{(crayons)}.$$

So $5$ boxes have $80$ crayons.
:::

:::warning Mistakes to watch out for
- **Forgetting the carry.** Wrong: $24\times3=62$. Why it is wrong: you wrote $2$, then worked out $2\times3=6$ and forgot to add the carried $1$, so a ten went missing. Right: $24\times3=72$.
- **Adding the carry to the ones.** Wrong: adding the carried ten to the $5$ in the ones place. Why it is wrong: the carry is tens, so it must be added to the tens. Right: $1\times5+2=7$ tens.
- **No unit.** Wrong: "Answer: $80$". Right: "Answer: $80$ crayons".
Many learners slip here, so when you finish, read the question again and check that your answer has its unit.
:::

## Summary

- A two-digit number is tens and ones: $24=20+4$.
- Multiply the ones first, then the tens.
- If the product of the ones is $10$ or more, write the ones digit and carry the tens.
- A problem with several equal groups needs multiplication; remember the unit in the answer.
At the start we asked how many pencils Mai has altogether. Now you can answer questions like that: split into tens and ones, multiply each part and add, or set it out in columns. A few more to practise will make it feel natural.

## Practice

Each exercise gives you what you need to remember and a hint to get you started. Have a go on your own first, look at the hint if you are stuck, and open the solution last. Getting something wrong is fine: putting it right is how the method sticks.

:::exercise
Work out $21\times4$.

::hint
**What you need:** multiply the ones first, then the tens; nothing is carried here.

**Steps:**
1. Work out $1\times4$.
2. Work out $2\times4$ for the tens.

::solution
Set out the multiplication in columns and multiply digit by digit, starting with the ones.

Ones: $1\times4=4$, write $4$.

Tens: $2\times4=8$, write $8$.

We get $21\times4=84$.

Check: $84\div4=21$. Correct.

So $21\times4=84$.

**Answer.** $84$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $14\times5 \;\square\; 70$.

::hint
**What you need:** work out the product first, then compare.

**Steps:**
1. Work out $14\times5$.
2. Compare the result with $70$.

::solution
To compare, we work out $14\times5$ first and then compare the result with $70$.

Ones: $4\times5=20$, write $0$ and carry $2$.

Tens: $1\times5=5$, add $2$ to make $7$, write $7$.

We get $14\times5=70$.

Since $70=70$, we have $14\times5=70$.

So the sign to write is $=$.

**Answer.** The sign $=$.
:::

:::exercise
Each bag has $23$ marbles. How many marbles are in $4$ such bags?

::hint
**What you need:** several equal bags: use multiplication.

**Steps:**
1. What do we know? $23$ marbles in each bag, $4$ bags. What is asked? The total number of marbles.
2. Work out $23\times4$ and write the answer with its unit.

::solution
Solution

Each bag has $23$ marbles and there are $4$ such bags, so we multiply the number of marbles in one bag by the number of bags.

The number of marbles altogether is:
$$23\times4=92\ \text{(marbles)}$$

Check: $92\div4=23$. Correct.

So $4$ bags have $92$ marbles altogether.

**Answer.** $92$ marbles.
:::

:::exercise
Remember the last lesson: a cuboid is built from small cubes in $4$ layers with $12$ cubes in each layer. How many small cubes are there altogether?

::hint
**What you need:** $4$ layers of $12$ cubes: multiply the number of cubes in a layer by the number of layers.

**Steps:**
1. Write the multiplication.
2. Work out $12\times4$.

::solution
Solution

The cuboid has $4$ layers with $12$ small cubes in each layer, so we multiply the number of cubes in one layer by the number of layers.

The number of small cubes altogether is:
$$12\times4=48\ \text{(cubes)}$$

Check: $48\div4=12$. Correct.

So there are $48$ small cubes altogether.

:::exercise Challenge
Find the missing number: $\square\times4=52$.

::hint
**What you need:** to find a missing factor, divide the product by the known factor.

**Steps:**
1. Write the division $52\div4$.
2. Check with multiplication.

::solution
In the multiplication $\square\times4=52$, $\square$ is the missing factor. To find a missing factor, we divide the product by the known factor.

We have
$$\square=52\div4=13.$$

Check: $13\times4=52$. Correct.

So the missing number is $13$.

**Answer.** $13$.
:::
