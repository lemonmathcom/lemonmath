:::goals
- Multiply a three-digit number by a one-digit number in columns, with regrouping, for example $124\times 3$.
- Divide a three-digit number by a one-digit number in columns, for example $372\div3$.
- Divide with a remainder and check by multiplying and adding the remainder.
- Solve word problems using multiplication or division of three-digit numbers.
:::

Each box holds $124$ sweets. A shop has $3$ boxes like this. How many sweets does the shop have altogether? If the sweets are shared equally into $3$ bags, how many sweets are in each bag?

These two questions go together: the first uses multiplication, the second uses division, and the division brings you back to the number of sweets in each box. This lesson teaches you both calculations.

## Multiplying a three-digit number by a one-digit number

### Let's explore

Work out $124\times 3$. Split $124=100+20+4$ and multiply each part by $3$:
$$100\times 3=300,\quad 20\times 3=60,\quad 4\times 3=12.$$
Add them: $300+60+12=372$. So the shop has $372$ sweets.

Now set it out in columns, multiplying from right to left:

$$\begin{array}{r} 124 \\ \times\ \ \ 3 \\ \hline 372 \end{array}$$

Ones: $4\times 3=12$, write $2$ and regroup $1$. Tens: $2\times 3=6$, add $1$ to make $7$. Hundreds: $1\times 3=3$.

:::theorem Multiplying a three-digit number by a one-digit number
To multiply a three-digit number by a one-digit number:
1. Set it out, with the one-digit factor under the ones.
2. Multiply from right to left: the ones, then the tens, then the hundreds.
3. If the product in a column is $10$ or more, write the ones digit and regroup into the column on the left; in the next column, add the regrouped number.
:::

Why does this work? Because each place is multiplied by $3$ separately: $12$ ones is $1$ ten and $2$ ones, so you write $2$ and regroup $1$ ten into the tens column.

### Examples

We start with a multiplication that regroups twice.

:::example Work out $145\times 4$
**Solution.** Set it out and multiply from right to left:
$$\begin{array}{r} 145 \\ \times\ \ \ 4 \\ \hline 580 \end{array}$$
Ones: $5\times 4=20$, write $0$ and regroup $2$. Tens: $4\times 4=16$, add $2$ to make $18$, write $8$ and regroup $1$. Hundreds: $1\times 4=4$, add $1$ to make $5$.

So $145\times 4=580$.
:::

When there is a digit $0$ in the middle, you still have to add the regrouped number.

:::example Work out $207\times 4$
**Solution.** Set it out:
$$\begin{array}{r} 207 \\ \times\ \ \ 4 \\ \hline 828 \end{array}$$
Ones: $7\times 4=28$, write $8$ and regroup $2$. Tens: $0\times 4=0$, add $2$ to make $2$. Hundreds: $2\times 4=8$.

So $207\times 4=828$.
:::

Now use multiplication to solve a problem from everyday life.

:::example Crates of water
Each crate holds $126$ bottles of water. A shop has $4$ crates like this. How many bottles of water does the shop have altogether?

**Solution.** There are $4$ crates with the same number of bottles in each, so we multiply.

The number of bottles of water in the shop is:
$$126\times 4=504\ \text{(bottles)}.$$
**Answer:** $504$ bottles of water.
:::

## Dividing a three-digit number by a one-digit number

### Let's explore

You share $372$ sweets equally into $3$ bags. Divide place by place, from left to right:

- Hundreds: $3$ hundreds divided by $3$ is $1$ hundred, remainder $0$.
- Tens: $7$ tens divided by $3$ is $2$ tens, because $3\times 2=6$; $1$ ten is left over.
- Ones: exchange $1$ ten for $10$ ones and bring down $2$ to make $12$. $12$ divided by $3$ is $4$, remainder $0$.

So
$$372\div3=124.$$
Each bag has $124$ sweets, exactly the number in each box at the start. Check: $124\times 3=372$.

:::theorem Dividing a three-digit number by a one-digit number
To divide a three-digit number by a one-digit number:
1. Divide the hundreds, then the tens, then the ones.
2. After each division, find the remainder, exchange it for units of the next place on the right, bring down that place's digit and keep dividing.
3. The final remainder must be less than the divisor; check by multiplying and adding the remainder.
:::

Why start with the hundreds? Because the hundreds are the biggest part, so you divide the biggest part first. The leftover is exchanged for smaller units and divided again, until every place has been used.

### Examples

We start with a division where the hundreds do not divide exactly.

:::example Work out $584\div4$
**Solution.** Hundreds: $5$ hundreds divided by $4$ is $1$ hundred, with $1$ hundred left over. Exchange $1$ hundred for $10$ tens and bring down $8$ tens to make $18$ tens. $18$ tens divided by $4$ is $4$ tens, because $4\times 4=16$, with $2$ tens left over. Exchange $2$ tens for $20$ ones and bring down $4$ to make $24$. $24$ divided by $4$ is $6$.

So $584\div4=146$. Check: $146\times 4=584$.
:::

Sometimes the hundreds are too few to divide, and there is a remainder.

:::example Work out $487\div5$
**Solution.** $4$ hundreds divided by $5$ is $0$ hundreds, so use $48$ tens instead. $48$ tens divided by $5$ is $9$ tens, because $5\times 9=45$, with $3$ tens left over. Exchange $3$ tens for $30$ ones and bring down $7$ to make $37$. $37$ divided by $5$ is $7$, because $5\times 7=35$, with remainder $2$.

So
$$487\div5=97\ (\text{remainder }2).$$
The remainder $2$ is less than the divisor $5$. Check: $97\times 5+2=487$.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example Putting books on shelves
A library has $856$ storybooks to put equally onto $4$ shelves. How many storybooks are on each shelf?

**Understand.** The library has $856$ books to put equally onto $4$ shelves. We are asked for the number of books on each shelf.

**Plan.** Sharing equally means dividing, so we work out $856\div4$.

**Solve.** Hundreds: $8$ hundreds divided by $4$ is $2$ hundreds. Tens: $5$ tens divided by $4$ is $1$ ten, with $1$ ten left over. Exchange it for $10$ ones and bring down $6$ to make $16$; $16$ divided by $4$ is $4$.

The number of storybooks on each shelf is:
$$856\div4=214\ \text{(books)}.$$
**Answer:** $214$ storybooks.

**Look back.** Check: $214\times 4=856$, exactly the number of books in the library. If the library shared the $856$ books equally onto $8$ shelves, would each shelf have more or fewer than $214$ books?
:::

:::warning Mistakes to watch out for
- **Forgetting the regrouped number.** Wrong: $126\times 4=484$. Why it is wrong: $6\times 4=24$, but $4$ was written and the $2$ was not regrouped; in the tens only $2\times 4=8$ was worked out. Right: $126\times 4=504$.
- **Forgetting the digit $0$ in the quotient.** Wrong: $408\div4=12$. Why it is wrong: in the tens, $0$ divided by $4$ is $0$, so the digit $0$ must be written in the quotient. Right: $408\div4=102$.
- **A remainder equal to or greater than the divisor.** Wrong: $487\div5=96$ (remainder $7$). Why it is wrong: $7>5$, so you can still divide $1$ more time. Right: $487\div5=97$ (remainder $2$).
:::

**Connection.** Multiplication and division undo each other: if $124\times 3=372$ then $372\div3=124$. In the next lesson you will learn to find the value of expressions with all four operations.

## Summary

- Multiplying a three-digit number by a one-digit number: multiply from right to left, regrouping into the column on the left when a product is $10$ or more.
- Dividing a three-digit number by a one-digit number: divide from the hundreds, bring down the next digit and keep dividing.
- The remainder is always less than the divisor; check: quotient $\times$ divisor $+$ remainder $=$ dividend.
- Remember to add the regrouped number and to write the digit $0$ in the quotient when needed.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Set out in columns and work out: $213\times 3$.

::hint
**What you need:** multiply from right to left, place by place.

**Steps:**
1. Multiply the ones: $3\times 3$.

::solution
$$\begin{array}{r} 213 \\ \times\ \ \ 3 \\ \hline 639 \end{array}$$
Ones: $3\times 3=9$. Tens: $1\times 3=3$. Hundreds: $2\times 3=6$.

**Answer.** $639$.
:::

:::exercise
Set out in columns and work out: $152\times 4$.

::hint
**What you need:** if the product in a column is $10$ or more, write the ones digit and regroup.

**Steps:**
1. Ones: $2\times 4$. Tens: $5\times 4$; what do you regroup?

::solution
$$\begin{array}{r} 152 \\ \times\ \ \ 4 \\ \hline 608 \end{array}$$
Ones: $2\times 4=8$. Tens: $5\times 4=20$, write $0$ and regroup $2$. Hundreds: $1\times 4=4$, add $2$ to make $6$.

**Answer.** $608$.
:::

:::exercise
Set out in columns and work out: $307\times 3$.

::hint
**What you need:** with a digit $0$ in the middle, you still add the regrouped number.

**Steps:**
1. Ones: $7\times 3$; what do you regroup?

::solution
$$\begin{array}{r} 307 \\ \times\ \ \ 3 \\ \hline 921 \end{array}$$
Ones: $7\times 3=21$, write $1$ and regroup $2$. Tens: $0\times 3=0$, add $2$ to make $2$. Hundreds: $3\times 3=9$.

**Answer.** $921$.
:::

:::exercise
Each crate holds $125$ books. How many books are there in $5$ crates like this?

::hint
**What you need:** the crates are equal, so use multiplication.

**Steps:**
1. What do we know? What is asked?
2. Write the multiplication, set it out, then check with division.

::solution
The number of books in $5$ crates is:
$$125\times 5=625\ \text{(books)}.$$
Ones: $5\times 5=25$, write $5$ and regroup $2$. Tens: $2\times 5=10$, add $2$ to make $12$, write $2$ and regroup $1$. Hundreds: $1\times 5=5$, add $1$ to make $6$.

**Answer.** $625$ books.
:::

:::exercise
Set out in columns and work out: $639\div3$.

::hint
**What you need:** divide from the hundreds to the tens to the ones.

**Steps:**
1. How many hundreds is $6$ hundreds divided by $3$?

::solution
Hundreds: $6\div3=2$. Tens: $3\div3=1$. Ones: $9\div3=3$. So
$$639\div3=213.$$
Check: $213\times 3=639$.

**Answer.** $213$.
:::

:::exercise
Set out in columns and work out: $408\div4$.

::hint
**What you need:** if a place divides to give $0$, you must still write the digit $0$ in the quotient.

**Steps:**
1. Tens: what is $0$ divided by $4$?

::solution
Hundreds: $4\div4=1$. Tens: $0\div4=0$. Ones: $8\div4=2$. So
$$408\div4=102.$$
Check: $102\times 4=408$.

**Answer.** $102$.
:::

:::exercise
Remember division with a remainder. Work out $725\div6$ and check.

::hint
**What you need:** the remainder must be less than the divisor.

**Steps:**
1. $7$ hundreds divided by $6$ is $1$ hundred, with $1$ hundred left over. Exchange it and bring down the next digit.

::solution
Hundreds: $7$ divided by $6$ is $1$, with $1$ hundred left over. Tens: $12$ tens divided by $6$ is $2$ tens, remainder $0$. Ones: $5$ divided by $6$ is $0$, remainder $5$. So
$$725\div6=120\ (\text{remainder }5).$$
Check: $120\times 6+5=725$. Correct.

**Answer.** $120$ remainder $5$.
:::

:::exercise Challenge
A teacher has $3$ boxes of pens, with $168$ pens in each box. She shares all the pens equally among $6$ classes. How many pens does each class get?

::hint
**What you need:** this problem has two steps: multiply to find the total number of pens, then share equally.

**Steps:**
1. Find the total number of pens in $3$ boxes.
2. Divide the total by $6$ classes.

::solution
The total number of pens in $3$ boxes is:
$$168\times 3=504\ \text{(pens)}.$$
The number of pens each class gets is:
$$504\div6=84\ \text{(pens)}.$$
Check: $84\times 6=504$. Correct.

**Answer.** $84$ pens.
:::
