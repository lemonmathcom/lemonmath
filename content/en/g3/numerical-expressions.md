:::goals
- Recognise a numerical expression and its value.
- Find the value of an expression with only addition and subtraction, or only multiplication and division, working from left to right.
- Find the value of an expression with addition, subtraction, multiplication and division: multiply and divide first, then add and subtract.
- Find the value of an expression with brackets and write an expression for a word problem.
:::

Lan has $20$ marbles. She buys $3$ more bags of marbles, $4$ marbles in each bag. How many marbles does Lan have altogether?

You can write an expression: $20+3\times 4$. But if you add $20+3$ first and then multiply by $4$, you get $92$, while if you multiply $3\times 4$ first you get a different number. Which one is right? This lesson teaches you the order in which to do the operations.

## Let's explore

Lan buys $3$ bags with $4$ marbles in each bag, so the extra marbles are $3\times 4=12$ (marbles). The number of marbles Lan has altogether is $20+12=32$ (marbles). So
$$20+3\times 4=32.$$
Adding $20+3$ first and then multiplying by $4$ gives $92$, which is wrong, because $3$ is not the number of marbles Lan buys: she buys $3$ bags with $4$ marbles in each.

A string of numbers joined by operation signs, like $20+3\times 4$, is called a **numerical expression**. The result after working it out is called the **value of the expression**. The value of $20+3\times 4$ is $32$.

:::theorem The order of operations
- An expression with only addition and subtraction, or only multiplication and division: work from left to right.
- An expression with addition, subtraction, multiplication and division: do the multiplication and division first; then the addition and subtraction.
- An expression with brackets $(\ )$: work out what is inside the brackets first.
:::

Why multiply and divide first? Because $3\times 4$ is a group that stays together: it says "$3$ bags, $4$ marbles in each". And brackets are your way of giving the order: "Do this part first".

## Examples

We start with an expression with only addition and subtraction.

:::example Work out $85-30+15$
**Solution.** The expression has only addition and subtraction, so work from left to right:
$$85-30+15=55+15=70.$$
So the value of the expression is $70$.
:::

An expression with only multiplication and division is also worked out from left to right.

:::example Work out $48\div6\times 3$
**Solution.** Work from left to right:
$$48\div6\times 3=8\times 3=24.$$
So the value of the expression is $24$.
:::

When there is both addition and multiplication, multiply first.

:::example Work out $30+6\times 5$
**Solution.** Do the multiplication first:
$$30+6\times 5=30+30=60.$$
So the value of the expression is $60$.
:::

Brackets change the order of working.

:::example Work out $(50-18)\times 2$ and $50-18\times 2$
**Solution.** In the first expression, work inside the brackets first:
$$(50-18)\times 2=32\times 2=64.$$
In the second expression there are no brackets, so multiply first:
$$50-18\times 2=50-36=14.$$
The two expressions have the same numbers and signs but different values: $64$ and $14$.
:::

Now write an expression for a problem from everyday life.

:::example Boxes of pens
A teacher buys $2$ boxes of blue pens with $6$ pens in each box, and $3$ boxes of red pens with $5$ pens in each box. How many pens does she buy altogether?

**Solution.** The number of blue pens is $2\times 6$, the number of red pens is $3\times 5$, and "altogether" means add. Write one expression:
$$2\times 6+3\times 5=12+15=27.$$
**Answer:** $27$ pens.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example Lan's marbles
Lan has $20$ marbles, buys $3$ more bags with $4$ marbles in each bag, then gives a friend $7$ marbles. How many marbles does Lan have left?

**Understand.** Lan has $20$ marbles, buys $3$ bags of $4$ marbles each, then gives away $7$. We are asked for the number of marbles left.

**Plan.** Write the expression $20+3\times 4-7$: the extra marbles are $3\times 4$, which are added, and then the marbles given to the friend are subtracted.

**Solve.** Multiply first, then work from left to right:
$$20+3\times 4-7=20+12-7=32-7=25.$$
**Answer:** $25$ marbles.

**Look back.** Check step by step, as in a two-step problem: $20+12=32$, then $32-7=25$, the same result. If Lan gave her friend $7$ marbles before buying more, would the final number change?
:::

:::warning Mistakes to watch out for
- **Working from left to right when there is a multiplication.** Wrong: $20+3\times 4=92$. Why it is wrong: $20+3$ was added first and then multiplied by $4$, but the multiplication must come first. Right: $20+3\times 4=32$.
- **Ignoring the brackets.** Wrong: $(50-18)\times 2=14$. Why it is wrong: the multiplication was done first and the brackets were forgotten. Right: $(50-18)\times 2=64$.
- **Multiplying before dividing.** Wrong: $48\div6\times 3=48\div18$. Why it is wrong: the expression has only division and multiplication, so you work from left to right. Right: $48\div6\times 3=24$.
:::

**Connection.** The two-step problems you have learned can be written as one expression, and an expression lets you write a whole solution on one line. You will use this order of operations in every year to come.

## Summary

- A numerical expression is a string of numbers joined by operation signs; the result is its value.
- Only addition and subtraction, or only multiplication and division: work from left to right.
- Addition, subtraction, multiplication and division together: multiply and divide first, then add and subtract.
- With brackets: work inside the brackets first.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Find the value of the expression: $90-25+17$.

::hint
**What you need:** with only addition and subtraction, work from left to right.

**Steps:**
1. Work out $90-25$ first.

::solution
$$90-25+17=65+17=82.$$
**Answer.** $82$.
:::

:::exercise
Find the value of the expression: $63\div7\times 4$.

::hint
**What you need:** with only division and multiplication, work from left to right.

**Steps:**
1. Work out $63\div7$ first.

::solution
$$63\div7\times 4=9\times 4=36.$$
**Answer.** $36$.
:::

:::exercise
Find the value of the expression: $15+4\times 6$.

::hint
**What you need:** multiply and divide first, add and subtract after.

**Steps:**
1. Which operation comes first?

::solution
$$15+4\times 6=15+24=39.$$
**Answer.** $39$.
:::

:::exercise
Find the value of the expression: $56-28\div4$.

::hint
**What you need:** divide first, subtract after.

**Steps:**
1. Work out $28\div4$ first.

::solution
$$56-28\div4=56-7=49.$$
**Answer.** $49$.
:::

:::exercise
Find the values of the two expressions $(24+36)\div6$ and $24+36\div6$. Are the two values equal?

::hint
**What you need:** brackets change the order of working.

**Steps:**
1. First expression: work inside the brackets first.
2. Second expression: do the division first.

::solution
$$(24+36)\div6=60\div6=10.$$
$$24+36\div6=24+6=30.$$
The two values are $10$ and $30$, so they are not equal.

**Answer.** $10$ and $30$; not equal.
:::

:::exercise
A shop has $5$ crates of water with $12$ bottles in each crate, and $25$ more loose bottles. The shop has sold $40$ bottles. How many bottles of water are left? Write an expression and work it out.

::hint
**What you need:** write the expression in the order of the story, remembering to multiply first.

**Steps:**
1. The number of bottles in $5$ crates is $5\times 12$.
2. Add the loose bottles, then subtract the bottles sold.

::solution
The number of bottles of water left is:
$$5\times 12+25-40=60+25-40=85-40=45\ \text{(bottles)}.$$
**Answer.** $45$ bottles of water.
:::

:::exercise
Remember two-step problems. Ha's family keeps $8$ hens, and they keep $3$ times as many ducks as hens. How many hens and ducks do they keep altogether? Write an expression and work it out.

::hint
**What you need:** the number of ducks is $8\times 3$; the number of hens and ducks is the total.

**Steps:**
1. Write an expression with the hens added to the ducks.

::solution
The number of hens and ducks is:
$$8+8\times 3=8+24=32\ \text{(birds)}.$$
**Answer.** $32$ birds.
:::

:::exercise Challenge
Put one pair of brackets into the expression $30-10+5$ so that its value is $15$.

::hint
**What you need:** without brackets $30-10+5=25$; brackets change the order of working.

**Steps:**
1. Try putting the brackets around $10+5$.

::solution
Without brackets: $30-10+5=20+5=25$.

With brackets around $10+5$:
$$30-(10+5)=30-15=15.$$
**Answer.** $30-(10+5)=15$.
:::

## Mini test

:::quiz
::mc
The value of the expression $20+3\times 4$ is
A. $32$.
B. $92$.
C. $12$.
D. $23$.
::key A
Multiply first: $3\times 4=12$, then $20+12=32$. A adds first and then multiplies, C only works out $3\times 4$, D only works out $20+3$.

::mc
The value of the expression $72\div8\times 3$ is
A. $3$.
B. $27$.
C. $9$.
D. $216$.
::key B
Work from left to right: $72\div8=9$, then $9\times 3=27$. B multiplies first, C stops at the division, D works out $72\times 3$.

::mc
The value of the expression $(50-18)\times 2$ is
A. $14$.
B. $32$.
C. $64$.
D. $68$.
::key C
Work inside the brackets first: $50-18=32$, then $32\times 2=64$. A multiplies first, B stops at the brackets, D is a slip in the calculation.

::mc
Lan has $20$ marbles and buys $3$ more bags of marbles, $4$ marbles in each bag. Which expression gives the number of marbles Lan has altogether?
A. $(20+3)\times 4$.
B. $20+3+4$.
C. $20\times 3+4$.
D. $20+3\times 4$.
::key D
The extra marbles are $3\times 4$, which are added to $20$. A adds $20$ to the number of bags, B and C do not match the problem.

::tf
Look at the expression $30+6\times 5$.
a) You must work out $30+6$ first.
b) You must work out $6\times 5$ first.
c) The value of the expression is $60$.
d) The expression $(30+6)\times 5$ has the value $180$.
::key F T T T
a) False: multiplication comes first. b) True: $6\times 5=30$. c) True: $30+30=60$. d) True: $36\times 5=180$.

::sa
Find the value of the expression $15+4\times 6$.
::key 39

Find the value of the expression $(24+36)\div6$.
::key 10
