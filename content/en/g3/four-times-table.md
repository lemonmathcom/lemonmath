:::goals
- Know and build the 4 times table.
- Use the 4 times table to divide by 4.
- Solve a word problem with one multiplication or one division.
:::

In a kennel there are $5$ dogs, and each dog has $4$ legs. How many legs do the $5$ dogs have altogether?

You could count every leg one by one, but that is slow and easy to get wrong. And what if the kennel had even more dogs? The $4$ times table is a shortcut: once you know it, the answer comes straight away.

## Let's explore

Each dog has $4$ legs, so we have groups of $4$ legs. Let's add the dogs one at a time and watch the number of legs grow:

- $1$ dog: $4$ legs.
- $2$ dogs: $4+4=8$ legs.
- $3$ dogs: $8+4=12$ legs.
- $4$ dogs: $12+4=16$ legs.
- $5$ dogs: $16+4=20$ legs.

So $5$ dogs have $20$ legs, that is $4\times5=20$. Notice this: each time we add a dog, which is one more group, the product goes up by exactly $4$.

Here is one more trick, if you already know the $2$ times table. Why does it work? Because $4$ is double $2$, so $4\times5$ is also double $2\times5=10$. You only need to work out $10+10=20$.

:::theorem The 4 times table
To work out $4\times n$, take $4\times(n-1)$ and add $4$. You can also take $2\times n$ and double it.

| $4\times1$ | $4\times2$ | $4\times3$ | $4\times4$ | $4\times5$ |
|---|---|---|---|---|
| $4$ | $8$ | $12$ | $16$ | $20$ |

| $4\times6$ | $4\times7$ | $4\times8$ | $4\times9$ | $4\times10$ |
|---|---|---|---|---|
| $24$ | $28$ | $32$ | $36$ | $40$ |
:::

Once you know the $4$ times table, you know the division facts for $4$ too. Why? Because division undoes multiplication. Since $4\times5=20$, we have $20\div4=5$. In dog words: if you share $20$ legs into groups of $4$, you get $5$ groups, one for each dog.

## Examples

Let's try the first way: take the product before and add $4$.

:::example Work out $4\times7$
**Solution.** You know $4\times6=24$. Add one more group of $4$:
$$4\times7=4\times6+4=24+4=28.$$
So $4\times7=28$.
:::

Now the doubling trick: if you know one product, doubling it gives you another.

:::example Work out $4\times8$ by doubling
**Solution.** We have $4\times4=16$. Since $8$ is double $4$, $4\times8$ is double $4\times4$:
$$4\times8=16+16=32.$$
So $4\times8=32$.
:::

Now for division. Look in the $4$ times table for a product equal to the dividend. The number that is multiplied by $4$ to make it is your answer.

:::example Work out $36\div4$
**Solution.** Ask: which number times $4$ makes $36$? In the $4$ times table, $4\times9=36$, so
$$36\div4=9.$$
**Check.** $4\times9=36$. Correct.

So $36\div4=9$.
:::

Now a word problem that needs multiplication. Think about what one group is and how many groups there are.

:::example Seats
Each table seats $4$ children. How many children can sit at $6$ such tables?

**Solution.** Each table is a group of $4$ children and there are $6$ groups, so we multiply. The number of children is:
$$4\times6=24\ \text{(children)}.$$
So $24$ children can sit at $6$ tables.
:::

Finally, a word problem that needs division. This time we know the total and the size of each group, and we want to find the number of groups.

:::example Oranges on plates
There are $28$ oranges to put on plates, $4$ oranges on each plate. How many plates can we fill?

**Solution.** We split $28$ oranges into groups of $4$, so we divide. The number of plates is:
$$28\div4=7\ \text{(plates)}.$$
**Check.** $4\times7=28$. Correct.

So we can fill $7$ plates.
:::

:::warning Mistakes to watch out for
- **Taking the wrong neighbour.** This is an easy one to slip on. Wrong: $4\times7=24$. Why it is wrong: $24$ is $4\times6$; you forgot to add one more group of $4$. Right: $4\times7=24+4=28$.
- **Adding instead of multiplying.** Wrong: $4\times6=10$. Why it is wrong: $4+6$ is an addition, but $4\times6$ means $6$ groups of $4$. Right: $4\times6=24$.
- **Mixing up a nearby product.** Wrong: $36\div4=8$. Why it is wrong: $4\times8=32$, not $36$. Right: $4\times9=36$, so $36\div4=9$. Checking with a multiplication shows you straight away whether you are right.
- **Forgetting the unit.** Wrong: "Answer: $24$". Right: "Answer: $24$ children". The unit tells the reader what you counted.
:::

## Summary

- The $4$ times table: $4,\ 8,\ 12,\ 16,\ 20,\ 24,\ 28,\ 32,\ 36,\ 40$.
- Each new group adds $4$ to the product: $4\times n=4\times(n-1)+4$.
- $4$ is double $2$, so $4\times n$ is double $2\times n$.
- From $4\times a=b$ we get $b\div4=a$ and $b\div a=4$.
- Write the unit in the answer; check a division with a multiplication.

Back to our opening question: with the table, you can find the legs of the whole kennel without counting each one. Remember that every new group adds exactly one group to the product, and practise until the table feels familiar.

## Practice

Each exercise has a short reminder of what you need and a hint to get you started. Have a go on your own first, and don't worry if you get stuck. Then open the solution and compare.

:::exercise
Work out:

a) $4\times3$.

b) $4\times5$.

c) $4\times9$.

::hint
**What you need:** the $4$ times table: each new group adds $4$ to the product.

**Steps:**
1. Count in fours: $4,\ 8,\ 12,\ \dots$
2. Stop at the number you need.

::solution
Solution

We use the $4$ times table.

a) $4\times3$ is $3$ lots of $4$: $4+4+4=12$. So $4\times3=12$.

b) $4\times5$ is $5$ lots of $4$: $4\times5=20$.

c) $4\times9$ is $9$ lots of $4$: $4\times9=36$.

So $4\times3=12$; $4\times5=20$; $4\times9=36$.

**Answer.** a) $12$; b) $20$; c) $36$.
:::

:::exercise
Work out:

a) $4\times7$.

b) $4\times10$.

c) $4\times4$.

::hint
**What you need:** $4\times n=4\times(n-1)+4$.

**Steps:**
1. Remember the product before.
2. Add $4$.

::solution
Solution

When the number of lots goes up by $1$, the product in the $4$ times table goes up by $4$. We use the product just before to work out each answer.

a) We have $4\times6=24$, so $4\times7=24+4=28$.

b) We have $4\times9=36$, so $4\times10=36+4=40$.

c) We have $4\times3=12$, so $4\times4=12+4=16$.

So $4\times7=28$; $4\times10=40$; $4\times4=16$.

**Answer.** a) $28$; b) $40$; c) $16$.
:::

:::exercise
Remember the $3$ times table. Work out and compare:

a) $3\times4$.

b) $4\times3$.

c) $3\times8$ and $4\times6$.

::hint
**What you need:** swapping the two factors does not change the product.

**Steps:**
1. Work out each product with the $3$ or $4$ times table.
2. Compare the results.

::solution
Solution

a) From the $3$ times table: $3\times4=12$.

b) From the $4$ times table: $4\times3=12$. This is the same as $3\times4$, because swapping the two numbers does not change the product.

c) From the $3$ times table: $3\times8=24$. From the $4$ times table: $4\times6=24$. The two products are equal.

So $3\times4=4\times3=12$ and $3\times8=4\times6=24$.

**Answer.** a) $12$; b) $12$; c) $24$ and $24$.
:::

:::exercise
Work out:

a) $12\div4$.

b) $28\div4$.

c) $40\div4$.

::hint
**What you need:** from $4\times a=b$ we get $b\div4=a$.

**Steps:**
1. Find the product equal to the dividend in the $4$ times table.
2. The other number is the quotient.

::solution
Solution

Dividing by $4$ is the opposite of multiplying by $4$. We think: "$4$ times what number gives the number being divided?"

a) We have $4\times3=12$, so $12\div4=3$.

b) We have $4\times7=28$, so $28\div4=7$.

c) We have $4\times10=40$, so $40\div4=10$.

So $12\div4=3$; $28\div4=7$; $40\div4=10$.

**Answer.** a) $3$; b) $7$; c) $10$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Why?

a) $4\times7 \;\square\; 30$.

b) $24\div4 \;\square\; 4\times2$.

c) $4\times9 \;\square\; 3\times12$.

::hint
**What you need:** work out each side first, then compare the two numbers.

**Steps:**
1. Work out each side with the times table and division facts.
2. Compare the results.

::solution
Solution

We work out the value of each side and then compare.

a) We have $4\times7=28$. Since $28<30$, we get $4\times7<30$.

b) We have $24\div4=6$ (because $4\times6=24$) and $4\times2=8$. Since $6<8$, we get $24\div4<4\times2$.

c) We have $4\times9=36$ and $3\times12=36$. The two sides are equal, so $4\times9=3\times12$.

So the signs to write are $<$, $<$, $=$ in that order.

**Answer.** a) $<$; b) $<$; c) $=$.
:::

:::exercise
Binh wrote: "$36\div4=8$ because $4\times8=36$". Where did Binh go wrong? Correct it.

::hint
**What you need:** check a division with a multiplication.

**Steps:**
1. Work out $4\times8$: does it equal $36$?
2. Find the right number in the $4$ times table.

::solution
Solution

Binh wrote $36\div4=8$ because he thought $4\times8=36$. But $4\times8=32$, not $36$. So Binh remembered the wrong product from the $4$ times table.

To correct it, we find the number that gives $36$ when multiplied by $4$. We have $4\times9=36$, so $36\div4=9$.

Check: $4\times9=36$. Correct.

So Binh's mistake was remembering the wrong product for $4\times8$; the correct result is $36\div4=9$.

**Answer.** Binh remembered the wrong product; $36\div4=9$.
:::

:::exercise
a) Each car has $4$ wheels. How many wheels do $8$ such cars have?

b) $36$ cakes are put into boxes, $4$ cakes in each box. How many boxes are filled?

::hint
**What you need:** equal groups: to find the total, multiply; to find the number of groups, divide.

**Steps:**
1. What do we know? What is asked?
2. Choose the operation, work it out and write the answer with its unit.

::solution
Solution

a) Each car has $4$ wheels, so $8$ such cars have this many wheels:
$$4\times8=32\ \text{(wheels)}$$

b) There are $36$ cakes with $4$ cakes in each box, so the number of boxes filled is:
$$36\div4=9\ \text{(boxes)}$$

So $8$ cars have $32$ wheels and $9$ boxes are filled.

**Answer.** a) $32$ wheels; b) $9$ boxes.
:::

:::exercise Challenge
Lan puts $40$ balls into boxes, $4$ balls in each box. She has already filled $6$ boxes. Find:

a) How many boxes are needed altogether?

b) How many boxes are still to fill, and how many balls are still to be packed?

::hint
**What you need:** the number of boxes is $40\div4$; the balls already packed are $4\times6$.

**Steps:**
1. Work out the total number of boxes.
2. Subtract the boxes filled, then work out the balls left.

::solution
Solution

a) There are $40$ balls with $4$ balls in each box. The number of boxes needed altogether is:
$$40\div4=10\ \text{(boxes)}$$

b) Lan has already filled $6$ boxes. The number of boxes still to fill is:
$$10-6=4\ \text{(boxes)}$$

The number of balls already packed is:
$$4\times6=24\ \text{(balls)}$$

The number of balls still to be packed is:
$$40-24=16\ \text{(balls)}$$

Check: $4$ boxes are left, with $4$ balls in each box, so $4\times4=16$ (balls). This matches the result above.

So $10$ boxes are needed altogether; $4$ boxes are still to fill and $16$ balls are still to be packed.

**Answer.** a) $10$ boxes; b) $4$ boxes and $16$ balls.
:::
