:::goals
- Know and build the 4 times table.
- Use the 4 times table to divide by 4.
- Solve a word problem with one multiplication or one division.
:::

In a kennel there are $5$ dogs, and each dog has $4$ legs. How many legs do the $5$ dogs have altogether?

You could count every leg, but that is slow and easy to get wrong. This lesson helps you work it out quickly with the $4$ times table.

## Let's explore

Each dog has $4$ legs, so we have groups of $4$ legs. We add one group at a time:

- $1$ dog: $4$ legs.
- $2$ dogs: $4+4=8$ legs.
- $3$ dogs: $8+4=12$ legs.
- $4$ dogs: $12+4=16$ legs.
- $5$ dogs: $16+4=20$ legs.

So $5$ dogs have $20$ legs, that is $4\times5=20$. Each time we add a group, the product goes up by $4$.

Here is one more trick: $4$ is double $2$, so $4\times5$ is double $2\times5=10$, and $10+10=20$.

:::theorem The 4 times table
To work out $4\times n$, take $4\times(n-1)$ and add $4$. You can also take $2\times n$ and double it.

| $4\times1$ | $4\times2$ | $4\times3$ | $4\times4$ | $4\times5$ |
|---|---|---|---|---|
| $4$ | $8$ | $12$ | $16$ | $20$ |

| $4\times6$ | $4\times7$ | $4\times8$ | $4\times9$ | $4\times10$ |
|---|---|---|---|---|
| $24$ | $28$ | $32$ | $36$ | $40$ |
:::

The division facts for $4$ come from the $4$ times table. Since $4\times5=20$, we have $20\div4=5$. If you share $20$ things into groups of $4$, you get $5$ groups.

## Examples

We start by taking the product before and adding $4$.

:::example Work out $4\times7$
**Solution.** You know $4\times6=24$. Add one more group of $4$:
$$4\times7=4\times6+4=24+4=28.$$
So $4\times7=28$.
:::

Now use the doubling trick.

:::example Work out $4\times8$ by doubling
**Solution.** We have $4\times4=16$. Since $8$ is double $4$, $4\times8$ is double $4\times4$:
$$4\times8=16+16=32.$$
So $4\times8=32$.
:::

Next, division. Look in the $4$ times table for a product equal to the dividend.

:::example Work out $36\div4$
**Solution.** Ask: which number times $4$ makes $36$? In the $4$ times table, $4\times9=36$, so
$$36\div4=9.$$
**Check.** $4\times9=36$. Correct.

So $36\div4=9$.
:::

Now solve a word problem with multiplication.

:::example Seats
Each table seats $4$ children. How many children can sit at $6$ such tables?

**Solution.** Each table is a group of $4$ children and there are $6$ groups, so we multiply. The number of children is:
$$4\times6=24\ \text{(children)}.$$
So $24$ children can sit at $6$ tables.
:::

Finally, a word problem with division.

:::example Oranges on plates
There are $28$ oranges to put on plates, $4$ oranges on each plate. How many plates can we fill?

**Solution.** We split $28$ oranges into groups of $4$, so we divide. The number of plates is:
$$28\div4=7\ \text{(plates)}.$$
**Check.** $4\times7=28$. Correct.

So we can fill $7$ plates.
:::

:::warning Mistakes to watch out for
- **Taking the wrong neighbour.** Wrong: $4\times7=24$. Why it is wrong: $24$ is $4\times6$; you forgot to add one more group of $4$. Right: $4\times7=24+4=28$.
- **Adding instead of multiplying.** Wrong: $4\times6=10$. Why it is wrong: $4+6$ is an addition, but $4\times6$ means $6$ groups of $4$. Right: $4\times6=24$.
- **Mixing up a nearby product.** Wrong: $36\div4=8$. Why it is wrong: $4\times8=32$, not $36$. Right: $4\times9=36$, so $36\div4=9$.
- **Forgetting the unit.** Wrong: "Answer: $24$". Right: "Answer: $24$ children".
:::

## Summary

- The $4$ times table: $4,\ 8,\ 12,\ 16,\ 20,\ 24,\ 28,\ 32,\ 36,\ 40$.
- Each new group adds $4$ to the product: $4\times n=4\times(n-1)+4$.
- $4$ is double $2$, so $4\times n$ is double $2\times n$.
- From $4\times a=b$ we get $b\div4=a$ and $b\div a=4$.
- Write the unit in the answer; check a division with a multiplication.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out:

a) $4\times3$.

b) $4\times5$.

c) $4\times9$.

::hint
**What you need:** the $4$ times table: each new group adds $4$ to the product.

**Steps:**
1. Count in fours: $4,\ 8,\ 12,\ \dots$
2. Stop at the number you need.

::solution
a) $4\times3=12$.

b) $4\times5=20$.

c) $4\times9=36$.

**Answer.** a) $12$; b) $20$; c) $36$.
:::

:::exercise
Work out:

a) $4\times7$.

b) $4\times10$.

c) $4\times4$.

::hint
**What you need:** $4\times n=4\times(n-1)+4$.

**Steps:**
1. Remember the product before.
2. Add $4$.

::solution
a) $4\times7=24+4=28$.

b) $4\times10=36+4=40$.

c) $4\times4=12+4=16$.

**Answer.** a) $28$; b) $40$; c) $16$.
:::

:::exercise
Remember the $3$ times table. Work out and compare:

a) $3\times4$.

b) $4\times3$.

c) $3\times8$ and $4\times6$.

::hint
**What you need:** swapping the two factors does not change the product.

**Steps:**
1. Work out each product with the $3$ or $4$ times table.
2. Compare the results.

::solution
a) $3\times4=12$.

b) $4\times3=12$, the same as $3\times4$.

c) $3\times8=24$ and $4\times6=24$, so the two products are equal.

**Answer.** a) $12$; b) $12$; c) $24$ and $24$.
:::

:::exercise
Work out:

a) $12\div4$.

b) $28\div4$.

c) $40\div4$.

::hint
**What you need:** from $4\times a=b$ we get $b\div4=a$.

**Steps:**
1. Find the product equal to the dividend in the $4$ times table.
2. The other number is the quotient.

::solution
a) $4\times3=12$, so $12\div4=3$.

b) $4\times7=28$, so $28\div4=7$.

c) $4\times10=40$, so $40\div4=10$.

**Answer.** a) $3$; b) $7$; c) $10$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Why?

a) $4\times7 \;\square\; 30$.

b) $24\div4 \;\square\; 4\times2$.

c) $4\times9 \;\square\; 3\times12$.

::hint
**What you need:** work out each side first, then compare the two numbers.

**Steps:**
1. Work out each side with the times table and division facts.
2. Compare the results.

::solution
a) $4\times7=28$ and $28<30$, so $4\times7<30$.

b) $24\div4=6$ and $4\times2=8$; $6<8$, so $24\div4<4\times2$.

c) $4\times9=36$ and $3\times12=36$, so the two sides are equal.

**Answer.** a) $<$; b) $<$; c) $=$.
:::

:::exercise
Binh wrote: "$36\div4=8$ because $4\times8=36$". Where did Binh go wrong? Correct it.

::hint
**What you need:** check a division with a multiplication.

**Steps:**
1. Work out $4\times8$: does it equal $36$?
2. Find the right number in the $4$ times table.

::solution
$4\times8=32$, not $36$. We have $4\times9=36$, so $36\div4=9$.

**Check.** $4\times9=36$. Correct.

**Answer.** Binh remembered the wrong product; $36\div4=9$.
:::

:::exercise
a) Each car has $4$ wheels. How many wheels do $8$ such cars have?

b) $36$ cakes are put into boxes, $4$ cakes in each box. How many boxes are filled?

::hint
**What you need:** equal groups: to find the total, multiply; to find the number of groups, divide.

**Steps:**
1. What do we know? What is asked?
2. Choose the operation, work it out and write the answer with its unit.

::solution
a) The number of wheels is $4\times8=32$ (wheels).

b) The number of boxes is $36\div4=9$ (boxes).

**Answer.** a) $32$ wheels; b) $9$ boxes.
:::

:::exercise Challenge
Lan puts $40$ balls into boxes, $4$ balls in each box. She has already filled $6$ boxes. Find:

a) How many boxes are needed altogether?

b) How many boxes are still to fill, and how many balls are still to be packed?

::hint
**What you need:** the number of boxes is $40\div4$; the balls already packed are $4\times6$.

**Steps:**
1. Work out the total number of boxes.
2. Subtract the boxes filled, then work out the balls left.

::solution
a) The number of boxes needed is $40\div4=10$ (boxes).

b) The boxes still to fill: $10-6=4$ (boxes). The balls already packed: $4\times6=24$, so the balls left are $40-24=16$. Check: $4\times4=16$.

**Answer.** a) $10$ boxes; b) $4$ boxes and $16$ balls.
:::
