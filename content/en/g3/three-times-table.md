:::goals
- Know the 3 times table, from $3\times 1$ to $3\times 10$.
- Use the 3 times table to divide by $3$, for example $24\div 3$.
- Solve a word problem with one multiplication or one division.
:::

Mai puts cakes into boxes. Each box holds $3$ cakes. Mai fills $5$ boxes. How many cakes does Mai have altogether?

You could add $3+3+3+3+3$. But adding so many times is long and easy to get wrong. The 3 times table helps you work much faster.

## Let's explore

Count the cakes as Mai fills one more box each time.

- $1$ box has $3$ cakes.
- $2$ boxes have $3+3=6$ cakes.
- $3$ boxes have $6+3=9$ cakes.
- $4$ boxes have $9+3=12$ cakes.
- $5$ boxes have $12+3=15$ cakes.

Each new box adds $3$ more cakes. So $5$ boxes hold $15$ cakes. We write $3\times 5=15$.

Now go the other way. Mai has $15$ cakes and puts $3$ in each box. You count $5$ boxes. We write $15\div 3=5$.

:::theorem Multiplying by 3 and dividing by 3
1. $3\times 5$ means $5$ groups with $3$ in each: $3+3+3+3+3=15$.
2. In $3\times 5=15$, $3$ and $5$ are the **factors** and $15$ is the **product**.
3. From $3\times 5=15$ we get $15\div 3=5$.
4. In $15\div 3=5$, $15$ is the **dividend**, $3$ is the **divisor** and $5$ is the **quotient**.
:::

Learn the table below. Each row gives you one multiplication and one division.

| 3 times table | Division facts for 3 |
|---|---|
| $3\times 1=3$ | $3\div 3=1$ |
| $3\times 2=6$ | $6\div 3=2$ |
| $3\times 3=9$ | $9\div 3=3$ |
| $3\times 4=12$ | $12\div 3=4$ |
| $3\times 5=15$ | $15\div 3=5$ |
| $3\times 6=18$ | $18\div 3=6$ |
| $3\times 7=21$ | $21\div 3=7$ |
| $3\times 8=24$ | $24\div 3=8$ |
| $3\times 9=27$ | $27\div 3=9$ |
| $3\times 10=30$ | $30\div 3=10$ |

You see: going down one row, the product goes up by $3$. To divide by $3$, you only need to remember the matching multiplication.

## Examples

We start with a multiplication you may not know yet. Take the answer from the row just above and add $3$.

:::example Work out $3\times 7$
**Solution.** The row just above is $3\times 6=18$. Each row adds $3$, so:
$$3\times 7=3\times 6+3=18+3=21.$$
So $3\times 7=21$.
:::

Now go the other way to divide.

:::example Work out $24\div 3$
**Solution.** Find the number that times $3$ gives $24$. Count on in threes: $3, 6, 9, 12, 15, 18, 21, 24$. The number $24$ is the $8$th one, so $3\times 8=24$. Therefore:
$$24\div 3=8.$$
So $24\div 3=8$.
:::

Use multiplication to solve a problem from everyday life.

:::example Making bunches of flowers
Each bunch has $3$ flowers. Mrs Lan makes $9$ bunches. How many flowers does Mrs Lan have altogether?

**Solution.** There are $9$ bunches with $3$ flowers in each, so we add $3$ nine times: that is multiplication.
$$3\times 9=3\times 8+3=24+3=27\ \text{(flowers)}.$$
So Mrs Lan has $27$ flowers altogether.
:::

When we know the total and the size of each group, we divide.

:::example Oranges on plates
There are $21$ oranges, put on plates with $3$ oranges on each plate. How many plates are needed?

**Solution.** We split $21$ oranges into groups of $3$, so we divide. Since $3\times 7=21$:
$$21\div 3=7\ \text{(plates)}.$$
So $7$ plates are needed.
:::

:::warning Mistakes to watch out for
- **Adding instead of multiplying.** Wrong: $3\times 4=7$. Why it is wrong: $7$ is the answer to $3+4$. Right: $3\times 4=3+3+3+3=12$.
- **Slipping to the next row.** Wrong: $3\times 7=24$. Why it is wrong: $24$ is the answer to $3\times 8$. Right: $3\times 7=21$.
- **Subtracting instead of dividing.** Wrong: $12\div 3=9$. Why it is wrong: this is $12-3$. Right: $12\div 3=4$, because $3\times 4=12$.
:::

## Summary

- In the 3 times table, going down one row adds $3$ to the product, from $3\times 1=3$ to $3\times 10=30$.
- $3\times 5=15$ means $5$ groups with $3$ in each.
- To divide by $3$, find the matching multiplication: $3\times 8=24$, so $24\div 3=8$.
- Many equal groups: multiply. Sharing equally or making groups: divide. Remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out in your head: a) $3\times 5$; b) $3\times 8$.

::hint
**What you need:** count on in threes, or take the answer from the row above and add $3$.

**Steps:**
1. Part a: count on in threes five times.
2. Part b: you know $3\times 7=21$, so add $3$.

::solution
a) $3\times 5=3+3+3+3+3=15$.

b) $3\times 8=3\times 7+3=21+3=24$.

**Answer.** a) $15$; b) $24$.
:::

:::exercise
Fill in the missing numbers in the pattern: $3, 6, 9, \square, 15, \square, 21$.

::hint
**What you need:** each number in the pattern is $3$ more than the one before it.

**Steps:**
1. The number after $9$ is $9+3$.
2. The number after $15$ is $15+3$.

::solution
$9+3=12$ and $15+3=18$. The full pattern is $3, 6, 9, 12, 15, 18, 21$.

**Check.** $18+3=21$. Correct.

**Answer.** $12$ and $18$.
:::

:::exercise
Work out: a) $18\div 3$; b) $27\div 3$.

::hint
**What you need:** to divide by $3$, find the multiplication by $3$ that gives the dividend.

**Steps:**
1. Part a: $3\times\square=18$.
2. Part b: $3\times\square=27$.

::solution
a) $3\times 6=18$, so $18\div 3=6$.

b) $3\times 9=27$, so $27\div 3=9$.

**Answer.** a) $6$; b) $9$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $3\times 7 \;\square\; 20$.

::hint
**What you need:** work out the multiplication first, then compare the two numbers.

**Steps:**
1. Work out $3\times 7$.
2. Compare the result with $20$.

::solution
$3\times 7=21$. Since $21>20$, we have $3\times 7>20$.

**Answer.** The sign $>$.
:::

:::exercise
A teacher shares $15$ pens equally between $3$ children. How many pens does each child get?

::hint
**What you need:** sharing equally means dividing.

**Steps:**
1. What do we know? $15$ pens shared equally between $3$ children. What is asked? How many pens each child gets.
2. How do we solve it? Work out $15\div 3$, then check with multiplication.

::solution
The number of pens each child gets is:
$$15\div 3=5\ \text{(pens)}.$$

**Check.** $3\times 5=15$. Correct.

**Answer.** $5$ pens.
:::

:::exercise
Each row in the school garden has $3$ plant pots. The garden has $10$ rows like this. How many plant pots are there altogether?

::hint
**What you need:** many equal groups means multiplication.

**Steps:**
1. What do we know? $3$ pots in each row and $10$ rows. What is asked? The number of pots altogether.
2. How do we solve it? Work out $3\times 10$ and write the unit.

::solution
The number of plant pots altogether is:
$$3\times 10=30\ \text{(pots)}.$$

**Answer.** $30$ plant pots.
:::

:::exercise
Remember the last lesson: finding a missing number in an addition. Find the missing number: $\square+12=3\times 7$.

::hint
**What you need:** the missing addend is the total minus the addend you know.

**Steps:**
1. Work out $3\times 7$ to find the total.
2. Take away $12$ from the total.

::solution
$3\times 7=21$, so $\square+12=21$. The missing addend is $21-12=9$.

**Check.** $9+12=21$. Correct.

**Answer.** $9$.
:::

:::exercise Challenge
Mrs Hoa has $27$ apples and puts them into bags with $3$ apples in each bag. She gives away $4$ bags. How many apples does Mrs Hoa have left?

::hint
**What you need:** this problem has several steps: a division, a subtraction, then a multiplication.

**Steps:**
1. Find how many bags there were at first: $27\div 3$.
2. Find how many bags are left after giving away $4$.
3. Change the bags left into apples.

::solution
At first there were $27\div 3=9$ (bags). After giving away $4$ bags, $9-4=5$ (bags) are left. The apples left are $3\times 5=15$ (apples).

**Check.** She gave away $3\times 4=12$ apples, and $27-12=15$. Correct.

**Answer.** $15$ apples.
:::

## Mini test

:::quiz
::mc
$3\times 6$ equals
A. $9$.
B. $18$.
C. $15$.
D. $21$.
::key B
$3\times 6=3\times 5+3=15+3=18$. Option A is the mistake of adding $3+6$ instead of multiplying.

::mc
$27\div 3$ equals
A. $9$.
B. $24$.
C. $8$.
D. $30$.
::key A
Since $3\times 9=27$, we get $27\div 3=9$. Option B is the mistake of taking $27-3$, and option D is $27+3$.

::mc
Which of these is correct?
A. $3\times 4=7$.
B. $3\times 7=24$.
C. $3\times 5=18$.
D. $3\times 9=27$.
::key D
$3\times 9=3\times 8+3=24+3=27$. The others should be $12$, $21$ and $15$.

::mc
$18$ cakes are put into boxes with $3$ cakes in each box. How many boxes are there?
A. $15$ boxes.
B. $6$ boxes.
C. $21$ boxes.
D. $54$ boxes.
::key B
We make groups of $3$: $18\div 3=6$ (boxes). Option A is $18-3$, option C is $18+3$ and option D is $18\times 3$.

::tf
We know that $3\times 8=24$. Look at these calculations.
a) $24\div 3=8$.
b) $3\times 9=24+6$.
c) $3\times 7=24-3$.
d) $24\div 3=21$.
::key T F T F
a) True: from $3\times 8=24$ we get $24\div 3=8$. b) False: $3\times 9=27=24+3$. c) True: $3\times 7=21=24-3$. d) False: $24\div 3=8$, and $21$ is the answer to $24-3$.

::sa
Ha puts flowers in vases, $3$ in each vase. She fills $9$ vases. How many flowers does Ha have altogether?
::key 27
$3\times 9=27$ (flowers).

::sa
A teacher shares $30$ sweets equally between $3$ children. How many sweets does each child get?
::key 10
$30\div 3=10$, because $3\times 10=30$ (sweets).
:::
