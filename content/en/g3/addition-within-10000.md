:::goals
- Set out and add two four-digit numbers, with regrouping, for example $2\,456+1\,378$.
- Set out and subtract two four-digit numbers, with regrouping, for example $6\,243-2\,758$.
- Use the inverse operation to check an answer.
- Solve word problems with addition and subtraction, in one or two steps.
:::

The library of a primary school (made-up numbers) has $2\,456$ story books and $1\,378$ science books. How many books does the library have altogether?

When the library receives new books, we add. When classes borrow books, we subtract. The two operations always go together. This lesson shows you how to do both with numbers up to $10\,000$ without mistakes.

## Let's explore

Split each number by place: $2\,456=2\,000+400+50+6$ and $1\,378=1\,000+300+70+8$. We add place by place:

- Ones: $6+8=14$.
- Tens: $50+70=120$.
- Hundreds: $400+300=700$.
- Thousands: $2\,000+1\,000=3\,000$.

Putting it together: $14+120+700+3\,000=3\,834$.

This works but it is long. Set it out in columns, with digits of the same place in the same column, and add from right to left:

$$\begin{array}{r} 2\,456 \\ +\ 1\,378 \\ \hline 3\,834 \end{array}$$

Ones: $6+8=14$, write $4$ and regroup $1$. Tens: $5+7+1=13$, write $3$ and regroup $1$. Hundreds: $4+3+1=8$. Thousands: $2+1=3$.

So the library has $3\,834$ books. Setting out in columns is exactly the place-by-place addition above, just written more neatly.

## Addition within 10,000

:::theorem Adding two four-digit numbers
To add two four-digit numbers:
1. Set out the sum: digits of the same place go in the same column.
2. Add from right to left, starting with the ones. If a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
3. Write the answer.
:::

Why do the columns have to line up? Because we can only add things of the same kind: ones with ones, tens with tens. Why regroup? Because $10$ ones make $1$ ten, so when the ones column reaches $10$, we exchange it for $1$ ten and add it to the tens column.

We start with an addition that needs no regrouping.

:::example Set out and work out $3\,142+2\,526$
**Solution.** Every column adds to less than $10$, so nothing is regrouped:
$$\begin{array}{r} 3\,142 \\ +\ 2\,526 \\ \hline 5\,668 \end{array}$$
So $3\,142+2\,526=5\,668$.
:::

Now every column needs regrouping.

:::example Set out and work out $4\,758+2\,675$
**Solution.** We add column by column and regroup when a column makes $10$ or more:
$$\begin{array}{r} 4\,758 \\ +\ 2\,675 \\ \hline 7\,433 \end{array}$$
Ones: $8+5=13$, write $3$ and regroup $1$. Tens: $5+7+1=13$, write $3$ and regroup $1$. Hundreds: $7+6+1=14$, write $4$ and regroup $1$. Thousands: $4+2+1=7$.

So $4\,758+2\,675=7\,433$.
:::

Let us use addition to solve a word problem.

:::example Selling boxes of colouring pencils
A stationery shop (made-up numbers) sold $3\,285$ boxes of colouring pencils in January and $2\,749$ boxes in February. How many boxes of colouring pencils did the shop sell in the two months altogether?

**Solution.** "In the two months altogether" means putting the amounts together, so we add. The number of boxes sold in the two months is:
$$3\,285+2\,749=6\,034\ \text{(boxes)}.$$
**Answer.** $6\,034$ boxes of colouring pencils.
:::

## Subtraction within 10,000

:::theorem Subtracting two four-digit numbers
To subtract two four-digit numbers:
1. Set out the subtraction: the larger number on top, the smaller number below, digits of the same place in the same column.
2. Subtract from right to left, starting with the ones. If a digit on top is smaller than the digit below it, add $10$ to the digit on top, subtract, write the result and regroup $1$. This $1$ is added to the digit below in the column on the left.
3. Write the answer.
:::

Why regroup $1$? When we add $10$ ones to the top number in the ones column, we have "borrowed" $1$ ten. To keep the difference the same, we pay back $1$ ten by adding $1$ to the digit below in the tens column.

We start with a subtraction that needs no regrouping.

:::example Set out and work out $7\,689-3\,425$
**Solution.** In every column, the digit on top is not smaller than the digit below:
$$\begin{array}{r} 7\,689 \\ -\ 3\,425 \\ \hline 4\,264 \end{array}$$
So $7\,689-3\,425=4\,264$.
:::

Now every column needs regrouping.

:::example Set out and work out $6\,243-2\,758$
**Solution.** We subtract column by column and regroup when the digit on top is smaller:
$$\begin{array}{r} 6\,243 \\ -\ 2\,758 \\ \hline 3\,485 \end{array}$$
Ones: $3$ is less than $8$, so take $13-8=5$, write $5$ and regroup $1$. Tens: $5+1=6$; $4$ is less than $6$, so take $14-6=8$, write $8$ and regroup $1$. Hundreds: $7+1=8$; $2$ is less than $8$, so take $12-8=4$, write $4$ and regroup $1$. Thousands: $2+1=3$; $6-3=3$.

So $6\,243-2\,758=3\,485$.
:::

Finally, a problem that needs both operations. We work in four steps: understand, plan, solve, look back.

:::example A two-step problem
A stationery shop (made-up numbers) has $4\,500$ exercise books. On the first day the shop sells $1\,235$ books, and on the second day it receives $2\,480$ more. How many exercise books does the shop have after the two days?

**Understand.** We are told the starting number of books, the number sold and the number received. We are asked for the number of books after two days.

**Plan.** Selling books makes the number go down, so we subtract. Receiving books makes it go up, so we add. We follow the order of the story: subtract first, then add.

**Solve.**

Solution

The number of books left after the first day is:
$$4\,500-1\,235=3\,265\ \text{(books)}.$$
The number of books after the two days is:
$$3\,265+2\,480=5\,745\ \text{(books)}.$$
Answer: $5\,745$ exercise books.

**Look back.** Check with the inverse operation: $5\,745-2\,480=3\,265$. Now change the order, adding first and subtracting second: $4\,500+2\,480=6\,980$ and $6\,980-1\,235=5\,745$. Both ways give the same result, because the books sold and the books received do not depend on each other.
:::

**Connection.** Addition and subtraction are inverse operations: if $a+b=c$ then $c-b=a$. You can use this to check an answer. Later you will meet a pair of inverse operations like this for multiplication and division.

:::warning Mistakes to watch out for
- **Forgetting to regroup in an addition.** Wrong: $4\,758+2\,675=6\,323$. Why it is wrong: in each column only the ones digit was written and the $1$ was forgotten. Right: $4\,758+2\,675=7\,433$.
- **Subtracting the smaller digit from the larger in every column.** Wrong: $6\,243-2\,758=4\,515$. Why it is wrong: in each column the larger digit was taken away from the smaller one, even when the smaller digit is on top. Right: $6\,243-2\,758=3\,485$.
- **No unit in a word problem.** Wrong: "Answer: $6\,034$". Right: "Answer: $6\,034$ boxes of colouring pencils".
:::

## Summary

- To add or subtract four-digit numbers, set them out with digits of the same place **in the same column**, then work from right to left.
- Addition with regrouping: if a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
- Subtraction with regrouping: if the digit on top is smaller, add $10$ to it, subtract, write the result and add $1$ to the digit below in the column on the left.
- Check with the inverse operation: if $a+b=c$ then $c-b=a$. "Altogether" and "both" mean add; "left" means subtract; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Set out in columns and work out: $3\,425+2\,163$.

::hint
**What you need:** line up digits of the same place and add from right to left.

**Steps:**
1. Write $2\,163$ under $3\,425$, with the places lined up.
2. Add column by column, starting with the ones.

::solution
$$\begin{array}{r} 3\,425 \\ +\ 2\,163 \\ \hline 5\,588 \end{array}$$
No column makes $10$, so nothing is regrouped.

**Answer.** $5\,588$.
:::

:::exercise
Set out in columns and work out: $2\,749+3\,685$.

::hint
**What you need:** if a column makes $10$ or more, regroup $1$ into the column on the left.

**Steps:**
1. Set out the sum with the places lined up.
2. Add column by column, regrouping when needed.

::solution
$$\begin{array}{r} 2\,749 \\ +\ 3\,685 \\ \hline 6\,434 \end{array}$$
Ones: $9+5=14$, write $4$ and regroup $1$. Tens: $4+8+1=13$, write $3$ and regroup $1$. Hundreds: $7+6+1=14$, write $4$ and regroup $1$. Thousands: $2+3+1=6$.

**Answer.** $6\,434$.
:::

:::exercise
Set out in columns and work out: $8\,596-3\,241$.

::hint
**What you need:** the larger number goes on top; subtract from right to left.

**Steps:**
1. Write $3\,241$ under $8\,596$, with the places lined up.
2. Subtract column by column, starting with the ones.

::solution
$$\begin{array}{r} 8\,596 \\ -\ 3\,241 \\ \hline 5\,355 \end{array}$$
No column needs regrouping.

**Answer.** $5\,355$.
:::

:::exercise
Set out in columns and work out: $7\,003-4\,628$.

::hint
**What you need:** $3$ is less than $8$, so take $13$ minus $8$, then regroup $1$ into the tens column.

**Steps:**
1. Set out the subtraction with the places lined up.
2. In each column, add the regrouped $1$ to the digit below before you subtract.

::solution
$$\begin{array}{r} 7\,003 \\ -\ 4\,628 \\ \hline 2\,375 \end{array}$$
Ones: $13-8=5$, write $5$ and regroup $1$. Tens: $2+1=3$; $10-3=7$, write $7$ and regroup $1$. Hundreds: $6+1=7$; $10-7=3$, write $3$ and regroup $1$. Thousands: $4+1=5$; $7-5=2$.

**Answer.** $2\,375$.
:::

:::exercise
Find $x$: $x+2\,358=5\,000$.

::hint
**What you need:** an unknown addend equals the total minus the known addend.

**Steps:**
1. Write $x=5\,000-2\,358$.
2. Set out the subtraction and work it out, then check.

::solution
$x=5\,000-2\,358=2\,642$.

**Check.** $2\,642+2\,358=5\,000$. Correct.

**Answer.** $x=2\,642$.
:::

:::exercise
A petrol station (made-up numbers) sold $2\,865$ litres of petrol in the morning and $3\,478$ litres in the afternoon. How many litres of petrol did it sell in the whole day?

::hint
**What you need:** "in the whole day" means putting together: use addition.

**Steps:**
1. What do we know? What is asked?
2. How do we solve it? Set out the sum and add.
3. Check: the sum must be greater than each addend.

::solution
Solution

The number of litres sold in the whole day is:
$$2\,865+3\,478=6\,343\ \text{(litres)}.$$

**Answer.** $6\,343$ litres of petrol.
:::

:::exercise
Mai has $8\,000$ dong. She buys a pen for $2\,500$ dong and an exercise book for $4\,300$ dong. How many dong does Mai have left?

::hint
**What you need:** the money left equals the money she had minus the money she spent.

**Steps:**
1. Find the money she spent: use addition.
2. Find the money left: use subtraction.

::solution
Solution

The money Mai spent is:
$$2\,500+4\,300=6\,800\ \text{(dong)}.$$
The money Mai has left is:
$$8\,000-6\,800=1\,200\ \text{(dong)}.$$

**Answer.** $1\,200$ dong.
:::

:::exercise
Remember the lesson on comparing numbers. Write $>$, $<$ or $=$ in the gap: $3\,456+1\,234\ \ldots\ 4\,700$.

::hint
**What you need:** work out the left-hand side, then compare place by place from the thousands.

**Steps:**
1. Work out $3\,456+1\,234$.
2. Compare the result with $4\,700$, starting with the hundreds.

::solution
We have $3\,456+1\,234=4\,690$. The thousands digit is $4$ in both numbers; in the hundreds, $6<7$, so $4\,690<4\,700$.

**Answer.** The sign $<$.
:::

:::exercise
Nam works out $5\,400-2\,785=3\,615$. Use addition to check Nam's answer. If it is wrong, correct it.

::hint
**What you need:** if $a-b=c$ then $c+b=a$.

**Steps:**
1. Work out $3\,615+2\,785$.
2. If the sum is not $5\,400$, work out $5\,400-2\,785$ again.

::solution
We have $3\,615+2\,785=6\,400$, which is not $5\,400$, so Nam's answer is wrong. Working it out again: $5\,400-2\,785=2\,615$. Check: $2\,615+2\,785=5\,400$. Correct.

**Answer.** Nam is wrong; the correct answer is $2\,615$.
:::

:::exercise Challenge
Using the four digits $1$, $3$, $5$, $7$, write the largest and the smallest four-digit number with all digits different. Work out the difference between these two numbers.

::hint
**What you need:** the largest number has the largest digit in the thousands place, then the hundreds, then the tens.

**Steps:**
1. Arrange the digits from largest to smallest to get the largest number, and from smallest to largest to get the smallest number.
2. Set out the subtraction and work it out.

::solution
The largest number is $7\,531$ and the smallest is $1\,357$. We have:
$$7\,531-1\,357=6\,174.$$

**Answer.** $6\,174$.
:::
