:::goals
- Set out and add two numbers of up to five digits, with regrouping, for example $24\,365+38\,478$.
- Set out and subtract two numbers of up to five digits, with regrouping, for example $52\,304-18\,765$.
- Use the inverse operation to check an answer.
- Solve word problems with addition and subtraction, in one or two steps.
:::

A clothing workshop (made-up numbers) made $24\,365$ shirts in January and $38\,478$ shirts in February. How many shirts did the workshop make in the two months altogether?

These numbers have five digits, but the method is the same as for the four-digit numbers you already know: there is just one more place on the left. This lesson helps you add and subtract numbers up to $100\,000$ with confidence.

## Addition within 100,000

### Let's explore

Split each number by place: $24\,365=20\,000+4\,000+300+60+5$ and $38\,478=30\,000+8\,000+400+70+8$. We add place by place:

- Ones: $5+8=13$.
- Tens: $60+70=130$.
- Hundreds: $300+400=700$.
- Thousands: $4\,000+8\,000=12\,000$.
- Ten-thousands: $20\,000+30\,000=50\,000$.

Putting it together: $13+130+700+12\,000+50\,000=62\,843$.

Set it out in columns, with digits of the same place in the same column, and add from right to left:

$$\begin{array}{r} 24\,365 \\ +\ 38\,478 \\ \hline 62\,843 \end{array}$$

Ones: $5+8=13$, write $3$ and regroup $1$. Tens: $6+7+1=14$, write $4$ and regroup $1$. Hundreds: $3+4+1=8$. Thousands: $4+8=12$, write $2$ and regroup $1$. Ten-thousands: $2+3+1=6$.

So the workshop made $62\,843$ shirts in the two months.

### How to add

:::theorem Adding two numbers within 100,000
To add two numbers within $100\,000$:
1. Set out the sum: digits of the same place go in the same column.
2. Add from right to left, starting with the ones. If a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
3. Write the answer.
:::

Why do the columns have to line up? Because we can only add things of the same kind: ten-thousands with ten-thousands, thousands with thousands, and so on. Why regroup? Because $10$ units in one place make $1$ unit in the place on the left.

We start with an addition that needs no regrouping.

:::example Set out and work out $31\,524+45\,263$
**Solution.** Every column adds to less than $10$, so nothing is regrouped:
$$\begin{array}{r} 31\,524 \\ +\ 45\,263 \\ \hline 76\,787 \end{array}$$
So $31\,524+45\,263=76\,787$.
:::

Now every column needs regrouping.

:::example Set out and work out $47\,586+28\,749$
**Solution.** We add column by column and regroup when a column makes $10$ or more:
$$\begin{array}{r} 47\,586 \\ +\ 28\,749 \\ \hline 76\,335 \end{array}$$
Ones: $6+9=15$, write $5$ and regroup $1$. Tens: $8+4+1=13$, write $3$ and regroup $1$. Hundreds: $5+7+1=13$, write $3$ and regroup $1$. Thousands: $7+8+1=16$, write $6$ and regroup $1$. Ten-thousands: $4+2+1=7$.

So $47\,586+28\,749=76\,335$.
:::

Let us use addition to solve a word problem.

:::example The populations of two districts
Two districts (made-up numbers) have $35\,240$ people and $48\,765$ people. How many people live in the two districts altogether?

**Solution.** "In the two districts altogether" means putting the amounts together, so we add. The number of people in the two districts is:
$$35\,240+48\,765=84\,005\ \text{(people)}.$$
**Answer.** $84\,005$ people.
:::

## Subtraction within 100,000

:::theorem Subtracting two numbers within 100,000
To subtract two numbers within $100\,000$:
1. Set out the subtraction: the larger number on top, the smaller number below, digits of the same place in the same column.
2. Subtract from right to left, starting with the ones. If a digit on top is smaller than the digit below it, add $10$ to the digit on top, subtract, write the result and regroup $1$. This $1$ is added to the digit below in the column on the left.
3. Write the answer.
:::

Why regroup $1$? When we add $10$ units to the top number in one place, we have "borrowed" $1$ unit from the place on the left. To keep the difference the same, we pay it back by adding $1$ to the digit below in that column.

We start with a subtraction that needs no regrouping.

:::example Set out and work out $78\,956-34\,521$
**Solution.** In every column, the digit on top is not smaller than the digit below:
$$\begin{array}{r} 78\,956 \\ -\ 34\,521 \\ \hline 44\,435 \end{array}$$
So $78\,956-34\,521=44\,435$.
:::

Now every column needs regrouping.

:::example Set out and work out $52\,304-18\,765$
**Solution.** We subtract column by column and regroup when the digit on top is smaller:
$$\begin{array}{r} 52\,304 \\ -\ 18\,765 \\ \hline 33\,539 \end{array}$$
Ones: $4$ is less than $5$, so take $14-5=9$, write $9$ and regroup $1$. Tens: $6+1=7$; $0$ is less than $7$, so take $10-7=3$, write $3$ and regroup $1$. Hundreds: $7+1=8$; $3$ is less than $8$, so take $13-8=5$, write $5$ and regroup $1$. Thousands: $8+1=9$; $2$ is less than $9$, so take $12-9=3$, write $3$ and regroup $1$. Ten-thousands: $1+1=2$; $5-2=3$.

So $52\,304-18\,765=33\,539$.
:::

Finally, a problem that needs both operations. We work in four steps: understand, plan, solve, look back.

:::example A two-step problem
A rice store (made-up numbers) has $60\,000$ kg of rice. $24\,750$ kg is taken out, and then $18\,400$ kg more is delivered. How many kilograms of rice does the store have now?

**Understand.** We are told the starting amount of rice, the amount taken out and the amount delivered. We are asked for the amount in the store now.

**Plan.** Taking rice out makes the amount go down, so we subtract. Delivering rice makes it go up, so we add. We follow the order of the story: subtract first, then add.

**Solve.**

Solution

The number of kilograms left after taking rice out is:
$$60\,000-24\,750=35\,250\ \text{(kg)}.$$
The number of kilograms in the store now is:
$$35\,250+18\,400=53\,650\ \text{(kg)}.$$
Answer: $53\,650$ kg of rice.

**Look back.** Check with the inverse operation: $53\,650-18\,400=35\,250$. Now change the order, adding first and subtracting second: $60\,000+18\,400=78\,400$ and $78\,400-24\,750=53\,650$. Both ways give the same result, because the rice taken out and the rice delivered do not depend on each other.
:::

**Connection.** The method here is exactly the one you used for four-digit numbers, with one more place. Addition and subtraction are still inverse operations: if $a+b=c$ then $c-b=a$. You can use this to check an answer, and later to round and estimate results.

:::warning Mistakes to watch out for
- **Forgetting to regroup in an addition.** Wrong: $47\,586+28\,749=65\,225$. Why it is wrong: in each column only the ones digit of the total was written and the $1$ was forgotten. Right: $47\,586+28\,749=76\,335$.
- **Subtracting the smaller digit from the larger in every column.** Wrong: $52\,304-18\,765=46\,461$. Why it is wrong: in each column the larger digit was taken away from the smaller one, even when the smaller digit is on top. Right: $52\,304-18\,765=33\,539$.
- **Numbers not lined up in columns.** Wrong: $45\,678+934=55\,018$. Why it is wrong: $934$ was written one place too far to the left, so $45\,678$ was added to $9\,340$. Right: $45\,678+934=46\,612$.
:::

## Summary

- To add or subtract numbers within $100\,000$, set them out with digits of the same place **in the same column**, then work from right to left.
- Addition with regrouping: if a column makes $10$ or more, write the ones digit of the total and regroup $1$ into the column on the left.
- Subtraction with regrouping: if the digit on top is smaller, add $10$ to it, subtract, write the result and add $1$ to the digit below in the column on the left.
- Check with the inverse operation: if $a+b=c$ then $c-b=a$. "Both" and "altogether" mean add; "left" means subtract; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Set out in columns and work out: $23\,145+61\,432$.

::hint
**What you need:** line up digits of the same place and add from right to left.

**Steps:**
1. Write $61\,432$ under $23\,145$, with the places lined up.
2. Add column by column, starting with the ones.

::solution
$$\begin{array}{r} 23\,145 \\ +\ 61\,432 \\ \hline 84\,577 \end{array}$$
No column makes $10$, so nothing is regrouped.

**Answer.** $84\,577$.
:::

:::exercise
Set out in columns and work out: $36\,758+27\,495$.

::hint
**What you need:** if a column makes $10$ or more, regroup $1$ into the column on the left.

**Steps:**
1. Set out the sum with the places lined up.
2. Add column by column, regrouping when needed.

::solution
$$\begin{array}{r} 36\,758 \\ +\ 27\,495 \\ \hline 64\,253 \end{array}$$
Ones: $8+5=13$, write $3$ and regroup $1$. Tens: $5+9+1=15$, write $5$ and regroup $1$. Hundreds: $7+4+1=12$, write $2$ and regroup $1$. Thousands: $6+7+1=14$, write $4$ and regroup $1$. Ten-thousands: $3+2+1=6$.

**Answer.** $64\,253$.
:::

:::exercise
Set out in columns and work out: $87\,649-25\,317$.

::hint
**What you need:** the larger number goes on top; subtract from right to left.

**Steps:**
1. Write $25\,317$ under $87\,649$, with the places lined up.
2. Subtract column by column, starting with the ones.

::solution
$$\begin{array}{r} 87\,649 \\ -\ 25\,317 \\ \hline 62\,332 \end{array}$$
No column needs regrouping.

**Answer.** $62\,332$.
:::

:::exercise
Set out in columns and work out: $70\,025-34\,168$.

::hint
**What you need:** $5$ is less than $8$, so take $15$ minus $8$, then regroup $1$ into the tens column.

**Steps:**
1. Set out the subtraction with the places lined up.
2. In each column, add the regrouped $1$ to the digit below before you subtract.

::solution
$$\begin{array}{r} 70\,025 \\ -\ 34\,168 \\ \hline 35\,857 \end{array}$$
Ones: $15-8=7$, write $7$ and regroup $1$. Tens: $6+1=7$; $12-7=5$, write $5$ and regroup $1$. Hundreds: $1+1=2$; $10-2=8$, write $8$ and regroup $1$. Thousands: $4+1=5$; $10-5=5$, write $5$ and regroup $1$. Ten-thousands: $3+1=4$; $7-4=3$.

**Answer.** $35\,857$.
:::

:::exercise
Find $x$: $x+25\,360=70\,000$.

::hint
**What you need:** an unknown addend equals the total minus the known addend.

**Steps:**
1. Write $x=70\,000-25\,360$.
2. Set out the subtraction and work it out, then check.

::solution
$x=70\,000-25\,360=44\,640$.

**Check.** $44\,640+25\,360=70\,000$. Correct.

**Answer.** $x=44\,640$.
:::

:::exercise
Two concerts at an arena (made-up numbers): on Friday evening there are $15\,280$ people in the audience, and on Saturday evening there are $21\,765$. How many people are in the audience at the two concerts altogether?

::hint
**What you need:** "at the two concerts altogether" means putting together: use addition.

**Steps:**
1. What do we know? What is asked?
2. How do we solve it? Set out the sum and add.
3. Check: the sum must be greater than each addend.

::solution
Solution

The number of people in the audience at the two concerts is:
$$15\,280+21\,765=37\,045\ \text{(people)}.$$

**Answer.** $37\,045$ people.
:::

:::exercise
Hoa has $100\,000$ dong. She spends $45\,500$ dong on rice and $28\,750$ dong on cooking oil. How many dong does Hoa have left?

::hint
**What you need:** the money left equals the money she had minus the money she spent.

**Steps:**
1. Find the money she spent: use addition.
2. Find the money left: use subtraction.

::solution
Solution

The money Hoa spent is:
$$45\,500+28\,750=74\,250\ \text{(dong)}.$$
The money Hoa has left is:
$$100\,000-74\,250=25\,750\ \text{(dong)}.$$

**Answer.** $25\,750$ dong.
:::

:::exercise
Remember the lesson on comparing numbers. Write $>$, $<$ or $=$ in the gap: $58\,760+9\,240\ \ldots\ 68\,000$.

::hint
**What you need:** work out the left-hand side, then compare it with the right-hand side.

**Steps:**
1. Set out $58\,760+9\,240$.
2. Compare the result with $68\,000$.

::solution
We have $58\,760+9\,240=68\,000$. The two numbers are equal.

**Answer.** The sign $=$.
:::

:::exercise
Nam works out $80\,000-35\,600=54\,400$. Use addition to check Nam's answer. If it is wrong, correct it.

::hint
**What you need:** if $a-b=c$ then $c+b=a$.

**Steps:**
1. Work out $54\,400+35\,600$.
2. If the sum is not $80\,000$, work out $80\,000-35\,600$ again.

::solution
We have $54\,400+35\,600=90\,000$, which is not $80\,000$, so Nam's answer is wrong. Working it out again: $80\,000-35\,600=44\,400$. Check: $44\,400+35\,600=80\,000$. Correct.

**Answer.** Nam is wrong; the correct answer is $44\,400$.
:::

:::exercise Challenge
Find the difference between the largest and the smallest five-digit number whose digits are all different.

::hint
**What you need:** the largest number arranges the digits from largest to smallest; the smallest has the smallest digit in the ten-thousands place that is not $0$.

**Steps:**
1. Write the largest and the smallest number.
2. Set out the subtraction and work it out.

::solution
The largest number is $98\,765$. The smallest is $10\,234$ (the digit $1$ first, then $0$, $2$, $3$, $4$). We have:
$$98\,765-10\,234=88\,531.$$

**Answer.** $88\,531$.
:::
