:::goals
- Set out and multiply a four-digit number by a one-digit number (no regrouping).
- Multiply with regrouping: write one digit and carry to the place on the left.
- Check the answer by estimating.
- Solve a word problem with one multiplication.
:::

A box holds $1\,213$ exercise books. How many exercise books are there in $3$ such boxes?

You already know the times tables and how to multiply smaller numbers in columns. This lesson takes the same method to four-digit numbers.

## Let's explore

The number $1\,213$ is $1$ thousand, $2$ hundreds, $1$ ten and $3$ ones. We multiply each place by $3$ and put them back together.

| | Thousands | Hundreds | Tens | Ones |
|---|---|---|---|---|
| The number $1\,213$ | $1$ | $2$ | $1$ | $3$ |
| Times $3$ | $1\times3=3$ | $2\times3=6$ | $1\times3=3$ | $3\times3=9$ |

Putting them together gives $3$ thousands, $6$ hundreds, $3$ tens and $9$ ones, which is $3\,639$. So $3$ boxes hold $3\,639$ exercise books.

Instead of drawing a table, you set out the multiplication like this and multiply from right to left:

$$\begin{array}{r}1213\\ \times\ 3\\ \hline 3639\end{array}$$

:::theorem How to multiply a four-digit number by a one-digit number
1. Write the one-digit number under the four-digit number, lined up with the ones.
2. Multiply from right to left: ones, tens, hundreds, thousands.
3. If the product in a place has two digits, write the ones digit and **carry** the tens digit to the place on the left. In that place, multiply first and then **add the carried digit**.
:::

Why do we carry? For example, $15$ ones are $1$ ten and $5$ ones. You write the $5$ ones in the ones place, and the $1$ ten must go to the tens place.

## Examples

We start with a multiplication that needs no carrying.

:::example Multiplying without regrouping
Work out $2\,121\times4$.

**Solution.** Set out the multiplication and multiply each digit by $4$, from right to left:
$$\begin{array}{r}2121\\ \times\ 4\\ \hline 8484\end{array}$$
- Ones: $1\times4=4$, write $4$.
- Tens: $2\times4=8$, write $8$.
- Hundreds: $1\times4=4$, write $4$.
- Thousands: $2\times4=8$, write $8$.

So $2\,121\times4=8\,484$.
:::

The next example works in exactly the same way, with different numbers.

:::example Without regrouping, different numbers
Work out $3\,102\times3$.

**Solution.** Each place times $3$ is less than $10$, so there is nothing to carry:
$$\begin{array}{r}3102\\ \times\ 3\\ \hline 9306\end{array}$$
Ones: $2\times3=6$. Tens: $0\times3=0$. Hundreds: $1\times3=3$. Thousands: $3\times3=9$.

So $3\,102\times3=9\,306$.
:::

Now some places give a product of $10$ or more, so you must carry.

:::example Multiplying with regrouping
Work out $1\,425\times3$.

**Solution.** Multiply each place and carry when the product has two digits:
$$\begin{array}{r}1425\\ \times\ 3\\ \hline 4275\end{array}$$
- Ones: $5\times3=15$, write $5$ carry $1$.
- Tens: $2\times3=6$, add $1$ to get $7$, write $7$.
- Hundreds: $4\times3=12$, write $2$ carry $1$.
- Thousands: $1\times3=3$, add $1$ to get $4$, write $4$.

So $1\,425\times3=4\,275$.

**Check.** $1\,425$ is close to $1\,400$, and $1\,400\times3=4\,200$. The answer $4\,275$ is close to $4\,200$, so it makes sense.
:::

When you meet a $0$, you still add the carried digit.

:::example A zero digit and regrouping
Work out $2\,308\times4$.

**Solution.** The tens digit is $0$, but you still add the digit carried from the ones:
$$\begin{array}{r}2308\\ \times\ 4\\ \hline 9232\end{array}$$
- Ones: $8\times4=32$, write $2$ carry $3$.
- Tens: $0\times4=0$, add $3$ to get $3$, write $3$.
- Hundreds: $3\times4=12$, write $2$ carry $1$.
- Thousands: $2\times4=8$, add $1$ to get $9$, write $9$.

So $2\,308\times4=9\,232$.

**Check.** $2\,300\times4=9\,200$, close to $9\,232$. It makes sense.
:::

Last, use multiplication to solve a problem from everyday life.

:::example Boxes of pens
A storeroom has $6$ boxes, and each box holds $1\,125$ pens. How many pens are in the storeroom altogether?

**Solution.** Every box holds the same number of pens, so multiply the pens in one box by the number of boxes:
$$1\,125\times6=6\,750\ \text{(pens)}.$$
- Ones: $5\times6=30$, write $0$ carry $3$.
- Tens: $2\times6=12$, add $3$ to get $15$, write $5$ carry $1$.
- Hundreds: $1\times6=6$, add $1$ to get $7$, write $7$.
- Thousands: $1\times6=6$, write $6$.

So the storeroom has $6\,750$ pens.
:::

:::warning Mistakes to watch out for
- **Forgetting to add the carried digit.** Wrong: $1\,425\times3=4\,265$. Why it is wrong: in the tens you forgot to add the $1$ carried from the ones. Right: $2\times3=6$, add $1$ to get $7$, so the answer is $4\,275$.
- **Dropping the carried digit at a zero.** Wrong: $2\,308\times4=9\,202$. Why it is wrong: $0\times4=0$, but you still add the carried $3$, so the tens digit is $3$. Right: $9\,232$.
- **Leaving out the unit in a word problem.** Wrong: "Answer: $6\,750$". Right: "Answer: $6\,750$ pens".
:::

## Summary

- Line up the places and multiply each digit from right to left: ones, tens, hundreds, thousands.
- If the product in a place has two digits, write the ones digit and carry the tens digit to the place on the left.
- In the next place, multiply first and then add the carried digit, even when the digit is $0$.
- Check by rounding and estimating, and remember to write the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out:

a) $2\,103\times3$.

b) $1\,321\times2$.

::hint
**What you need:** multiply each digit by the one-digit number, from right to left. Neither of these needs carrying.

**Steps:**
1. Set out the multiplication, lined up with the ones.
2. Multiply the ones, tens, hundreds and thousands in turn.

::solution
a) Ones: $3\times3=9$. Tens: $0\times3=0$. Hundreds: $1\times3=3$. Thousands: $2\times3=6$. So $2\,103\times3=6\,309$.

b) Ones: $1\times2=2$. Tens: $2\times2=4$. Hundreds: $3\times2=6$. Thousands: $1\times2=2$. So $1\,321\times2=2\,642$.

**Answer.** a) $6\,309$; b) $2\,642$.
:::

:::exercise
Work out (with regrouping):

a) $1\,346\times2$.

b) $1\,507\times4$.

::hint
**What you need:** if the product in a place has two digits, write the ones digit and carry the tens digit to the place on the left.

**Steps:**
1. Multiply the ones and note any carry.
2. In the next place, multiply and then add the carry.

::solution
a) $6\times2=12$, write $2$ carry $1$. $4\times2=8$, add $1$ to get $9$. $3\times2=6$. $1\times2=2$. So $1\,346\times2=2\,692$.

b) $7\times4=28$, write $8$ carry $2$. $0\times4=0$, add $2$ to get $2$. $5\times4=20$, write $0$ carry $2$. $1\times4=4$, add $2$ to get $6$. So $1\,507\times4=6\,028$.

**Answer.** a) $2\,692$; b) $6\,028$.
:::

:::exercise
Remember the last lesson (subtraction within $10\,000$). Work out $5\,000-1\,275$, then multiply the answer by $2$.

::hint
**What you need:** subtraction with regrouping, then multiplication by a one-digit number.

**Steps:**
1. Set out and work out $5\,000-1\,275$.
2. Multiply the difference by $2$.

::solution
$5\,000-1\,275=3\,725$. Then $3\,725\times2=7\,450$ (because $5\times2=10$, write $0$ carry $1$; $2\times2=4$, add $1$ to get $5$; $7\times2=14$, write $4$ carry $1$; $3\times2=6$, add $1$ to get $7$).

**Check.** $3\,725+1\,275=5\,000$. Correct.

**Answer.** $7\,450$.
:::

:::exercise
Find the product of the two factors:

a) $2\,019$ and $4$.

b) $7$ and $1\,234$.

::hint
**What you need:** the product is the answer to a multiplication; swapping the two factors does not change the product.

**Steps:**
1. Write the four-digit number on top and the one-digit number underneath.
2. Multiply from right to left, carrying when needed.

::solution
a) $9\times4=36$, write $6$ carry $3$. $1\times4=4$, add $3$ to get $7$. $0\times4=0$. $2\times4=8$. So $2\,019\times4=8\,076$.

b) $1\,234\times7$: $4\times7=28$, write $8$ carry $2$. $3\times7=21$, add $2$ to get $23$, write $3$ carry $2$. $2\times7=14$, add $2$ to get $16$, write $6$ carry $1$. $1\times7=7$, add $1$ to get $8$. So the product is $8\,638$.

**Answer.** a) $8\,076$; b) $8\,638$.
:::

:::exercise
Does each problem need addition, subtraction or multiplication? Why? Then solve it.

a) Each jar holds $1\,250$ beans. How many beans are there in $3$ such jars?

b) A storeroom has $4\,080$ kg of rice and $1\,260$ kg have been sold. How many kilograms of rice are left?

c) A shop sells $2\,315$ books in the morning and $1\,280$ books in the afternoon. How many books does it sell in the whole day?

::hint
**What you need:** several equal groups means multiply; "left" means subtract; "both together" or "altogether" means add.

**Steps:**
1. What do we know? What is asked?
2. Choose the operation, solve, and write the unit.

::solution
a) There are $3$ equal jars, so multiply: $1\,250\times3=3\,750$ (beans).

b) Some rice "has been sold" and the question asks what is "left", so subtract: $4\,080-1\,260=2\,820$ (kg).

c) The books from the two parts of the day are put together, so add: $2\,315+1\,280=3\,595$ (books).

**Answer.** a) $3\,750$ beans; b) $2\,820$ kg; c) $3\,595$ books.
:::

:::exercise
Find the mistake in each pupil's work and correct it.

a) Nam: "$1\,536\times3=4\,598$."

b) Lan: "$3\,070\times2=6\,040$."

::hint
**What you need:** in each place, after multiplying you must add the digit carried from the right, even when the digit is $0$.

**Steps:**
1. Redo each place and note the carries.
2. Compare to find the place that went wrong.

::solution
a) $6\times3=18$, write $8$ carry $1$. $3\times3=9$, add $1$ to get $10$, write $0$ carry $1$. Nam forgot to add the $1$ and wrote $9$. Done correctly: $1\,536\times3=4\,608$.

b) $0\times2=0$. $7\times2=14$, write $4$ carry $1$. $0\times2=0$, add $1$ to get $1$. Lan forgot to add the $1$ in the hundreds because she saw a $0$. Done correctly: $3\,070\times2=6\,140$.

**Answer.** a) $4\,608$; b) $6\,140$.
:::

:::exercise
A factory makes $1\,450$ cakes every day.

a) How many cakes does the factory make in $3$ days?

b) An order needs $5\,000$ cakes. After $3$ days, how many more cakes are still needed?

::hint
**What you need:** several days with the same number of cakes each day means multiply; "still needed" means subtract.

**Steps:**
1. What do we know? What is asked?
2. Part a): multiply. Part b): take what has been made away from what is needed.
3. Check by estimating.

::solution
a) $1\,450\times3=4\,350$ (cakes).

b) $5\,000-4\,350=650$ (cakes).

**Check.** $1\,500\times3=4\,500$, close to $4\,350$. It makes sense.

**Answer.** a) $4\,350$ cakes; b) $650$ cakes.
:::

:::exercise Challenge
Mr Tu has $4$ bags of seeds and Mr Nam has $3$ bags of seeds. Each bag holds $1\,245$ seeds.

a) Work out how many seeds Mr Tu has and how many seeds Mr Nam has.

b) The two men put their seeds together. How many seeds are there in total? Why is this total also equal to $1\,245\times7$?

::hint
**What you need:** multiplying by $4$ means taking the number $4$ times; $4$ times plus $3$ times is $7$ times.

**Steps:**
1. Work out $1\,245\times4$ and $1\,245\times3$.
2. Add the two answers, then work out $1\,245\times7$ to compare.

::solution
a) Mr Tu: $1\,245\times4=4\,980$ seeds. Mr Nam: $1\,245\times3=3\,735$ seeds.

b) Total: $4\,980+3\,735=8\,715$ seeds. Together there are $4+3=7$ bags of $1\,245$ seeds each, so the total is $1\,245\times7=8\,715$. The two answers are the same.

**Answer.** a) $4\,980$ seeds and $3\,735$ seeds; b) $8\,715$ seeds.
:::
