:::goals
- Know and build the 8 times table.
- Use the 8 times table to divide by 8.
- Solve a word problem with one multiplication or one division.
:::

Each spider has $8$ legs. How many legs do $3$ spiders have altogether?

You could add $8+8+8$, and that works. But what if there were ten spiders, or twenty? Adding would take a long time. The $8$ times table is a shortcut: once you know it, the answer comes straight away.

## Let's explore

Each spider is a group of $8$ legs. Let's add the spiders one at a time and watch the number of legs change:

- $1$ spider: $8$ legs.
- $2$ spiders: $8+8=16$ legs.
- $3$ spiders: $16+8=24$ legs.

So $3$ spiders have $24$ legs, that is $8\times3=24$. Notice this: each time we add a spider, which is one more group, the product goes up by exactly $8$.

Here is one more trick, if you already know the $4$ times table. Why does it work? Because $8$ is double $4$, so $8\times3$ is also double $4\times3=12$. You only need to work out $12+12=24$.

:::theorem The 8 times table
To work out $8\times n$, take $8\times(n-1)$ and add $8$. You can also take $4\times n$ and double it.

| $8\times1$ | $8\times2$ | $8\times3$ | $8\times4$ | $8\times5$ |
|---|---|---|---|---|
| $8$ | $16$ | $24$ | $32$ | $40$ |

| $8\times6$ | $8\times7$ | $8\times8$ | $8\times9$ | $8\times10$ |
|---|---|---|---|---|
| $48$ | $56$ | $64$ | $72$ | $80$ |
:::

Once you know the $8$ times table, you know the division facts for $8$ too. Why? Because division undoes multiplication. Since $8\times3=24$, we have $24\div8=3$. In spider words: if you split $24$ legs into groups of $8$, you get $3$ groups, one for each spider.

## Examples

Let's try the doubling trick first, using the $4$ times table.

:::example Work out $8\times6$ by doubling
**Solution.** We have $4\times6=24$. Since $8$ is double $4$, $8\times6$ is double $4\times6$:
$$8\times6=24+24=48.$$
So $8\times6=48$.
:::

The second way is to take the product before and add $8$.

:::example Work out $8\times7$
**Solution.** You know $8\times6=48$. Add one more group of $8$:
$$8\times7=8\times6+8=48+8=56.$$
So $8\times7=56$.
:::

Sometimes it is easier to go back from the next product. Take that product and subtract $8$.

:::example Work out $8\times9$
**Solution.** You know $8\times10=80$. Take away one group of $8$:
$$8\times9=8\times10-8=80-8=72.$$
So $8\times9=72$.
:::

Now we use the times table to divide. Ask yourself: which number times the divisor gives the dividend?

:::example Work out $64\div8$
**Solution.** Ask: which number times $8$ makes $64$? In the $8$ times table, $8\times8=64$, so
$$64\div8=8.$$
**Check.** $8\times8=64$. Correct.

So $64\div8=8$.
:::

Finally, a word problem. Read it carefully and decide whether to multiply or divide before you work anything out.

:::example Cakes into boxes
There are $40$ cakes to put into boxes, $8$ cakes in each box. How many boxes can we fill?

**Solution.** We split $40$ cakes into groups of $8$, so we divide. The number of boxes is:
$$40\div8=5\ \text{(boxes)}.$$
**Check.** $8\times5=40$. Correct.

So we can fill $5$ boxes.
:::

:::warning Mistakes to watch out for
- **Using a nearby number.** Numbers that sit close together are easy to mix up. Wrong: $8\times7=54$. Why it is wrong: $54$ is not in the $8$ times table. Right: $8\times7=48+8=56$.
- **Adding instead of multiplying.** Wrong: $8\times8=16$. Why it is wrong: $8+8=16$ is an addition, but $8\times8$ means $8$ groups of $8$. Right: $8\times8=64$. Remember that multiplying means taking equal groups.
- **Dividing wrongly.** Wrong: $64\div8=7$. Why it is wrong: $8\times7=56$, not $64$. Right: $8\times8=64$, so $64\div8=8$. You can always check a division with a multiplication.
- **Forgetting the unit.** Wrong: "Answer: $5$". Right: "Answer: $5$ boxes".
:::

## Summary

- The $8$ times table: $8,\ 16,\ 24,\ 32,\ 40,\ 48,\ 56,\ 64,\ 72,\ 80$.
- Each new group adds $8$ to the product: $8\times n=8\times(n-1)+8$.
- $8$ is double $4$, so $8\times n$ is double $4\times n$.
- From $8\times a=b$ we get $b\div8=a$ and $b\div a=8$.
- Write the unit in the answer; check a division with a multiplication.

Back to the spiders: with the table, you can find the legs of any number of spiders without adding again and again. Knowing the times table gives you the division facts too, so practise a little at a time.

## Practice

Each exercise has a short reminder of what you need and a hint to get you started. Have a go on your own first, and don't worry if you get stuck. Then open the solution and compare.

:::exercise
Work out:

a) $8\times3$.

b) $8\times5$.

c) $8\times6$.

::hint
**What you need:** the $8$ times table: each new group adds $8$ to the product.

**Steps:**
1. Count in eights: $8,\ 16,\ 24,\ \dots$
2. Stop at the number you need.

::solution
We use the $8$ times table: each time we add one more $8$, the product goes up by $8$.

a) $8\times3=8+8+8=24$.

b) From $8\times3=24$, we have $8\times4=24+8=32$ and $8\times5=32+8=40$.

c) From $8\times5=40$, we have $8\times6=40+8=48$.

So $8\times3=24$; $8\times5=40$; $8\times6=48$.

**Answer.** a) $24$; b) $40$; c) $48$.
:::

:::exercise
Work out:

a) $8\times7$.

b) $8\times9$.

c) $8\times10$.

::hint
**What you need:** $8\times n=8\times(n-1)+8$.

**Steps:**
1. Remember the product before.
2. Add $8$.

::solution
We continue from $8\times6=48$: each time we add one more $8$, the product goes up by $8$.

a) $8\times7=48+8=56$.

b) We have $8\times8=56+8=64$, so $8\times9=64+8=72$.

c) $8\times10=72+8=80$.

So $8\times7=56$; $8\times9=72$; $8\times10=80$.

**Answer.** a) $56$; b) $72$; c) $80$.
:::

:::exercise
Remember the $7$ times table. Work out and compare:

a) $7\times8$.

b) $8\times7$.

c) $7\times9$ and $8\times8$.

::hint
**What you need:** swapping the two factors does not change the product.

**Steps:**
1. Work out each product with the $7$ or $8$ times table.
2. Compare the results.

::solution
a) By the $7$ times table, $7\times8=56$.

b) When we swap the two factors, the product does not change, so $8\times7=56$, the same as $7\times8$.

c) By the $7$ times table, $7\times9=63$. By the $8$ times table, $8\times8=64$. Since $63<64$, we have $7\times9<8\times8$.

So $7\times8=8\times7=56$ and $7\times9=63<64=8\times8$.

**Answer.** a) $56$; b) $56$; c) $63$ and $64$.
:::

:::exercise
Work out:

a) $16\div8$.

b) $56\div8$.

c) $80\div8$.

::hint
**What you need:** from $8\times a=b$ we get $b\div8=a$.

**Steps:**
1. Find the product equal to the dividend in the $8$ times table.
2. The other number is the quotient.

::solution
To divide by $8$, we look for the number that multiplied by $8$ gives the dividend.

a) Since $8\times2=16$, we have $16\div8=2$.

b) Since $8\times7=56$, we have $56\div8=7$.

c) Since $8\times10=80$, we have $80\div8=10$.

So $16\div8=2$; $56\div8=7$; $80\div8=10$.

**Answer.** a) $2$; b) $7$; c) $10$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box. Why?

a) $8\times6 \;\square\; 50$.

b) $72\div8 \;\square\; 8\times1$.

c) $8\times8 \;\square\; 4\times16$.

::hint
**What you need:** work out each side first, then compare the two numbers.

**Steps:**
1. Work out each side with the times table and division facts.
2. Compare the results.

::solution
We work out the value of each side and then compare the two numbers.

a) We have $8\times6=48$. Since $48<50$, we have $8\times6<50$.

b) We have $72\div8=9$ (because $8\times9=72$) and $8\times1=8$. Since $9>8$, we have $72\div8>8\times1$.

c) We have $8\times8=64$ and $4\times16=64$. The two numbers are equal, so $8\times8=4\times16$.

So the signs to write are $<$, $>$, $=$.

**Answer.** a) $<$; b) $>$; c) $=$.
:::

:::exercise
Tam wrote: "$8\times7=54$". Where did Tam go wrong? Correct it.

::hint
**What you need:** $8\times7=8\times6+8$.

**Steps:**
1. Work out $8\times7$ again from the product before.
2. Check with a division.

::solution
We work out $8\times7$ again by adding $8$ to $8\times6$:
$$8\times7=8\times6+8=48+8=56.$$

Tam's $54$ is wrong, because the correct product is $56$.

Check: $56\div8=7$, because $8\times7=56$. Correct.

So Tam remembered the wrong product. The correct calculation is $8\times7=56$.

**Answer.** Tam remembered the wrong product; $8\times7=56$.
:::

:::exercise
a) Each spider has $8$ legs. How many legs do $9$ spiders have?

b) $64$ mangoes are put into baskets, $8$ mangoes in each basket. How many baskets are filled?

::hint
**What you need:** equal groups: to find the total, multiply; to find the number of groups, divide.

**Steps:**
1. What do we know? What is asked?
2. Choose the operation, work it out and write the answer with its unit.

::solution
Solution

a) Each spider has $8$ legs, so the number of legs of $9$ spiders is:
$$8\times9=72\ \text{(legs)}.$$

So $9$ spiders have $72$ legs.

b) There are $64$ mangoes with $8$ in each basket, so the number of baskets filled is:
$$64\div8=8\ \text{(baskets)}.$$

Check: $8\times8=64$.

So $8$ baskets are filled.

**Answer.** a) $72$ legs; b) $8$ baskets.
:::

:::exercise Challenge
$80$ marbles are put into bags, $8$ marbles in each bag. Nam has already filled $6$ bags. Find:

a) How many bags are needed altogether?

b) How many bags are still to fill, and how many marbles are still to be bagged?

::hint
**What you need:** the number of bags is $80\div8$; the marbles already bagged are $8\times6$.

**Steps:**
1. Work out the total number of bags.
2. Subtract the bags filled, then work out the marbles left.

::solution
Solution

a) There are $80$ marbles with $8$ in each bag, so the number of bags needed is:
$$80\div8=10\ \text{(bags)}.$$

So $10$ bags are needed altogether.

b) The number of bags still to fill is:
$$10-6=4\ \text{(bags)}.$$
The number of marbles already bagged is:
$$8\times6=48\ \text{(marbles)}.$$
The number of marbles still to be bagged is:
$$80-48=32\ \text{(marbles)}.$$

Check: $8\times4=32$.

So $4$ bags are still to fill and $32$ marbles are still to be bagged.

**Answer.** a) $10$ bags; b) $4$ bags and $32$ marbles.
:::
