:::goals
- Read, write and partition four-digit numbers into thousands, hundreds, tens and ones.
- Recognise that $10\,000$ is the number after $9999$.
- Compare two numbers within $10\,000$ from left to right.
- Order numbers and solve word problems that compare numbers.
:::

A city library has $2345$ books. How is that number read? How many thousands, hundreds, tens and ones does it have? Another library has $2354$ books. Which library has more books?

You already know three-digit numbers. This lesson takes you to larger numbers: four digits, and then the number $10\,000$.

## Four-digit numbers

### Let's explore

You already know that $10$ hundreds make $1$ thousand. Putting together thousands, hundreds, tens and ones gives a four-digit number. The number $2345$ has $2$ thousands, $3$ hundreds, $4$ tens and $5$ ones:

| Thousands | Hundreds | Tens | Ones |
|---|---|---|---|
| $2$ | $3$ | $4$ | $5$ |

Write $2345=2000+300+40+5$ and read it as "two thousand three hundred and forty-five".

:::theorem Four-digit numbers
- A four-digit number has the places: thousands, hundreds, tens and ones.
- Each digit has a value that depends on its place.
- The digit in the thousands place is never $0$.
:::

Why does the position of a digit matter? Because the digit $2$ in $2345$ means $2$ thousands, which is $2000$, while in $5432$ the digit $2$ means $2$ ones. The same digit in a different place has a different value.

### Examples

We start with writing a number from how it is read.

:::example Writing a number
Write the number: three thousand four hundred and twenty-one.

**Solution.** This number has $3$ thousands, $4$ hundreds, $2$ tens and $1$ one, so the number is $3421$.
:::

When there is a digit $0$, you must write the places correctly.

:::example Partitioning a number with a digit $0$
Partition the number $5070$ into thousands, hundreds, tens and ones, and read it.

**Solution.** The number $5070$ has $5$ thousands, $0$ hundreds, $7$ tens and $0$ ones:
$$5070=5000+70.$$
It is read "five thousand and seventy".
:::

## The number 10,000

### Let's explore

The largest four-digit number is $9999$. Add $1$ to it:
$$9999+1=10\,000.$$
The number $10\,000$ is read "ten thousand", and has $10$ thousands or $1$ ten thousand. It is the smallest five-digit number. So $10\,000$ is the number after $9999$, and $9999$ is the number before $10\,000$.

:::theorem The number 10,000
- $9999+1=10\,000$.
- $10\,000$ is the smallest five-digit number.
- The number before $10\,000$ is $9999$.
:::

Why do we need one more digit? Because in $9999$ every place is already full of $9$s. Adding $1$ to the ones makes $10$ ones into $1$ ten, and the exchanges carry up place by place until at $10$ thousands a new place is needed.

### Examples

:::example The number before and the number after
Find the number after $9999$ and the number before $10\,000$. Count on in $1000$s from $7000$ to $10\,000$.

**Solution.** The number after $9999$ is $9999+1=10\,000$. The number before $10\,000$ is $10\,000-1=9999$.

Counting on in $1000$s: $7000$, $8000$, $9000$, $10\,000$.
:::

## Comparing numbers within 10,000

### Let's explore

The first library has $2345$ books and the second library has $2354$ books. Compare the two numbers from left to right:

- Thousands: $2=2$.
- Hundreds: $3=3$.
- Tens: $4<5$.

They first differ in the tens and $4<5$, so $2345<2354$. The second library has more books.

:::theorem Comparing numbers within 10,000
- A number with fewer digits is smaller.
- Two numbers with the same number of digits: compare place by place from left to right, starting with the thousands. The first place where the digits differ decides which number is greater.
:::

Why compare from the left? Because the thousands are worth the most. A greater thousands digit is enough to make a number greater, whatever the later digits are.

### Examples

We start with two numbers that have the same number of digits.

:::example Comparing $4567$ and $4576$
**Solution.** Thousands: $4=4$. Hundreds: $5=5$. Tens: $6<7$.

So $4567<4576$.
:::

A number with fewer digits is smaller.

:::example Comparing $9999$ and $10\,000$
**Solution.** $9999$ has four digits and $10\,000$ has five digits, so $9999<10\,000$.
:::

You can also order several numbers.

:::example Ordering numbers
Put the numbers $5432$, $5342$, $5423$ in order from smallest to largest.

**Solution.** All three numbers have $5$ in the thousands. In the hundreds: $3<4$, so $5342$ is the smallest. The other two have $4$ in the hundreds; in the tens: $2<3$, so $5423<5432$.

In order from smallest to largest: $5342<5423<5432$.
:::

The next problem is a little harder, so we use four steps: understand, plan, solve, look back.

:::example Two libraries
Library $A$ has $3482$ books and library $B$ has $3428$ books. Which library has more books?

**Understand.** Library $A$ has $3482$ books and library $B$ has $3428$ books. We are asked which library has more books.

**Plan.** Both numbers have four digits, so compare them place by place from left to right.

**Solve.** Thousands: $3=3$. Hundreds: $4=4$. Tens: $8>2$.

So $3482>3428$.

**Answer:** library $A$ has more books.

**Look back.** The two numbers differ only in the tens and ones, so they are close. Think about what would change if the thousands digit of one number were $4$.
:::

:::warning Mistakes to watch out for
- **Forgetting the digit $0$ when writing a number.** Wrong: "five thousand and seventy" written as $5700$. Why it is wrong: there are no hundreds, so the hundreds digit is $0$. Right: $5070$.
- **Comparing from the ones.** Wrong: $4567>4576$ because $7>6$. Why it is wrong: you must compare from the highest place; in the tens $6<7$. Right: $4567<4576$.
- **Thinking $10\,000$ has four digits.** Wrong: $10\,000$ has four digits. Why it is wrong: $10\,000$ has $5$ digits. Right: $10\,000$ is the smallest five-digit number.
:::

**Connection.** You already know three-digit numbers. Four-digit numbers, and then $10\,000$, show how the place-value chart grows: ten ones make a ten, ten tens make a hundred, ten hundreds make a thousand. In the next lessons you will round these numbers.

## Summary

- A four-digit number has thousands, hundreds, tens and ones places; its first digit is not $0$.
- $9999+1=10\,000$, and $10\,000$ is the smallest five-digit number.
- To compare numbers: fewer digits means smaller; with the same number of digits, compare from left to right.
- When you write a number with a digit $0$, keep the places correct.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
a) Write the number: seven thousand two hundred and thirty-four. b) Read the number $6805$.

::hint
**What you need:** write according to the thousands, hundreds, tens and ones places.

**Steps:**
1. How many thousands, hundreds, tens and ones are there?

::solution
a) $7$ thousands, $2$ hundreds, $3$ tens, $4$ ones: $7234$.

b) $6805$ has $6$ thousands, $8$ hundreds, $0$ tens and $5$ ones, and is read "six thousand eight hundred and five".

**Answer.** a) $7234$; b) six thousand eight hundred and five.
:::

:::exercise
Partition the number $4096$ into thousands, hundreds, tens and ones.

::hint
**What you need:** the hundreds digit of this number is $0$.

**Steps:**
1. Write the value of each digit.

::solution
$4096$ has $4$ thousands, $0$ hundreds, $9$ tens and $6$ ones:
$$4096=4000+90+6.$$
**Answer.** $4000+90+6$.
:::

:::exercise
Count on in $500$s from $8000$ to $10\,000$.

::hint
**What you need:** $2$ lots of $500$ make $1000$.

**Steps:**
1. Add $500$ to $8000$, then keep going.

::solution
$$8000,\ 8500,\ 9000,\ 9500,\ 10\,000.$$
**Answer.** $8000$, $8500$, $9000$, $9500$, $10\,000$.
:::

:::exercise
Fill in $>$, $<$ or $=$: a) $6548\ \ldots\ 6584$; b) $9999\ \ldots\ 10\,000$; c) $3000+500\ \ldots\ 3050$.

::hint
**What you need:** compare from left to right; fewer digits means smaller.

**Steps:**
1. In part c, work out the sum first, then compare.

::solution
a) Thousands and hundreds are equal; in the tens $4<8$, so $6548<6584$.

b) $9999$ has four digits and $10\,000$ has five digits, so $9999<10\,000$.

c) $3000+500=3500$ and $3500>3050$ (hundreds $5>0$).

**Answer.** a) $<$; b) $<$; c) $>$.
:::

:::exercise
School $A$ has $1245$ pupils and school $B$ has $1254$ pupils. Which school has more pupils?

::hint
**What you need:** compare two four-digit numbers from left to right.

**Steps:**
1. In which place do the two numbers first differ?

::solution
Thousands: $1=1$. Hundreds: $2=2$. Tens: $4<5$. So $1245<1254$.

**Answer.** School $B$ has more pupils.
:::

:::exercise
Put the numbers $7108$, $7180$, $7018$, $7801$ in order from largest to smallest.

::hint
**What you need:** compare place by place from left to right.

**Steps:**
1. Find the number with the greatest hundreds digit.

::solution
Hundreds: the $8$ in $7801$ is the greatest. The other three have hundreds $1$, $1$, $0$: $7018$ is the smallest. Between $7180$ and $7108$, the tens $8>0$.

In order from largest to smallest: $7801>7180>7108>7018$.

**Answer.** $7801$, $7180$, $7108$, $7018$.
:::

:::exercise
Remember three-digit numbers. a) What is the largest three-digit number? What number comes after it? b) What is the largest four-digit number? What number comes after it?

::hint
**What you need:** adding $1$ to the largest number of one size gives the smallest number of the next size.

**Steps:**
1. How many digits $9$ does the largest three-digit number have?

::solution
a) The largest three-digit number is $999$; the number after it is $999+1=1000$.

b) The largest four-digit number is $9999$; the number after it is $9999+1=10\,000$.

**Answer.** a) $999$ and $1000$; b) $9999$ and $10\,000$.
:::

:::exercise Challenge
Using the four digits $3$, $0$, $8$, $5$, each exactly once, make the largest four-digit number and the smallest four-digit number.

::hint
**What you need:** the thousands digit cannot be $0$.

**Steps:**
1. Largest number: put the digits in order from greatest to smallest.
2. Smallest number: pick the smallest thousands digit that is not $0$.

::solution
Largest number: putting $8$, $5$, $3$, $0$ from greatest to smallest gives $8530$.

Smallest number: the thousands digit cannot be $0$, so pick $3$; then put $0$, $5$, $8$ from smallest to greatest to get $3058$.

**Answer.** The largest number is $8530$; the smallest number is $3058$.
:::
