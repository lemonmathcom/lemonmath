:::goals
- Name the tens and the ones of two two-digit numbers.
- Add two two-digit numbers (no regrouping), for example $23+34$.
- Solve a word problem with one addition.
:::

Lan has $23$ stickers. Hoa has $34$ stickers. How many stickers do the two girls have altogether?

Counting on one at a time takes too long. This lesson shows you a quick way: split each number into tens and ones.

## Let's explore

You learned in the last lesson that $23+4$ means adding the ones and keeping the tens the same. Now we add the tens as well.

We split each number into tens and ones:

| Number | Tens | Ones |
|---|---|---|
| $23$ | $2$ | $3$ |
| $34$ | $3$ | $4$ |

- Add the ones to the ones: $3+4=7$.
- Add the tens to the tens: $2+3=5$.
- $5$ tens and $7$ ones make $57$.

So $23+34=57$.

:::theorem How to add two two-digit numbers
To work out $23+34$:
1. Add the ones to the ones: $3+4=7$.
2. Add the tens to the tens: $2+3=5$.
3. Put them together: $5$ tens and $7$ ones make $57$.
:::

This works because you put tens with tens and ones with ones, so no sticker is lost and none is counted twice.

## Examples

We start with the simplest sum.

:::example Work out $23+34$
**Solution.** Add the ones: $3+4=7$. Add the tens: $2+3=5$:
$$23+34=57.$$
So $23+34=57$.
:::

Now a similar sum with different numbers.

:::example Work out $41+25$
**Solution.** Add the ones: $1+5=6$. Add the tens: $4+2=6$:
$$41+25=66.$$
So $41+25=66$.
:::

When one number is a whole number of tens, its ones digit is $0$.

:::example Work out $30+52$
**Solution.** Add the ones: $0+2=2$. Add the tens: $3+5=8$:
$$30+52=82.$$
So $30+52=82$.
:::

Now try a sum where the ones add up to nearly $10$.

:::example Work out $45+34$
**Solution.** Add the ones: $5+4=9$. Add the tens: $4+3=7$:
$$45+34=79.$$
So $45+34=79$.

**Check.** $79$ is bigger than $45$ and bigger than $34$, as a sum should be.
:::

Now use addition to answer a question from everyday life.

:::example Two classes
Class $1$A has $32$ pupils and Class $1$B has $36$ pupils. How many pupils are in the two classes altogether?

**Solution.** "The two classes" means putting them together, so we add. Ones: $2+6=8$. Tens: $3+3=6$:
$$32+36=68.$$
So the two classes have $68$ pupils.
:::

:::warning Mistakes to watch out for
- **Forgetting the tens.** Wrong: $23+34=7$. Why it is wrong: you only added the ones. Right: there are also $2+3=5$ tens, so $23+34=57$.
- **Swapping tens and ones.** Wrong: $23+34=75$. Why it is wrong: you wrote the ones before the tens. Right: $5$ tens and $7$ ones make $57$.
- **No unit in a word problem.** Wrong: "Answer: $68$". Right: "Answer: $68$ pupils".
:::

## Summary

- To add two two-digit numbers (no regrouping), add the ones to the ones and the tens to the tens.
- Example: $23+34=57$ because $3+4=7$ and $2+3=5$.
- Write the tens first and the ones second: $5$ tens and $7$ ones make $57$.
- Swapping the addends does not change the sum.
- Questions with "altogether" or "both" usually need addition; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Work out $32+45$.

::hint
**What you need:** add the ones to the ones, and the tens to the tens.

**Steps:**
1. Work out $2+5$.
2. Work out $3+4$.

::solution
Ones: $2+5=7$. Tens: $3+4=7$. So $32+45=77$.

**Answer.** $77$.
:::

:::exercise
Work out $61+28$.

::hint
**What you need:** $61$ has $6$ tens and $1$ one; $28$ has $2$ tens and $8$ ones.

**Steps:**
1. Work out $1+8$.
2. Work out $6+2$.

::solution
Ones: $1+8=9$. Tens: $6+2=8$. So $61+28=89$.

**Answer.** $89$.
:::

:::exercise
Work out $40+37$.

::hint
**What you need:** a whole number of tens has $0$ ones.

**Steps:**
1. Work out $0+7$.
2. Work out $4+3$.

::solution
Ones: $0+7=7$. Tens: $4+3=7$. So $40+37=77$.

**Answer.** $77$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $24+35 \;\square\; 60$.

::hint
**What you need:** work out the sum first, then compare the two numbers.

**Steps:**
1. Work out $24+35$.
2. Compare the result with $60$.

::solution
$4+5=9$ and $2+3=5$, so $24+35=59$. Since $59<60$, we have $24+35<60$.

**Answer.** The sign $<$.
:::

:::exercise
An apple tree has $54$ red apples and $23$ green apples. How many apples does the tree have altogether?

::hint
**What you need:** "altogether" means putting together: use addition.

**Steps:**
1. What do we know? $54$ red and $23$ green. What is asked? How many apples altogether.
2. Work out $54+23$ and write the answer with its unit.

::solution
The number of apples altogether is:
$$54+23=77\ \text{(apples)}.$$

**Answer.** $77$ apples.
:::

:::exercise
Remember the last lesson: adding a one-digit number to a two-digit number. Work out $35+4$, then add $20$ to the result.

::hint
**What you need:** a one-digit number is added to the ones only; $20$ is $2$ tens.

**Steps:**
1. Work out $35+4$.
2. Add $2$ more tens to the tens.

::solution
$5+4=9$, so $35+4=39$. Add $2$ tens: $3+2=5$ tens, so $39+20=59$.

**Answer.** $59$.
:::

:::exercise
Binh writes: "$25+43$: ones $5+3=8$, tens $2+4=6$, so $25+43=86$". Is Binh right or wrong? Why? Correct it.

::hint
**What you need:** write the tens first and the ones second.

**Steps:**
1. Are Binh's two additions correct?
2. Put the answer together: how many tens and how many ones?

::solution
Binh's two additions are correct, but he wrote the digits in the wrong places. There are $6$ tens and $8$ ones, so $25+43=68$.

**Answer.** Wrong; the correct answer is $68$.
:::

:::exercise Challenge
Find the missing digit: $3\square+41=75$.

::hint
**What you need:** the ones digit of the sum is $5$. Which digit plus $1$ makes $5$?

**Steps:**
1. Ask: $?+1=5$, so $?=4$.
2. Check the tens: $3+4=7$.

::solution
Ones: $4+1=5$. The number is $34$, so the missing digit is $4$.

**Check.** $34+41=75$. Correct.

**Answer.** $4$.
:::
