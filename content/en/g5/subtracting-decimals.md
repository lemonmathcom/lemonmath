:::goals
- Set out and work out the difference of two decimals, for example $7.85-3.24$.
- Add zeros at the end of the decimal part so that both numbers have the same number of decimal places.
- Solve a word problem with one subtraction of decimals and check it by addition.
:::

Nam has a rope $5.6$ m long. He cuts off $2.3$ m to tie a gift box. How many metres of rope are left?

Both lengths are decimals, so you cannot subtract them as whole numbers straight away. This lesson shows you how to set out the subtraction neatly and get it right.

## Let's explore

Change the metres into decimetres to make it easier. We have $5.6$ m $=56$ dm and $2.3$ m $=23$ dm.

- The rope left is $56-23=33$ (dm).
- Change back to metres: $33$ dm $=3.3$ m.

So $5.6-2.3=3.3$. You see: we subtract the whole numbers $56-23$, then put the decimal point back in the right place.

You write the subtraction in columns like this.

$$\begin{array}{r} 5.6 \\ -\ 2.3 \\ \hline 3.3 \end{array}$$

:::theorem How to subtract decimals
To subtract two decimals:
1. Write the second number under the first so that digits of the same place value are in the same column and the decimal points are in a line.
2. Subtract as you would with whole numbers.
3. Put the decimal point in the answer in line with the decimal points above.
:::

This works because, with the digits in the same columns, you always subtract tenths from tenths and hundredths from hundredths. If the two numbers have different numbers of decimal places, add zeros at the end of the decimal part of the shorter one. This does not change the value: $5.4=5.40$.

## Examples

We start with two numbers that have the same number of decimal places, and no regrouping.

:::example Work out $7.85-3.24$
**Solution.** Both numbers have two decimal places, so we line up the decimal points and subtract place by place:
$$\begin{array}{r} 7.85 \\ -\ 3.24 \\ \hline 4.61 \end{array}$$
So $7.85-3.24=4.61$.
:::

Now the numbers have different numbers of decimal places, and we regroup.

:::example Work out $12.4-5.78$
**Solution.** $5.78$ has two decimal places but $12.4$ has only one. We write $12.4=12.40$ and set it out; in the hundredths column $0$ cannot take away $8$, so we regroup:
$$\begin{array}{r} 12.40 \\ -\ \ 5.78 \\ \hline 6.62 \end{array}$$
So $12.4-5.78=6.62$.

**Check.** $6.62+5.78=12.40$. Correct.
:::

When the first number is a whole number, we also add a decimal point and zeros.

:::example Work out $9-3.45$
**Solution.** Write $9$ as $9.00$ so that it has two decimal places like $3.45$:
$$\begin{array}{r} 9.00 \\ -\ 3.45 \\ \hline 5.55 \end{array}$$
So $9-3.45=5.55$.
:::

Now use subtraction to answer a question from everyday life.

:::example Cutting cloth
A piece of cloth is $15.2$ m long. Ms Hoa uses $6.75$ m to make a shirt. How many metres of cloth are left?

**Solution.** "Left" means taking a part away, so we subtract. We write $15.2=15.20$ and set it out:
$$15.20-6.75=8.45\ \text{(m)}.$$
So $8.45$ m of cloth are left.
:::

:::warning Mistakes to watch out for
- **Decimal points not in a line.** Wrong: setting out $12.4-5.78$ with the digit $4$ above the digit $8$. Why it is wrong: $4$ is in the tenths place but $8$ is in the hundredths place. Right: decimal point under decimal point, $12.40-5.78=6.62$.
- **Forgetting to add zeros.** Wrong: $9-3.45=6.45$. Why it is wrong: you only did $9-3=6$ and copied $45$. Right: $9.00-3.45=5.55$.
- **Forgetting the decimal point in the answer.** Wrong: $7.85-3.24=461$. Why it is wrong: the answer must be smaller than $7.85$. Right: $7.85-3.24=4.61$.
- **Subtracting the wrong way round when you need to regroup.** Wrong: $5.2-1.7=4.5$ (taking $7-2$). Why it is wrong: $2$ cannot take away $7$, so you must regroup. Right: $5.2-1.7=3.5$.
:::

## Summary

- Set out the subtraction so that digits of the same place value are in the same column, with the **decimal points in a line**.
- If the numbers have different numbers of decimal places, add zeros at the end of the decimal part of the shorter one, for example $12.4=12.40$.
- Subtract as with whole numbers, then put the decimal point in the answer in line with the ones above.
- Check: difference $+$ subtrahend $=$ minuend.
- Questions with "left" or "taken away" usually need subtraction; remember the unit in the answer.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Set out and work out $8.95-4.32$.

::hint
**What you need:** line up the decimal points, then subtract as with whole numbers.

**Steps:**
1. Both numbers have two decimal places.
2. Subtract place by place from right to left, then put in the decimal point.

::solution
$$\begin{array}{r} 8.95 \\ -\ 4.32 \\ \hline 4.63 \end{array}$$

**Answer.** $4.63$.
:::

:::exercise
Work out $15.7-6.9$.

::hint
**What you need:** in the tenths place, $7$ cannot take away $9$, so you must regroup.

**Steps:**
1. Line up the decimal points.
2. Regroup $1$ from the ones place, then subtract place by place.

::solution
$15.7-6.9=8.8$.

**Check.** $8.8+6.9=15.7$. Correct.

**Answer.** $8.8$.
:::

:::exercise
Work out $20.5-8.76$.

::hint
**What you need:** add a zero so that both numbers have the same number of decimal places.

**Steps:**
1. Write $20.5=20.50$.
2. Set out the subtraction and subtract, regrouping when needed.

::solution
$20.50-8.76=11.74$.

**Answer.** $11.74$.
:::

:::exercise
Work out $6-2.8$.

::hint
**What you need:** a whole number can be written as a decimal: $6=6.0$.

**Steps:**
1. Write $6$ as $6.0$.
2. Set out the subtraction and subtract.

::solution
$6.0-2.8=3.2$.

**Answer.** $3.2$.
:::

:::exercise
Write $>$, $<$ or $=$ in the box: $14.5-6.25 \;\square\; 8.5$.

::hint
**What you need:** work out the difference first, then compare the two decimals.

**Steps:**
1. Write $14.5=14.50$ and work out $14.50-6.25$.
2. Compare the result with $8.5=8.50$.

::solution
$14.50-6.25=8.25$. Since $8.25<8.50$, we have $14.5-6.25<8.5$.

**Answer.** The sign $<$.
:::

:::exercise
A sack of sugar weighs $25.5$ kg. A shop sells $18.75$ kg of it. How many kilograms of sugar are left in the sack?

::hint
**What you need:** "left" means taking away: use subtraction.

**Steps:**
1. What do we know? The sack weighs $25.5$ kg and $18.75$ kg are sold. What is asked? The sugar that is left.
2. Work out $25.50-18.75$, write the unit in the answer, then check by addition.

::solution
The sugar left is:
$$25.50-18.75=6.75\ \text{(kg)}.$$

**Check.** $6.75+18.75=25.50$. Correct.

**Answer.** $6.75$ kg.
:::

:::exercise
Remember the last lesson: work out $4.75+3.6$. Then subtract $5.9$ from your answer.

::hint
**What you need:** adding and subtracting decimals both need the decimal points in a line.

**Steps:**
1. Write $3.6=3.60$ and work out the sum.
2. Write $5.9=5.90$ and subtract it from the sum.

::solution
$4.75+3.60=8.35$. Then $8.35-5.90=2.45$.

**Answer.** $2.45$.
:::

:::exercise Challenge
Find $x$, given that $x+3.75=10.2$.

::hint
**What you need:** an unknown addend equals the sum minus the known addend.

**Steps:**
1. Write $x=10.2-3.75$.
2. Write $10.2=10.20$ and subtract.

::solution
We have $x=10.2-3.75=10.20-3.75=6.45$.

**Check.** $6.45+3.75=10.20$. Correct.

**Answer.** $x=6.45$.
:::

::key C
$10.0-4.6=5.4$. Option A is the mistake of doing $10-4=6$ and copying the $6$; option D is the mistake of forgetting the decimal point.

B. $12.44$.
C. $124.0$.
D. $12.40$.
::key D
Adding a zero at the end of the decimal part does not change the value: $12.4=12.40$. Options A and C change the value of the number.

B. $6.2-3.8$.
C. $9.3-6.7$.
D. $5.5-2.5$.
::key A
$7.9-5.4=2.5$. The other subtractions equal $2.4$, $2.6$ and $3$.

D. $6.75$ litres.
::key B
"Used" means taken away: $5.00-1.75=3.25$. Option D is an addition by mistake; option C forgets the decimal point.
