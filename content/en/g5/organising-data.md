:::goals
- Collect data by asking, counting and using tally marks.
- Sort data into a table and check the total.
- Read a data table and put data in ascending or descending order.
:::

Class 5A has $24$ children. The teacher asks: "Which fruit do you like best?" She writes down each answer in the order she asks:

Orange, Mango, Guava, Orange, Banana, Mango, Orange, Watermelon, Orange, Mango, Banana, Guava, Orange, Mango, Orange, Watermelon, Banana, Mango, Orange, Guava, Mango, Banana, Orange, Watermelon.

The list is long and messy. Which fruit did the most children choose?

## Let's explore

Draw a table with one row for each fruit. Read each answer and make one stroke in that fruit's row. After $5$ strokes, group them together to make counting easy. This is called a **tally**.

| Fruit | Tally | Number of children |
|---|---|---|
| Orange | ///// /// | 8 |
| Mango | ///// / | 6 |
| Banana | //// | 4 |
| Guava | /// | 3 |
| Watermelon | /// | 3 |
| Total | | 24 |

Add the numbers: $8+6+4+3+3=24$. The total equals the number of children asked, so no child was missed or counted twice. The favourite fruit is orange, with $8$ children.

:::theorem Three jobs with data
1. **Collect:** ask, measure or count, and write down each piece of data.
2. **Sort into groups:** put the data into groups, tally it and write it in a table. Add up to check the total.
3. **Put in order:** arrange the numbers in **ascending order** (smallest to largest) or **descending order** (largest to smallest).
:::

Checking the total is an important step. If the total is different from the number of children asked, you missed someone or counted someone twice, so count again.

## Examples

We start with data that are numbers: the number of brothers and sisters each child has.

:::example Brothers and sisters
The teacher asks $12$ children: "How many brothers and sisters do you have?" The answers are $1, 2, 1, 0, 2, 1, 3, 1, 2, 1, 0, 2$. Make a table of the data.

**Solution.** We sort the numbers into the groups $0$, $1$, $2$, $3$ and count:

| Brothers and sisters | Tally | Number of children |
|---|---|---|
| 0 | // | 2 |
| 1 | ///// | 5 |
| 2 | //// | 4 |
| 3 | / | 1 |
| Total | | 12 |

Check: $2+5+4+1=12$, exactly the number of children asked. So $5$ children have exactly $1$ brother or sister.
:::

Once we have the data, we often need to put them in order.

:::example Putting heights in order
The heights of $6$ children in a group (in cm) are $138, 145, 141, 150, 139, 143$. Write them in ascending order. How tall are the shortest and the tallest child?

**Solution.** We find the smallest number, then the smallest of the numbers left, and so on:
$$138 < 139 < 141 < 143 < 145 < 150.$$
For descending order, write it backwards: $150, 145, 143, 141, 139, 138$.
So the shortest child is $138$ cm and the tallest is $150$ cm.
:::

Now read a data table and answer questions.

:::example Library loans
The table shows how many books were borrowed in $5$ days:

| Day | Monday | Tuesday | Wednesday | Thursday | Friday |
|---|---|---|---|---|---|
| Books | 34 | 28 | 41 | 28 | 39 |

Which day had the most loans? How many books were borrowed in the $5$ days? How many more books were borrowed on the busiest day than on the quietest day?

**Solution.** The largest number is $41$, so Wednesday had the most loans. The smallest number is $28$.

The total number of books is:
$$34+28+41+28+39=170.$$
The busiest day had this many more than the quietest day:
$$41-28=13.$$
So Wednesday had the most loans; $170$ books were borrowed in the week; the busiest day had $13$ more books than the quietest day.
:::

Finally, use the total to find a missing number in a table.

:::example A bakery
One morning a bakery sold $60$ items: $18$ rolls, $12$ steamed buns, $14$ sticky rice parcels and some doughnuts. How many doughnuts were sold? Put the items in order of the number sold, from most to least.

**Solution.** The known items add up to $18+12+14=44$. The doughnuts are the total minus the known items:
$$60-44=16.$$
Check: $18+12+14+16=60$. In descending order: $18, 16, 14, 12$, that is rolls, doughnuts, sticky rice, steamed buns.
So the bakery sold $16$ doughnuts.
:::

:::warning Mistakes to watch out for
- **Not checking the total.** Wrong: a table totals $23$ for $24$ children and nobody counts again. Why it is wrong: one child was missed. Right: add up and compare with the number asked.
- **Mixing up ascending and descending.** Wrong: saying $5, 9, 12$ is descending. Why it is wrong: the numbers are getting bigger. Right: $5<9<12$ is ascending.
- **Ordering numbers but dropping the names.** Wrong: putting running times in order without saying who ran each one. Right: keep each name with its number.
:::

## Summary

- Collect data by asking, measuring or counting; write down each piece of data.
- Sort into a table with a **tally**: one stroke each time, and group every $5$ strokes.
- Add the numbers in the table; the total must equal the number of children asked.
- **Ascending:** smallest to largest. **Descending:** largest to smallest.
- When the total is known, a missing number is the total minus the known numbers.

## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Put these numbers in ascending order: $47, 39, 52, 40, 45$.

::hint
**What you need:** ascending means smallest to largest.

**Steps:**
1. Find the smallest number.
2. Find the smallest of the numbers left, and so on.

::solution
The smallest is $39$, then $40$, $45$, $47$, and the largest is $52$.

**Answer.** $39, 40, 45, 47, 52$.
:::

:::exercise
Put these numbers in descending order: $205, 250, 25, 502, 52$.

::hint
**What you need:** descending means largest to smallest. A number with more digits is larger.

**Steps:**
1. Find the three-digit numbers and compare them.
2. Compare the two-digit numbers.

::solution
The three-digit numbers: $502>250>205$. The two-digit numbers: $52>25$. A three-digit number is larger than a two-digit number.

**Answer.** $502, 250, 205, 52, 25$.
:::

:::exercise
The teacher asks $12$ children which pet they have: dog, cat, dog, fish, cat, dog, dog, cat, fish, dog, rabbit, cat. Make a table of the data. Which pet is the most common?

::hint
**What you need:** sort into groups, then tally; add up to check the total.

**Steps:**
1. Draw a table with four rows: dog, cat, fish, rabbit.
2. Read each answer and make a stroke.
3. Add the numbers and compare with $12$.

::solution
Dog: $5$ children; cat: $4$; fish: $2$; rabbit: $1$. Check: $5+4+2+1=12$. The largest number is $5$.

**Answer.** Dog $5$, cat $4$, fish $2$, rabbit $1$. The most common pet is the dog.
:::

:::exercise
The number of rainy days in four months: June $14$ days; July $17$ days; August $20$ days; September $16$ days. Which month had the most rainy days? How many rainy days were there in the four months?

::hint
**What you need:** the largest number is the rainiest month; the total is an addition.

**Steps:**
1. Find the largest of the four numbers.
2. Add the four numbers.

::solution
The largest number is $20$, for August. Total: $14+17+20+16=67$ (days).

**Answer.** August; $67$ days.
:::

:::exercise
Classes $5$A, $5$B, $5$C and $5$D planted $120$ trees altogether. Class $5$A planted $24$ trees, $5$B planted $31$ and $5$D planted $28$. How many trees did $5$C plant? Put the classes in order of trees planted, from most to least.

::hint
**What you need:** a missing number is the total minus the known numbers.

**Steps:**
1. What do we know? What is asked?
2. Add the trees planted by the three classes, then take that away from $120$.
3. Check by adding all four numbers.

::solution
The three classes planted $24+31+28=83$ (trees). Class $5$C planted $120-83=37$ (trees). Check: $83+37=120$. In descending order: $37, 31, 28, 24$.

**Answer.** Class $5$C planted $37$ trees. Order: $5$C, $5$B, $5$D, $5$A.
:::

:::exercise
The times for a $60$ m run (in seconds) are: An $11.2$; Binh $10.8$; Chi $12.5$; Dung $9.9$; Ha $10.6$. Who ran fastest? Put the children in order from fastest to slowest.

::hint
**What you need:** the less time, the faster the run, so put the times in ascending order.

**Steps:**
1. Compare the decimals: look at the whole-number part first.
2. Put them in order from smallest to largest, keeping each name with its time.

::solution
In ascending order: $9.9 < 10.6 < 10.8 < 11.2 < 12.5$. The smallest time is Dung's.

**Answer.** Dung ran fastest. Order: Dung, Ha, Binh, An, Chi.
:::

:::exercise
Remember the last lesson. Three children cycled at a steady speed for $2$ hours. Nam went $24$ km, Son went $30$ km and Tu went $26$ km. Work out each child's speed, then put them in order from fastest to slowest.

::hint
**What you need:** speed is distance divided by time: $v=s\div t$.

**Steps:**
1. Work out each child's speed.
2. Put the speeds in descending order.

::solution
Nam: $24\div2=12$ (km/h). Son: $30\div2=15$ (km/h). Tu: $26\div2=13$ (km/h). In descending order: $15, 13, 12$.

**Answer.** Son $15$ km/h, Tu $13$ km/h, Nam $12$ km/h.
:::

:::exercise Challenge
The teacher asks $30$ children to choose a sport. Football has $11$ children and chess has $4$. Badminton has $3$ more children than swimming. How many children chose badminton and how many chose swimming?

::hint
**What you need:** if you know the total and the difference of two numbers, the smaller is (total $-$ difference) $\div2$.

**Steps:**
1. Find how many children chose badminton and swimming together.
2. Use the difference $3$ to find the smaller number, then the larger.
3. Check by adding all four sports.

::solution
Badminton and swimming together: $30-11-4=15$ (children). Swimming: $(15-3)\div2=6$. Badminton: $6+3=9$.

**Check.** $11+9+6+4=30$ and $9-6=3$. Correct.

**Answer.** Badminton $9$ children, swimming $6$ children.
:::

## Mini test

:::quiz
::mc
Which list is in ascending order?
A. $48, 40, 84, 80$.
B. $84, 80, 48, 40$.
C. $40, 80, 48, 84$.
D. $40, 48, 80, 84$.
::key D
Ascending means smallest to largest: $40<48<80<84$. Option B is descending order.

::mc
Which number does the tally ///// /// show?
A. $8$.
B. $5$.
C. $7$.
D. $3$.
::key A
One full group of $5$ strokes and $3$ more strokes: $5+3=8$. Option B forgets the group of $3$, and option D forgets the group of $5$.

::mc
The teacher asks $20$ children which lesson they like best: Maths $6$ children, English $5$, Science $4$, and the rest like PE. How many children like PE?
A. $15$.
B. $5$.
C. $35$.
D. $4$.
::key B
The first three lessons have $6+5+4=15$ children, so PE has $20-15=5$. Option A is the number for the first three lessons, not yet taken away from $20$.

::mc
Which list is in descending order?
A. $0.9,\ 0.8,\ 0.85,\ 0.75$.
B. $0.75,\ 0.8,\ 0.85,\ 0.9$.
C. $0.9,\ 0.85,\ 0.8,\ 0.75$.
D. $0.85,\ 0.9,\ 0.8,\ 0.75$.
::key C
We have $0.9>0.85>0.8>0.75$. Option B is ascending; option A puts $0.8$ before $0.85$, which is wrong.

::tf
The number of books four children read in a month: Lan $8$, Mai $12$, Nam $5$, Hung $12$.
a) Mai and Hung read the most books.
b) The four children read $36$ books altogether.
c) In ascending order: $5, 8, 12, 12$.
d) Nam read $4$ fewer books than Lan.
::key T F T F
a) True: the largest number is $12$. b) False: $8+12+5+12=37$. c) True: $5<8<12=12$. d) False: $8-5=3$.

::sa
A shop sold $45$ cakes on the first day, $38$ on the second day and $52$ on the third day. How many cakes did it sell altogether?
::key 135
$45+38+52=135$ (cakes).

::sa
The test scores of $5$ children are $36, 29, 41, 33, 38$. In ascending order, which number is in second place?
::key 33
In ascending order: $29, 33, 36, 38, 41$. The second number is $33$.
:::
