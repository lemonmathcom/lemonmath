:::goals
- Know what an expression is and find the value of an expression with several operations.
- Carry out the operations in the correct order: powers, then multiplication and division, then addition and subtraction, from left to right.
- Use round, square and curly brackets correctly to change the order of calculation.
- Write an expression for a word problem and then calculate its value.
:::

Suppose you buy $1$ exercise book for $12$ thousand dong and $3$ pens at $7$ thousand dong each. The total cost is written $12+3\times7$. An calculates: $12+3=15$ then $15\times7=105$. Binh calculates: $3\times7=21$ then $12+21=33$. The two friends get different results. Which result is right for the money to be paid, and why?

## Expressions and the order of operations

**Explore.** Let us check with real life: $3$ pens at $7$ thousand dong each cost $3\times7=21$ thousand dong, and adding the exercise book at $12$ thousand dong gives $33$ thousand dong. So Binh is right. In the expression $12+3\times7$, the product $3\times7$ is a separate amount of money, so it must be worked out before the addition.

A string of numbers joined by operations (possibly with brackets) is called an **expression**. The result after carrying out the operations is called the **value** of the expression. So that everyone gets the same result, we agree on an order for the operations.

:::theorem Expressions without brackets
- If an expression has only addition and subtraction, or only multiplication and division, we calculate from left to right.
- If an expression has powers, multiplication, division, addition and subtraction, we carry out the operations in this order:
  1. powers;
  2. multiplication and division (from left to right);
  3. addition and subtraction (from left to right).
:::

:::theorem Expressions with brackets
We carry out the operations inside brackets first, in this order: round brackets $(\ )$, then square brackets $[\ ]$, then curly brackets $\{\ \}$. Inside each pair of brackets we follow the rules above.
:::

**Why this order?** Multiplication is repeated addition, so $3\times7$ is a ready-made "lump" that must be worked out before adding it to another number. A power is repeated multiplication, so it takes priority even over that. Brackets are used to gather a group of operations into a single number when we want that group done first. When there is only addition and subtraction (or only multiplication and division), the operations are at the same level, so we do them in the order they appear, from left to right.

## Examples

:::example Only addition and subtraction
Calculate $48-12+8$.

**Solution.** There are only addition and subtraction, so we go from left to right: $48-12+8=36+8=44$.
:::

:::example Power, multiplication and addition
Calculate $2+3\times4^2$.

**Solution.** Power first: $4^2=16$. Then multiply: $3\times16=48$. Finally add: $2+48=50$.
:::

:::example Multiplication, division, power and subtraction
Calculate $100\div5\times2-3^2$.

**Solution.** Power first: $3^2=9$. Multiplication and division from left to right: $100\div5=20$ then $20\times2=40$. Finally subtract: $40-9=31$.
:::

:::example Nested brackets
Calculate $100-\{5\times[4+(12-8)]\}$.

**Solution.** Round brackets first: $12-8=4$. Then square brackets: $4+4=8$. Then curly brackets: $5\times8=40$. Finally: $100-40=60$.
:::

The next problem is a word problem, so we go step by step: *Understand, Plan, Solve, Look back*.

:::example Change
Suppose Lan buys $4$ boxes of biscuits at $25$ thousand dong a box and $3$ boxes of sweets at $18$ thousand dong a box. She gives the seller $200$ thousand dong. How much change does she get?

**Solution.**

*Understand.* We must find the total cost of the biscuits and sweets, then subtract it from $200$ thousand dong.

*Plan.* The biscuits cost $4\times25$ and the sweets cost $3\times18$. The change is $200-(4\times25+3\times18)$.

*Solve.* We have $200-(4\times25+3\times18)$. Inside the brackets, multiply first: $4\times25=100$ and $3\times18=54$. Then add: $100+54=154$. Finally $200-154=46$. So Lan gets $46$ thousand dong in change.

*Look back.* Let us subtract the items one by one: $200-4\times25-3\times18=200-100-54=46$. Both ways give the same result, because subtracting the total is the same as subtracting each item. The brackets in the first way are essential: if we drop them and write $200-4\times25+3\times18$, we get $154$, not $46$.
:::

:::warning Mistakes to avoid
- **Adding before multiplying.** Wrong: $12+3\times7=15\times7=105$. Why it is wrong: multiplication must be done before addition. Right: $12+21=33$.
- **Not going from left to right.** Wrong: $48-12+8=48-20=28$. Why it is wrong: addition and subtraction are at the same level, so we go from left to right. Right: $36+8=44$.
- **Mishandling a power.** Wrong: $2\times3^2=6^2=36$. Why it is wrong: the power applies only to the $3$, and is done first. Right: $2\times9=18$.
- **Ignoring brackets.** Wrong: $20-(6+4)=20-6+4=18$. Why it is wrong: we must work out the brackets first. Right: $20-10=10$.
:::

## Summary

- Without brackets: powers first, then multiplication and division, then addition and subtraction; operations at the same level go from left to right.
- With brackets: round $(\ )$, then square $[\ ]$, then curly $\{\ \}$.
- To change the order, add brackets; for a word problem, write an expression first and then calculate.

## Practice

Try each one yourself first, then open the solution.

:::exercise
**Question 1.** Calculate: a) $60-25+15$; b) $72\div8\times3$.

::hint
**What you need:** addition and subtraction are at the same level, and so are multiplication and division: go from left to right.

**Steps:**
1. Do the first operation on the left.
2. Then the second.

::solution
a) $60-25+15=35+15=50$. b) $72\div8\times3=9\times3=27$.

**Answer.** a) $50$; b) $27$.
:::

:::exercise
**Question 2.** Calculate $5+4\times6-10$.

::hint
**What you need:** multiply first, then add and subtract from left to right.

**Steps:**
1. Work out $4\times6$.
2. Add, then subtract.

::solution
$5+4\times6-10=5+24-10=29-10=19$.

**Answer.** $19$.
:::

:::exercise
**Question 3.** Calculate $3\times2^3+5^2$.

::hint
**What you need:** powers first, then multiplication, then addition.

**Steps:**
1. Work out $2^3$ and $5^2$.
2. Multiply, then add.

::solution
$3\times2^3+5^2=3\times8+25=24+25=49$.

**Answer.** $49$.
:::

:::exercise
**Question 4.** Calculate $36\div(2+4)\times3$.

::hint
**What you need:** brackets first; then divide and multiply from left to right.

**Steps:**
1. Work out the brackets.
2. Divide, then multiply.

::solution
$36\div(2+4)\times3=36\div6\times3=6\times3=18$.

**Answer.** $18$.
:::

:::exercise
**Question 5.** Calculate: a) $2\times[30-(4+6)]$; b) $100-\{3\times[5+(9-4)]\}$.

::hint
**What you need:** round brackets, then square brackets, then curly brackets.

**Steps:**
1. Work out the innermost round brackets.
2. Work outwards in turn.

::solution
a) $2\times[30-10]=2\times20=40$. b) $9-4=5$; $5+5=10$; $3\times10=30$; $100-30=70$.

**Answer.** a) $40$; b) $70$.
:::

:::exercise
**Question 6.** Suppose a mother buys $5$ boxes of paints at $28$ thousand dong a box and $6$ exercise books at $9$ thousand dong each, and gives the seller $200$ thousand dong. How much change does she get?

::hint
**What you need:** change $=$ money given $-$ total cost.

**Steps:**
1. What is given? What is asked?
2. Write the expression $200-(5\times28+6\times9)$.
3. Work out the brackets, then subtract.

::solution
$200-(5\times28+6\times9)=200-(140+54)=200-194=6$ (thousand dong).

**Answer.** $6$ thousand dong.
:::

:::exercise
**Question 7.** Class $6$A has $36$ students standing in rows of $9$. Each row is given $2$ flags, and the whole class is given $3$ extra flags to share. How many flags are there in all?

::hint
**What you need:** number of rows $=36\div9$; write one expression, then calculate.

**Steps:**
1. What is given? What is asked?
2. Work out the number of rows.
3. Multiply by the flags per row, then add $3$.

::solution
Expression: $36\div9\times2+3=4\times2+3=8+3=11$ (flags).

**Answer.** $11$ flags.
:::

:::exercise
**Question 8.** Add brackets to make each equation true: a) $5+3\times4=32$; b) $20-6+4=10$.

::hint
**What you need:** brackets make a group of operations be done first.

**Steps:**
1. To make $5+3\times4$ equal $32$, which group must be done first?
2. To make $20-6+4$ equal $10$, which group must be done first?

::solution
a) $(5+3)\times4=8\times4=32$. b) $20-(6+4)=20-10=10$.

**Answer.** a) $(5+3)\times4=32$; b) $20-(6+4)=10$.
:::

:::exercise
**Question 9.** Calculate $25\times4\times13-3^3$.

::hint
**What you need:** use the commutative and associative properties to calculate quickly; powers first.

**Steps:**
1. Work out $25\times4$ first.
2. Work out $3^3$.
3. Subtract.

::solution
$25\times4\times13-3^3=100\times13-27=1300-27=1273$.

**Answer.** $1273$.
:::

:::exercise Challenge
**Question 10.** Using only four $4$s (each used once), the operations $+$, $-$, $\times$, $\div$ and brackets, write an expression with value: a) $5$; b) $7$.

::hint
**What you need:** brackets change the order of calculation; $4\div4=1$.

**Steps:**
1. Part a: try to make $20$ and then divide by $4$.
2. Part b: try $4+4-1$ with $1=4\div4$.

::solution
a) $(4\times4+4)\div4=(16+4)\div4=20\div4=5$. b) $4+4-4\div4=8-1=7$.

**Answer.** a) $(4\times4+4)\div4=5$; b) $4+4-4\div4=7$ (other answers are possible).
:::
