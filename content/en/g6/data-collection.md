The form teacher wants to organise a sports afternoon for class 6A and needs to know which sport the students like best. She could guess. But guesses are easily wrong: the students who speak loudest in class do not necessarily represent the whole class. A better way is to ask every student, write down the answers, count them, and present the results so that the whole class understands them at a glance.

Ask, record, count, present: those are the four steps of statistics. This lesson starts with those first steps.

## Data and collecting data

Pieces of information such as "football", "badminton", "$145$ cm" or "$3$ brothers and sisters" are called **data**. There are two types of data:

:::definition Two types of data
- **Numerical data**: height, mass, marks, temperature, number of brothers and sisters…
- **Non-numerical data**: name, home town, favourite colour, favourite sport…
:::

There are several ways to collect data. We choose one that suits the job:

- **Observing**, measuring or counting directly: counting the vehicles passing the school gate, measuring the temperature every day.
- **Doing an experiment**: planting a bean and measuring the plant every day, tossing a coin many times.
- **Using a questionnaire** (survey) or **interviewing**: asking classmates about their favourite sport.
- **Using an existing source**: books, newspapers, official websites, the class register.

## Is the data reasonable?

Collected data is not always right. Writing something down wrongly, mishearing or a joking answer can all produce data that makes no sense. Before using data, we check whether it is **reasonable**.

:::tip Three questions to check data
1. Is the value within the possible range? (A test mark out of $10$ cannot be $11$; a student cannot be $15$ m tall.)
2. Is the value the right kind? (A number of students must be a natural number, not $4.5$.)
3. Do the numbers fit together? (The parts must add up to the whole.)
:::

## Statistical tables

Once the data has been collected, we have a list of raw data, for example $20$ answers written down one after another. It is hard to see anything in such a list. We reorganise it by **tallying**: each time we meet a value, we make a mark in the box for that value, then count the marks.

The results are written in a **statistical table**: one column (or row) lists the values, and the other column (or row) gives how many times each value appears. From the table we see at once which value is most common, which is least common, and how many there are altogether.

## Pictograms

A **pictogram** uses symbols (circles, stars, little books…) to show data. Each symbol stands for a fixed amount, stated in the key. Pictograms are easy to understand and eye-catching, so they are often used in newspapers, posters and notice boards.

## Examples

We start by sorting data.

:::example Numerical and non-numerical data
For each student's record, the teacher writes down: full name; height (cm); favourite subject; number of brothers and sisters; mass (kg). Which pieces of information are numerical data, and which are not?

**Solution.**

Height, number of brothers and sisters, and mass are written as numbers, so they are numerical data.

Full name and favourite subject are written in words, not numbers.

So the numerical data are height, number of brothers and sisters, and mass; the non-numerical data are full name and favourite subject.
:::

Check whether data is reasonable before using it.

:::example Unreasonable data
A table records information about four grade 6 students. Point out the unreasonable data and explain.

| Name | Age | Height (cm) | Maths mark (out of $10$) |
|---|---|---|---|
| An | $11$ | $145$ | $8$ |
| Bình | $112$ | $150$ | $9$ |
| Chi | $12$ | $15$ | $7$ |
| Dũng | $11$ | $148$ | $11$ |

**Solution.**

Bình's age is $112$: grade 6 students are usually about $11$ to $12$ years old, so this value is unreasonable (probably $12$ written wrongly).

Chi's height is $15$ cm: no grade 6 student is only $15$ cm tall, so it is unreasonable (probably a digit is missing, for example $150$ or $151$).

Dũng's maths mark is $11$: a mark out of $10$ cannot be $11$, so it is unreasonable.

So three pieces of data are unreasonable: Bình's age, Chi's height and Dũng's maths mark.
:::

From raw data to a statistical table.

:::example Making a statistical table
The class monitor asks $20$ classmates for their favourite colour and writes the answers down (B: blue, R: red, Y: yellow, G: green):

B, R, Y, B, B, R, G, B, Y, R, B, G, B, R, Y, B, R, B, G, B.

Make a statistical table. Which colour is the most popular?

**Solution.**

We tally each colour in the list:

Blue (B) appears in positions $1$; $4$; $5$; $8$; $11$; $13$; $16$; $18$; $20$, that is, $9$ times.

Red (R) appears in positions $2$; $6$; $10$; $14$; $17$, that is, $5$ times.

Yellow (Y) appears in positions $3$; $9$; $15$, that is, $3$ times.

Green (G) appears in positions $7$; $12$; $19$, that is, $3$ times.

Check: $9+5+3+3=20$, the number of students asked.

| Colour | Blue | Red | Yellow | Green |
|---|---|---|---|---|
| Number of students | $9$ | $5$ | $3$ | $3$ |

So blue is the most popular colour, chosen by $9$ students.
:::

Reading a pictogram.

:::example Reading a pictogram
Look at the pictogram "Favourite sports of the students in class 6A" above.

a) How many students like each sport?

b) How many students are there in class 6A (each student chose exactly one sport)?

**Solution.**

a) Each circle stands for $5$ students.

Football has $3$ circles, so $3\cdot5=15$ students.

Badminton has $2$ circles, so $2\cdot5=10$ students.

Swimming has $1$ circle, so $5$ students.

Basketball has $2$ circles, so $10$ students.

b) The number of students in class 6A is
$$15+10+5+10=40\ (\text{students}).$$

So a) football $15$, badminton $10$, swimming $5$, basketball $10$ students; b) the class has $40$ students.
:::

Finally, we draw a pictogram ourselves.

:::example Drawing a pictogram
In a tree-planting day, the four grade 6 classes planted these numbers of trees: class 6A planted $30$ trees, class 6B $25$ trees, class 6C $40$ trees and class 6D $35$ trees. Draw a pictogram to show these data.

**Solution.**

*Understand.* There are four classes, each one a row of the pictogram. We need to choose a symbol and decide how many trees each symbol stands for.

*Plan.* The numbers $30$; $25$; $40$; $35$ are all divisible by $5$. If each symbol stood for $10$ trees, $25$ and $35$ would need half symbols, which are awkward to draw. If each symbol stands for $5$ trees, every row has a whole number of symbols, and not too many.

*Solve.* Choose the symbol ● with each ● standing for $5$ trees. The number of symbols for each class is:

6A: $30:5=6$; 6B: $25:5=5$; 6C: $40:5=8$; 6D: $35:5=7$.

| Class | Trees planted (● $=5$ trees) |
|---|---|
| 6A | ●●●●●● |
| 6B | ●●●●● |
| 6C | ●●●●●●●● |
| 6D | ●●●●●●● |

So we get the pictogram above, with the key ● $=5$ trees.

*Look back.* From the pictogram we see at once that class 6C planted the most and class 6B the fewest, without reading any numbers. That is the power of a chart.
:::

:::warning Common mistakes
- **Forgetting the key of a pictogram.** Wrong: the football row has $3$ circles, so $3$ students like football. Why it is wrong: each circle stands for $5$ students. Right: $3\cdot5=15$ students.
- **Missing something when tallying.** Wrong: finishing the table without adding up. Why it is wrong: it is easy to miss or double-count a value. Right: always check that the numbers in the table add up to the number of raw data values.
- **Using unreasonable data.** Wrong: working out the mean height of the class when one student is recorded as "$15$ cm". Why it is wrong: one nonsensical value spoils the whole result. Right: find and correct (or remove) unreasonable data first.
- **Asking a few people and drawing a conclusion about the whole class.** Wrong: asking the $5$ students sitting nearby and deciding what the whole class likes. Why it is wrong: those $5$ students do not necessarily represent the class. Right: ask enough students, ideally the whole class.
:::

## Summary

- Data can be numerical or non-numerical.
- Collect data by observing, experimenting, using a questionnaire, or using an existing source.
- Before using data, check it is reasonable: right range, right kind, adds up.
- A statistical table lists the values and how many times each appears; it is made by tallying.
- A pictogram uses symbols; each symbol stands for the amount stated in the key.

The teacher of class 6A now has a clear answer: football is the favourite, with $15$ of the $40$ students. No guessing needed, just asking, recording, counting and presenting properly. ## Practice

Each exercise comes with what you need and how to start. Try it yourself first, then open the solution.

:::exercise
Which of these data are numerical and which are not: students' masses; home towns; test marks; favourite fruit; midday temperature?

::hint
**What you need:** numerical data are data written as numbers.

**Steps:**
1. For each kind of data, decide whether it is written as a number or in words.
2. Put them into two groups.

::solution
Mass, test marks and midday temperature are written as numbers, so they are numerical data.

Home town and favourite fruit are written in words, so they are not numerical.

So numerical: mass, test marks, temperature; non-numerical: home town, favourite fruit.

**Answer.** Numerical: mass, test marks, temperature. Non-numerical: home town, favourite fruit.
:::

:::exercise
Which way of collecting data should be used in each case?

a) The number of motorbikes passing the school gate between $6$:$30$ and $7$:$00$ a.m.

b) The favourite breakfast dishes of the students in the class.

c) The populations of the provinces and cities in the latest year.

d) The height of a bean plant every day for two weeks.

::hint
**What you need:** observing; experimenting; using a questionnaire; using an existing source.

**Steps:**
1. Decide whether the data already exists somewhere or has to be produced.
2. Choose the suitable way.

::solution
a) Stand at the school gate and count directly: observing.

b) Ask the classmates: using a questionnaire or interviewing.

c) These data have already been published by the statistics office: using an existing source (the official website of the statistics office).

d) Plant a bean and measure the plant every day: doing an experiment.

So a) observing; b) questionnaire; c) existing source; d) experiment.

**Answer.** a) Observing; b) questionnaire; c) existing source; d) experiment.
:::

:::exercise
The class monitor recorded the number of students in four grade 6 classes: 6A: $38$; 6B: $41$; 6C: $4.5$; 6D: $40$. Which value is unreasonable? Why?

::hint
**What you need:** the number of students must be a natural number within a sensible range.

**Steps:**
1. Check the kind of each value.
2. Check the range of the values.

::solution
The number of students in a class must be a natural number. The value $4.5$ for class 6C is not a natural number, so it is unreasonable. Also, a class usually has about $30$ to $45$ students; $4.5$ is far too small as well.

The values $38$; $41$; $40$ are natural numbers within a sensible range.

So the unreasonable value is the number of students in class 6C ($4.5$).

**Answer.** The number for class 6C ($4.5$).
:::

:::exercise
The shoe sizes of $15$ students in a group were recorded as follows:

$35$; $36$; $35$; $37$; $36$; $36$; $38$; $35$; $36$; $37$; $36$; $35$; $36$; $37$; $36$.

Make a statistical table. Which shoe size is worn by the most students?

::hint
**What you need:** tally each value and check the total.

**Steps:**
1. Count how many times each size $35$; $36$; $37$; $38$ appears.
2. Check that the total is $15$, then make the table.

::solution
Tally each shoe size:

Size $35$ appears in positions $1$; $3$; $8$; $12$: $4$ times.

Size $36$ appears in positions $2$; $5$; $6$; $9$; $11$; $13$; $15$: $7$ times.

Size $37$ appears in positions $4$; $10$; $14$: $3$ times.

Size $38$ appears in position $7$: $1$ time.

Check: $4+7+3+1=15$, correct.

| Shoe size | $35$ | $36$ | $37$ | $38$ |
|---|---|---|---|---|
| Number of students | $4$ | $7$ | $3$ | $1$ |

So size $36$ is worn by the most students ($7$ students).

**Answer.** Size $36$ (7 students).
:::

:::exercise
The pictogram below shows the number of books each class gave to the library (■ $=10$ books):

| Class | Books given |
|---|---|
| 6A | ■■■■ |
| 6B | ■■■ |
| 6C | ■■■■■ |
| 6D | ■■ |

a) How many books did each class give?

b) How many books did the four classes give altogether?

c) How many more books did the class that gave the most give than the class that gave the fewest?

::hint
**What you need:** the number of books is the number of symbols times $10$.

**Steps:**
1. Count the ■ in each row and multiply by $10$.
2. Add up; find the most and the fewest and subtract.

::solution
a) Each ■ stands for $10$ books.

Class 6A has $4$ ■, so it gave $4\cdot10=40$ books.

Class 6B has $3$ ■, so it gave $30$ books.

Class 6C has $5$ ■, so it gave $50$ books.

Class 6D has $2$ ■, so it gave $20$ books.

b) The four classes gave
$$40+30+50+20=140\ (\text{books}).$$

c) Class 6C gave the most ($50$ books) and class 6D the fewest ($20$ books). The difference is $50-20=30$ (books).

So a) $40$; $30$; $50$; $20$ books; b) $140$ books; c) $30$ books.

**Answer.** a) 6A: $40$; 6B: $30$; 6C: $50$; 6D: $20$. b) $140$. c) $30$.
:::

:::exercise
A class has $40$ students. They come to school as follows: by bicycle $12$ students, on foot $8$ students, by bus $4$ students, driven by parents $16$ students. Draw a pictogram of these data, with each ● standing for $4$ students.

::hint
**What you need:** the number of symbols is the number of students divided by $4$.

**Steps:**
1. Work out the number of ● in each row.
2. Draw a table with a key.

::solution
The number of ● for each way of getting to school is:

Bicycle: $12:4=3$; on foot: $8:4=2$; bus: $4:4=1$; driven by parents: $16:4=4$.

| Way to school | Number of students (● $=4$ students) |
|---|---|
| Bicycle | ●●● |
| On foot | ●● |
| Bus | ● |
| Driven by parents | ●●●● |

Check: $3+2+1+4=10$ symbols, standing for $10\cdot4=40$ students, the size of the class.

So we get the pictogram above.

**Answer.** Bicycle $3$ ●; on foot $2$ ●; bus $1$ ●; driven by parents $4$ ●.
:::

:::exercise
To find out which fruit the students in her class ($40$ students) like best, Mai asks the $5$ students sitting near her. $3$ of them say they like oranges, so Mai concludes: "The whole class likes oranges best." Is Mai's method and conclusion reasonable? What would you do?

::hint
**What you need:** the data must be plentiful enough and represent the whole group being studied.

**Steps:**
1. Compare the number of students asked with the size of the class.
2. Suggest a better way to collect the data.

::solution
Mai only asked $5$ of the $40$ students, and they were the ones sitting near her, who may have similar tastes. Too few students were asked, and they do not represent the whole class, so the conclusion "the whole class likes oranges best" is not reasonable.

A better method: give a questionnaire to all $40$ students (each chooses one fruit), tally the answers, make a statistical table, and only then decide which fruit is the favourite.

So Mai's conclusion is not reasonable; she should ask the whole class and make a statistical table.

**Answer.** Not reasonable, because too few students were asked; ask the whole class.
:::

:::exercise
Using the shoe-size table from exercise 4 (size $35$: $4$ students; $36$: $7$; $37$: $3$; $38$: $1$), answer:

a) How many students wear size $36$ or larger?

b) What percentage of the group wears size $35$? (Round to the nearest whole number.)

::hint
**What you need:** add the numbers of students for the sizes that qualify; $a$ as a percentage of $b$ is $\dfrac{a}{b}\cdot100\%$.

**Steps:**
1. Add the numbers for sizes $36$, $37$, $38$.
2. Work out $\dfrac{4}{15}\cdot100\%$ and round.

::solution
a) The number of students wearing size $36$ or larger is
$$7+3+1=11\ (\text{students}).$$

b) The students wearing size $35$ make up
$$\dfrac{4}{15}\cdot100\%=\dfrac{400}{15}\%\approx26.67\%\approx27\%.$$

So a) $11$ students; b) about $27\%$.

**Answer.** a) $11$ students; b) about $27\%$.
:::

:::exercise Challenge
In a pictogram, each ● stands for $6$ students, and a half symbol ◐ stands for $3$ students. The "Football" row shows ●●●●◐ and the "Badminton" row shows ●●.

a) How many students like each sport?

b) To show $15$ students who like swimming, which symbols should be drawn?

::hint
**What you need:** ● $=6$ students, ◐ $=3$ students.

**Steps:**
1. Count the whole and half symbols in each row.
2. Write $15=6\cdot2+3$.

::solution
a) The "Football" row has $4$ symbols ● and $1$ half symbol ◐, so the number of students who like football is
$$4\cdot6+3=27\ (\text{students}).$$

The "Badminton" row has $2$ symbols ●, so the number who like badminton is $2\cdot6=12$ (students).

b) We have $15=2\cdot6+3$. So we draw $2$ symbols ● and $1$ half symbol ◐: ●●◐.

So a) football $27$ students, badminton $12$ students; b) draw ●●◐.

**Answer.** a) $27$ students; $12$ students. b) ●●◐.
:::
