# Lemonmath terminology: Vietnamese → standard English

English files use the terms a British maths textbook (GCSE / A level / IB) uses, with British spelling.
Never translate word by word. If a Vietnamese term has no exact English twin, use the English term and,
the first time, add the Vietnamese name in brackets only if it helps (e.g. "the intercept theorem (in Vietnam: Thales' theorem)").
The **Avoid** column lists literal translations that sound wrong to an English-speaking teacher.
