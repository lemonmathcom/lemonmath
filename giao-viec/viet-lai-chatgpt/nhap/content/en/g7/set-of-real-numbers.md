The diagonal of a square with side $1$ has length $\sqrt2$. No fraction $\dfrac ab$ has square exactly $2$, yet this length has an exact position on the number line. How should the number system be extended?

## irrational numbers, real numbers and number-line representation

**A short exploration.**
From $1^2<2<2^2$, we get $1<\sqrt2<2$. A decimal approximation is $\sqrt2\approx1.414$. Its digits continue without ending or repeating periodically; this characterises an irrational number.

:::definition Irrational number
An irrational number cannot be written as $\dfrac ab$ with $a,b\in\mathbb Z$, $b\ne0$. Its decimal representation is infinite and non-recurring; examples include $\sqrt2,\pi$.
:::

:::definition Real number
The real numbers $\mathbb R$ consist of all rational and irrational numbers. Every real number corresponds to exactly one point on the number line, and every point represents a real number.
:::

**Why does this work?**
The number sets are nested: $\mathbb N\subset\mathbb Z\subset\mathbb Q\subset\mathbb R$. The square root of a non-negative number is a length and takes the non-negative value. To compare roots, bound them between squares or use an approximation precise enough for the decision.

**How to check your own work.** For a question on this topic, first state in words what is given and what must be found. Next write the rule you will use, substitute values or reason one step at a time, and then check the result in a different way: put it back into the data, estimate its size, or compare it with a diagram or number line. If two methods disagree, locate the first step where they differ instead of changing only the final answer. This habit catches sign errors, missing units and overlooked cases.

**Systems view.** irrational numbers, real numbers and number-line representation is not an isolated trick. Follow the chain: the data determine a model, the model determines the calculation, and the result must return to the original situation. When one piece of data changes, predict whether the result should increase, decrease or stay unchanged before calculating again.

## Worked examples and applications

:::example Classifying a square root
Classify $\sqrt{49}$.

**Solution.**
$\sqrt{49}=7$, so it is natural, integer, rational and real.

Therefore, $7\in\mathbb N$.
:::

:::example Recognising an irrational
Is $\sqrt{12}$ rational or irrational?

**Solution.**
$\sqrt{12}=2\sqrt3$, and $3$ is not a perfect square, so $\sqrt{12}$ is irrational.

Therefore, irrational.
:::

:::example Bounding a square root
Find consecutive integers between which $\sqrt{30}$ lies.

**Solution.**
$5^2=25<30<36=6^2$, so $5<\sqrt{30}<6$.

Therefore, $5,6$.
:::

:::example A square diagonal
A hypothetical square courtyard has side $8$ m. Find its diagonal exactly and approximately to $0.1$ m.

**Solution.**

*Understand.* Record the given data, the required result and any conditions.

*Plan.* Choose the relevant definition or rule, then work in a logical order.

*Solve.* By Pythagoras, $d=\sqrt{8^2+8^2}=8\sqrt2\approx11.3$ m.

*Look back.* Compare the result with the data and use an independent check.

Therefore, $8\sqrt2\approx11.3$ m.
:::

## Common mistakes and connections

:::warning What can go wrong?
- **Treating every root as irrational.** Calling $\sqrt{64}$ irrational merely because it has a radical sign. The radicand may be a perfect square. Evaluate $\sqrt{64}=8$ before classifying.
- **Confusing approximation with equality.** Writing $\sqrt2=1.41$. $1.41$ is only a truncated or rounded value. Use the notation $\sqrt2\approx1.41$.
:::

**Connections.** Real numbers fill the number line and describe irrational lengths exactly. Distinguishing exact values from approximations is essential in geometry, measurement and scientific calculation. When solving a problem, separate three layers: the data, the mathematical relationship and the conclusion. Before substituting values, state why the chosen rule applies; after each step, check signs, units and conditions. A diagram, small table or simple case often reveals a missing assumption. Estimate before calculating so that you know whether the answer should be large or small, positive or negative. After obtaining a result, use an independent check: substitute it back into the data, measure it on the diagram, or test a boundary case. If one item of data changes, predict which part of the method changes and which part remains valid. This approach turns a formula into a connected system of reasons and makes the idea usable in an unfamiliar situation instead of only in a memorised exercise. It also produces written work that another student can follow, question and verify line by line.

## Summary

- $\mathbb R$ contains rational and irrational numbers.
- An irrational has an infinite non-recurring decimal.
- $\mathbb N\subset\mathbb Z\subset\mathbb Q\subset\mathbb R$.
- The root of a perfect square is rational.
- Use $\approx$ for an approximation.
