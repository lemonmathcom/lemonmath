A class wants to know the most common way students travel to school. Asking three close friends is quick but may not represent the class. How should the question, participants and responses be organised to make the data trustworthy?

## collecting, classifying and representing data

**A short exploration.**
Use the question “What was your main way of travelling to school today?” with categories walking, bicycle, bus and other. Ask each student once, make tally marks, then total the frequencies. The sum of frequencies must equal the number of respondents.

:::definition Data and variables
Data are collected values or responses. A variable is the observed characteristic; it may be categorical, such as colour, or numerical, such as height. Each value must belong to an observational unit.
:::

:::definition Classification and frequency
Classification places data into clear, non-overlapping categories. The frequency of a value or category is the number of times it occurs. A tally table records frequencies systematically.
:::

**Why does this work?**
Good data collection needs a neutral question, a suitable sample and consistent recording. Categories should cover all relevant responses without allowing one response to enter two groups. Checking the total frequency reveals omissions or duplicate counting.

**How to check your own work.** For a question on this topic, first state in words what is given and what must be found. Next write the rule you will use, substitute values or reason one step at a time, and then check the result in a different way: put it back into the data, estimate its size, or compare it with a diagram or number line. If two methods disagree, locate the first step where they differ instead of changing only the final answer. This habit catches sign errors, missing units and overlooked cases.

**Systems view.** collecting, classifying and representing data is not an isolated trick. Follow the chain: the data determine a model, the model determines the calculation, and the result must return to the original situation. When one piece of data changes, predict whether the result should increase, decrease or stay unchanged before calculating again.

## Worked examples and applications

:::example Identifying a variable type
Is the variable “number of books read in a month” categorical or numerical?

**Solution.**
Its values are counts, so it is a discrete numerical variable.

Therefore, numerical.
:::

:::example Finding a frequency
Colour choices are red, blue, red, yellow, blue, red. What is the frequency of red?

**Solution.**
Red occurs $3$ times, so its frequency is $3$.

Therefore, $3$.
:::

:::example Checking a total
A table has frequencies $7,9,5,4$. How many observations are there?

**Solution.**
The total is $7+9+5+4=25$ observations.

Therefore, $25$.
:::

:::example Designing a survey
A club wants a suitable practice time for its $40$ members. Should it ask only the $5$ early arrivals or all $40$ members?

**Solution.**

*Understand.* Record the given data, the required result and any conditions.

*Plan.* Choose the relevant definition or rule, then work in a logical order.

*Solve.* Asking all $40$ avoids bias towards early arrivals and directly represents the whole club.

*Look back.* Compare the result with the data and use an independent check.

Therefore, ask all $40$.
:::

## Common mistakes and connections

:::warning What can go wrong?
- **Using a leading question.** Attaching praise or criticism to the preferred response. The wording influences responses rather than merely recording views. Use neutral wording and balanced response choices.
- **Allowing categories to overlap.** Putting a boundary value into two intervals. The total frequency may then exceed the number of observations. State clearly which endpoint is included in each interval.
:::

**Connections.** Data collection is the first step behind every statistical conclusion. An attractive chart cannot repair a biased sample or an ambiguous question; the quality of a conclusion starts with how data are produced. When solving a problem, separate three layers: the data, the mathematical relationship and the conclusion. Before substituting values, state why the chosen rule applies; after each step, check signs, units and conditions. A diagram, small table or simple case often reveals a missing assumption. Estimate before calculating so that you know whether the answer should be large or small, positive or negative. After obtaining a result, use an independent check: substitute it back into the data, measure it on the diagram, or test a boundary case. If one item of data changes, predict which part of the method changes and which part remains valid. This approach turns a formula into a connected system of reasons and makes the idea usable in an unfamiliar situation instead of only in a memorised exercise. It also produces written work that another student can follow, question and verify line by line.

## Summary

- Define the variable and observational unit before collecting.
- Questions should be clear, neutral and ask one thing.
- Categories should be non-overlapping and cover all responses.
- Frequency is the number of times a value or category occurs.
- The total frequency must equal the number of observations.
