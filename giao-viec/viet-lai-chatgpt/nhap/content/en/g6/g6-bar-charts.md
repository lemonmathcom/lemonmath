A table shows four classes collecting $18,24,15,21$ kg of paper. A bar chart turns the four numbers into heights so the largest is seen at once. How should the axes and scale be chosen so the display is not misleading?

## reading, drawing and analysing bar charts

**A short exploration.**
Place class names on the horizontal axis and mass on the vertical axis. Let each interval represent $3$ kg, label the unit, and draw equal-width, equally spaced bars. Their heights reach $18,24,15,21$.

:::definition Structure of a bar chart
A bar chart uses rectangular bars to represent the frequency or value of each category. One axis shows categories and the other values; bar height or length is proportional to the value.
:::

:::definition Scale and interpretation
Tick marks on the value axis are equally spaced and represent equal intervals. To read a bar, identify the value per interval and align its top with the axis. The title, labels and units provide context.
:::

**Why does this work?**
Because bars have equal width, the eye compares their lengths. A uniform scale ensures twice the height represents twice the value. A truncated axis or unequal intervals can exaggerate differences, so read values rather than relying only on appearance.

**How to check your own work.** For a question on this topic, first state in words what is given and what must be found. Next write the rule you will use, substitute values or reason one step at a time, and then check the result in a different way: put it back into the data, estimate its size, or compare it with a diagram or number line. If two methods disagree, locate the first step where they differ instead of changing only the final answer. This habit catches sign errors, missing units and overlooked cases.

**Systems view.** reading, drawing and analysing bar charts is not an isolated trick. Follow the chain: the data determine a model, the model determines the calculation, and the result must return to the original situation. When one piece of data changes, predict whether the result should increase, decrease or stay unchanged before calculating again.

## Worked examples and applications

:::example Reading a bar height
Each axis interval represents $5$ visits. A bar reaches interval $7$. What is its value?

**Solution.**
$7\cdot5=35$ visits.

Therefore, $35$.
:::

:::example Comparing categories
Bars $A,B$ have values $28,19$. How much larger is group $A$?

**Solution.**
$28-19=9$.

Therefore, $9$.
:::

:::example Finding a total
Four bars have values $12,17,9,22$. Find the total.

**Solution.**
$12+17+9+22=60$.

Therefore, $60$.
:::

:::example Planning a chart
The largest value is $46$. Is a vertical axis from $0$ to $50$ in intervals of $5$ suitable?

**Solution.**

*Understand.* Record the given data, the required result and any conditions.

*Plan.* Choose the relevant definition or rule, then work in a logical order.

*Solve.* Yes. It includes $46$, intervals of $5$ are readable and most of the chart height is used.

*Look back.* Compare the result with the data and use an independent check.

Therefore, yes.
:::

## Common mistakes and connections

:::warning What can go wrong?
- **Ignoring the axis scale.** Counting grid spaces and assuming each always equals $1$. An interval may represent $2,5,10$ or another value. Read two consecutive labels to find the value per interval.
- **Drawing unequal bar widths.** Making a large category both taller and wider. The area then makes differences appear larger than the data. Keep bar width and spacing consistent.
:::

**Connections.** A bar chart turns a frequency table into a visual comparison. Checking the scale is part of responsible data reading, especially when a chart is used to persuade. When solving a problem, separate three layers: the data, the mathematical relationship and the conclusion. Before substituting values, state why the chosen rule applies; after each step, check signs, units and conditions. A diagram, small table or simple case often reveals a missing assumption. Estimate before calculating so that you know whether the answer should be large or small, positive or negative. After obtaining a result, use an independent check: substitute it back into the data, measure it on the diagram, or test a boundary case. If one item of data changes, predict which part of the method changes and which part remains valid. This approach turns a formula into a connected system of reasons and makes the idea usable in an unfamiliar situation instead of only in a memorised exercise. It also produces written work that another student can follow, question and verify line by line.

## Summary

- One axis shows categories and the other shows values.
- Bar height is proportional to value.
- Axis intervals must be equal.
- Bars should have equal width and consistent spacing.
- Always read the title, labels, units and axis starting point.
